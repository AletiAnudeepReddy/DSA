131. Palindrome Partitioning
🧩 Problem

Given a string s, partition it into one or more substrings such that every substring is a palindrome.

Return all possible palindrome partitions.

Example
Input: s = "aab"


Possible partitions:


["a", "a", "b"]   → all are palindromes
["aa", "b"]       → all are palindromes

So the answer is:

[["a","a","b"],["aa","b"]]
💡 Intuition

This is a Backtracking problem.

At every index, we have a choice:

Where should I end the current substring?

For example:

s = "aab"
     ↑
   start

We try every possible substring starting from start:

"a"      → palindrome ✅
"aa"     → palindrome ✅
"aab"    → not palindrome ❌

Whenever the substring is a palindrome:

Add it to the current path.
Recursively solve the remaining string.
Remove it afterward (backtrack) and try another possibility.
🔄 Backtracking Tree

For:

s = "aab"

The recursion looks roughly like:

                        ""
                       / \
                     "a" "aa"
                     /     \
                   "a"      "b"
                   /         \
                 "b"          []

The valid partitions are:

["a", "a", "b"]
["aa", "b"]

The substring "aab" is rejected because it is not a palindrome.

🧠 Why path.remove()?

This is the most important part of backtracking.

Suppose we choose:

path.add("a");

Then we explore all possibilities beginning with "a".

After finishing those possibilities, we need to go back and try:

"aa"

So we remove the previous choice:

path.remove(path.size() - 1);

Think of it as:

Choose
 ↓
Explore
 ↓
Undo
 ↓
Choose next option

This pattern appears in many backtracking problems.

✅ Code
class Solution {


    public List<List<String>> partition(String s) {


        List<List<String>> res = new ArrayList<>();


        dfs(0, s, new ArrayList<>(), res);


        return res;
    }


    private void dfs(
        int start,
        String s,
        List<String> path,
        List<List<String>> res
    ) {


        // We have partitioned the entire string
        if (start == s.length()) {


            res.add(new ArrayList<>(path));


            return;
        }


        // Try every possible ending position
        for (int end = start; end < s.length(); end++) {


            // Check whether s[start...end] is palindrome
            if (isPalindrome(s, start, end)) {


                // Choose
                path.add(s.substring(start, end + 1));


                // Explore
                dfs(end + 1, s, path, res);


                // Undo / Backtrack
                path.remove(path.size() - 1);
            }
        }
    }


    private boolean isPalindrome(String s, int l, int r) {


        while (l < r) {


            if (s.charAt(l++) != s.charAt(r--)) {
                return false;
            }
        }


        return true;
    }
}

⏱️ Complexity

Let n = s.length().

There can be up to:

2^(n-1)

different ways to partition a string because there are n-1 gaps and each gap can either be:

cut

or

not cut

For each candidate substring, isPalindrome() can take O(n).

Therefore, a commonly stated upper bound for this implementation is:

Time:  O(2^n × n²)
Space: O(n)

The O(n) auxiliary space comes from:

recursion depth
current path

However, the output itself can be exponential, so including the returned result storage, total space is larger:

Output space: O(2^n × n)
⭐ Key Pattern to Remember

This problem is a classic:

Backtracking + Validity Check

The general template is:

for (every possible choice) {


    if (choice is valid) {


        // choose
        path.add(choice);


        // explore
        dfs(next);


        // undo
        path.remove(path.size() - 1);
    }
}

For this problem:

Choice       → substring s[start...end]
Validity     → is it a palindrome?
Next state   → end + 1
Backtrack    → remove substring

So the core idea is:

Try every possible substring
          ↓
   Is it palindrome?
      ↙        ↘
    YES         NO
     ↓           ↓
   choose      skip
     ↓
   recurse
     ↓
  backtrack
