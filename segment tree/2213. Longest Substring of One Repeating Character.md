2213. Longest Substring of One Repeating Character
Problem

You are given:

A string s
queryCharacters
queryIndices

For every query:

s[queryIndices[i]] = queryCharacters[i]

After each update, we need to find the longest substring consisting of only one repeated character.

Example
s = "babacc"

queryCharacters = "bcb"
queryIndices = [1,3,3]
Query 1

Update index 1:

babacc
 ↓
bbbacc

Longest repeating substring:

bbb

Answer:

3
Query 2

Update index 3:

bbbacc
   ↓
bbbccc

Longest repeating substring:

bbb
ccc

Answer:

3
Query 3

Update index 3 again:

bbbccc
   ↓
bbbbcc

Longest repeating substring:

bbbb

Answer:

4

Therefore:

[3, 3, 4]
Why Can't We Use Brute Force?

Suppose:

n = 100000
k = 100000

After every update, if we scan the entire string to find the longest repeating substring:

O(n)

per query.

Total:

O(n * k)

which can become:

10^10

This is too slow.

We need to efficiently update one position and determine the new global maximum.

This is a perfect Segment Tree problem.

Segment Tree Idea

For every segment of the string, we store enough information to combine it with another segment.

For each segment we store:

leftChar
rightChar
leftCount
rightCount
maxCount
length
Meaning
leftChar

Character at the leftmost position of this segment.

rightChar

Character at the rightmost position of this segment.

leftCount

Number of consecutive equal characters starting from the left.

Example:

"aaabbc"
leftChar = 'a'
leftCount = 3
rightCount

Number of consecutive equal characters ending at the right.

For:

"aaabbc"
rightChar = 'c'
rightCount = 1
maxCount

Longest repeating-character substring inside this segment.

For:

"aaabbc"
maxCount = 3
length

Length of the segment.

Why Do We Need leftCount and rightCount?

This is the most important part of the problem.

Consider two segments:

Left  = "aab"
Right = "baa"

Individually:

Left.max = 2
Right.max = 2

But when combined:

"aab" + "baa"
     ↓
"aabbaa"

At the boundary:

b | b

The two bs combine.

So the repeating sequence crossing the boundary has length:

left.rightCount + right.leftCount
= 1 + 1
= 2

Therefore, while merging two nodes, we need:

left.rightCount
right.leftCount
Merge Logic

Suppose:

L = left child
R = right child

Initially:

parent.leftChar = L.leftChar;
parent.rightChar = R.rightChar;
parent.length = L.length + R.length;

The maximum can already exist completely inside either child:

parent.maxCount = Math.max(
    L.maxCount,
    R.maxCount
);
Boundary Characters Are Equal

If:

L.rightChar == R.leftChar

then a repeating sequence can cross the boundary.

Its length is:

L.rightCount + R.leftCount

So:

parent.maxCount = Math.max(
    parent.maxCount,
    L.rightCount + R.leftCount
);
Updating leftCount

Suppose:

Left  = "aaa"
Right = "aab"

Combined:

"aaaaab"

The entire left segment consists of a.

Therefore the prefix of the parent extends into the right segment:

parent.leftCount =
    left.length + right.leftCount

So we check:

if (left.leftCount == left.length) {
    parent.leftCount =
        left.length + right.leftCount;
}
Updating rightCount

Similarly, if the entire right segment consists of the same character:

Left  = "baa"
Right = "aaa"

Combined:

"baaaaa"

The suffix extends into the left segment.

Therefore:

if (right.rightCount == right.length) {
    parent.rightCount =
        right.length + left.rightCount;
}
Segment Tree Structure

For:

s = "babacc"

The segment tree recursively divides the string:

                [0..5]
               /     \
           [0..2]    [3..5]
           /   \      /   \
        [0..1] [2]  [3..4] [5]

Each node summarizes its entire segment.

The root therefore contains:

tree[0].maxCount

which is exactly the answer for the entire string.

Point Update

A query only changes one character.

For example:

s = "babacc"

index = 1
newChar = 'b'

Only the leaf representing index 1 changes.

Then we recalculate all its ancestors:

leaf
 ↓
parent
 ↓
parent
 ↓
root

This takes:

O(log n)

instead of scanning the entire string.

Code
class Solution {

    class Node {
        char leftChar;
        char rightChar;

        int leftCount;
        int rightCount;

        int maxCount;
        int length;

        Node(char leftChar, char rightChar,
             int leftCount, int rightCount,
             int maxCount, int length) {

            this.leftChar = leftChar;
            this.rightChar = rightChar;

            this.leftCount = leftCount;
            this.rightCount = rightCount;

            this.maxCount = maxCount;
            this.length = length;
        }
    }

    Node[] tree;
    char[] arr;

    public int[] longestRepeating(
            String s,
            String queryCharacters,
            int[] queryIndices) {

        int n = s.length();

        arr = s.toCharArray();

        tree = new Node[4 * n];

        // Build the segment tree
        build(0, 0, n - 1);

        int k = queryIndices.length;
        int[] ans = new int[k];

        for (int i = 0; i < k; i++) {

            int index = queryIndices[i];
            char ch = queryCharacters.charAt(i);

            // Update the actual string
            arr[index] = ch;

            // Update segment tree
            update(0, 0, n - 1, index);

            // Root contains answer for entire string
            ans[i] = tree[0].maxCount;
        }

        return ans;
    }

    // Build Segment Tree
    private void build(int node, int left, int right) {

        // Leaf node
        if (left == right) {

            char ch = arr[left];

            tree[node] = new Node(
                ch,
                ch,
                1,
                1,
                1,
                1
            );

            return;
        }

        int mid = left + (right - left) / 2;

        build(2 * node + 1, left, mid);
        build(2 * node + 2, mid + 1, right);

        tree[node] = merge(
            tree[2 * node + 1],
            tree[2 * node + 2]
        );
    }

    // Merge two segment tree nodes
    private Node merge(Node left, Node right) {

        Node parent = new Node(
            left.leftChar,
            right.rightChar,
            0,
            0,
            0,
            left.length + right.length
        );

        // Initially inherit prefix/suffix information
        parent.leftCount = left.leftCount;
        parent.rightCount = right.rightCount;

        // Maximum completely inside either child
        parent.maxCount = Math.max(
            left.maxCount,
            right.maxCount
        );

        // Boundary characters are equal
        if (left.rightChar == right.leftChar) {

            // Repeating sequence crossing the boundary
            parent.maxCount = Math.max(
                parent.maxCount,
                left.rightCount + right.leftCount
            );

            // Entire left segment has one character
            if (left.leftCount == left.length) {

                parent.leftCount =
                    left.length + right.leftCount;
            }

            // Entire right segment has one character
            if (right.rightCount == right.length) {

                parent.rightCount =
                    right.length + left.rightCount;
            }
        }

        return parent;
    }

    // Point update
    private void update(
            int node,
            int left,
            int right,
            int index) {

        // Leaf node
        if (left == right) {

            char ch = arr[index];

            tree[node] = new Node(
                ch,
                ch,
                1,
                1,
                1,
                1
            );

            return;
        }

        int mid = left + (right - left) / 2;

        if (index <= mid) {

            update(
                2 * node + 1,
                left,
                mid,
                index
            );

        } else {

            update(
                2 * node + 2,
                mid + 1,
                right,
                index
            );
        }

        // Recalculate this node
        tree[node] = merge(
            tree[2 * node + 1],
            tree[2 * node + 2]
        );
    }
}
Dry Run

Let's use:

s = "babacc"

First query:

queryCharacters = "b"
queryIndices = [1]

We change:

s[1] = 'b'

So:

"babacc"
   ↓
"bbbacc"

The segment tree updates only the path containing index 1.

The root now stores:

leftChar  = 'b'
rightChar = 'c'
maxCount  = 3

Therefore:

answer = 3
Second Query
queryCharacters = "c"
queryIndices = [3]

Update:

"bbbacc"
    ↓
"bbbccc"

Now:

bbb | ccc

The root's maxCount becomes:

3

Answer:

3
Third Query
queryCharacters = "b"
queryIndices = [3]

Update:

"bbbccc"
    ↓
"bbbbcc"

Now the longest repeating substring is:

bbbb

The root contains:

maxCount = 4

Answer:

4

Final:

[3, 3, 4]
Complexity

Let:

n = s.length()
k = number of queries
Building the Segment Tree

Every position is processed once:

O(n)
Each Query

Only one path from leaf to root is updated:

O(log n)

For k queries:

O(k log n)
Total Time
O(n + k log n)
Space

The segment tree contains approximately 4n nodes:

O(n)
Key Segment Tree Pattern

This problem is a very important example of what to store in a segment tree.

You don't always store just:

sum
min
max

Instead, ask:

What information from the left and right segments is necessary to calculate the answer for their combined segment?

Here we store:

┌──────────────────────────┐
│ leftChar                 │
│ rightChar                │
│ leftCount                │
│ rightCount               │
│ maxCount                 │
│ length                   │
└──────────────────────────┘

The most important part is:

left.rightChar == right.leftChar

because then:

left.rightCount + right.leftCount

can create a longer repeating substring crossing the boundary.

Pattern:

Point Update
     ↓
Update one leaf
     ↓
Merge ancestors
     ↓
Root stores global answer

This is why the solution handles 10^5 updates efficiently.
