# 1552. Magnetic Force Between Two Balls

## 1. Problem

Given `position[]` representing basket positions and `m` balls, place the balls in different baskets such that the **minimum distance between any two balls is as large as possible**.

Return this maximum possible minimum distance.

Example:

```text
position = [1,2,3,4,7], m = 3
```

Place balls at:

```text
1, 4, 7
```

Distances:

```text
3, 3, 6
```

Minimum = `3`, so answer is `3`.

---

## 2. Approach / Intuition

This is a **Binary Search on Answer** problem.

First sort the positions:

```text
[1,2,3,4,7]
```

The answer lies between:

```text
0 → maxPosition - minPosition
```

For a candidate distance `mid`, we check:

> Can we place `m` balls such that every two consecutive balls are at least `mid` apart?

We greedily place each ball at the **earliest possible position**.

If we can place all `m` balls:

```text
mid is possible → try larger distance
```

Otherwise:

```text
mid is not possible → try smaller distance
```

### Why Greedy Works

After placing a ball, choosing the earliest possible basket leaves the maximum remaining space for the other balls.

---

## 3. Java Code

```java
import java.util.*;

class Solution {

    private boolean can(int[] arr, int mid, int k) {

        int cnt = 1;
        int last = arr[0];

        for (int i = 1; i < arr.length; i++) {

            if (arr[i] - last >= mid) {

                cnt++;
                last = arr[i];

                if (cnt == k) {
                    return true;
                }
            }
        }

        return false;
    }

    public int maxDistance(int[] position, int m) {

        Arrays.sort(position);

        int n = position.length;

        int l = 0;
        int h = position[n - 1] - position[0];

        int ans = 0;

        while (l <= h) {

            int mid = l + (h - l) / 2;

            if (can(position, mid, m)) {

                ans = mid;
                l = mid + 1;

            } else {

                h = mid - 1;
            }
        }

        return ans;
    }
}
```

## 4. Dry Run

```text
position = [1,2,3,4,7]
m = 3
```

Search range:

```text
low = 0
high = 6
```

### `mid = 3`

Try placing balls at least `3` apart:

```text
1 → 4 → 7
```

We successfully place 3 balls.

So:

```text
ans = 3
low = 4
```

### `mid = 5`

Try:

```text
1 → 7
```

Only 2 balls can be placed.

So `5` is impossible.

```text
high = 4
```

### `mid = 4`

Try:

```text
1 → 7
```

Again only 2 balls.

So:

```text
high = 3
```

Binary search ends.

Answer:

```text
3
```

## 5. Time & Space Complexity

Sorting:

```text
O(n log n)
```

Binary search performs `O(log(maxPosition - minPosition))` checks, and each check takes `O(n)`.

### Time

```text
O(n log n + n log(maxPosition - minPosition))
```

### Space

```text
O(1)
```

excluding the sorting implementation's internal space.

---

## 6. Key Takeaways

* This is **Binary Search on Answer**.
* Sort the positions first.
* `can(mid)` checks whether distance `mid` is achievable.
* Use a **greedy strategy**: always place the next ball at the earliest valid position.
* If `mid` works, search right for a larger answer.
* If `mid` doesn't work, search left.

```text
Sort
  ↓
Binary Search on minimum distance
  ↓
Greedy feasibility check
  ↓
Maximum possible minimum distance
```
