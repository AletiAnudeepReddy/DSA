# 3116. Kth Smallest Amount With Single Denomination Combination

## 1. Problem

Given `coins`, each coin can independently generate its multiples:

```text
coin = 3 → 3, 6, 9, 12, ...
coin = 5 → 5, 10, 15, 20, ...
```

We **cannot combine different denominations**.

We need to find the **kth smallest distinct amount** that can be generated.

Example:

```text
coins = [5, 2], k = 7
```

Amounts:

```text
2, 4, 5, 6, 8, 10, 12, ...
```

Answer:

```text
12
```

---

## 2. Approach / Intuition

This solution uses:

> **Binary Search + Inclusion-Exclusion + LCM**

### Step 1: Remove redundant coins

If:

```text
coins = [3, 6, 9]
```

Every multiple of `6` is also a multiple of `3`, and every multiple of `9` is also a multiple of `3`.

So only `3` is necessary.

We remove a coin if a previously kept coin divides it.

---

### Step 2: Binary Search the Answer

For a value `x`, we need to know:

> How many distinct amounts `<= x` can be generated?

For one coin `c`:

```text
x / c
```

multiples exist.

For multiple coins, simply adding these counts causes duplicates.

Example:

```text
coins = [2, 3]
x = 6
```

Multiples of `2`:

```text
2, 4, 6
```

Multiples of `3`:

```text
3, 6
```

`6` is counted twice.

So we use **Inclusion-Exclusion**.

For two coins:

```text
count = x/2 + x/3 - x/lcm(2,3)
```

For more coins, we consider every subset:

```text
Odd number of coins  → add
Even number of coins → subtract
```

If:

```text
count(x) >= k
```

then the kth amount is `<= x`, so search left.

Otherwise search right.

---

## 3. Java Code

```java
import java.util.*;

class Solution {

    public long findKthSmallest(int[] coins, int k) {

        Arrays.sort(coins);

        // Remove redundant coins
        List<Integer> ls = new ArrayList<>();

        for (int coin : coins) {

            boolean redundant = false;

            for (int x : ls) {
                if (coin % x == 0) {
                    redundant = true;
                    break;
                }
            }

            if (!redundant) {
                ls.add(coin);
            }
        }

        int n = ls.size();

        long low = 1;
        long high = (long) ls.get(0) * k;

        while (low < high) {

            long mid = low + (high - low) / 2;

            if (count(mid, ls, n) >= k) {
                high = mid;
            } else {
                low = mid + 1;
            }
        }

        return low;
    }

    private long count(long x, List<Integer> coins, int n) {

        long result = 0;

        // Try every non-empty subset
        for (int mask = 1; mask < (1 << n); mask++) {

            long lcm = 1;
            int bits = 0;

            for (int i = 0; i < n; i++) {

                if ((mask & (1 << i)) != 0) {

                    bits++;

                    long gcd = gcd(lcm, coins.get(i));

                    lcm = (lcm / gcd) * coins.get(i);

                    if (lcm > x) {
                        break;
                    }
                }
            }

            if (lcm > x) {
                continue;
            }

            long multiples = x / lcm;

            if (bits % 2 == 1) {
                result += multiples;
            } else {
                result -= multiples;
            }
        }

        return result;
    }

    private long gcd(long a, long b) {

        while (b != 0) {

            long temp = a % b;
            a = b;
            b = temp;
        }

        return a;
    }
}
```

## 4. Dry Run

```text
coins = [2, 5]
k = 7
```

Amounts:

```text
2, 4, 5, 6, 8, 10, 12, ...
```

We binary search for the smallest `x` having at least `7` valid amounts.

Suppose:

```text
x = 12
```

Multiples of `2`:

```text
12 / 2 = 6
```

Multiples of `5`:

```text
12 / 5 = 2
```

Both sets overlap at multiples of:

```text
LCM(2,5) = 10
```

So:

```text
count(12)
= 6 + 2 - 1
= 7
```

Therefore `12` contains at least 7 valid amounts.

The 7 amounts are:

```text
2, 4, 5, 6, 8, 10, 12
```

So the answer is:

```text
12
```

---

## 5. Time & Space Complexity

Let `n = coins.length`.

There are at most `2^n` subsets, and:

```text
n <= 15
```

For each binary-search value, we process all subsets.

### Time

```text
O(n log n + log(k * minCoin) × 2^n × n)
```

With `n <= 15`, this is feasible.

### Space

```text
O(n)
```

excluding the recursion-free temporary variables.

---

## 6. Key Takeaways

* **Binary Search on Answer** finds the kth smallest value.
* `count(x)` tells how many distinct amounts are `<= x`.
* **Inclusion-Exclusion** prevents duplicate multiples from being counted.
* `LCM` finds numbers divisible by multiple denominations.
* Remove coins divisible by another smaller coin to reduce the number of subsets.
* Since `n <= 15`, enumerating `2^n` subsets is practical.

```text
Remove redundant coins
        ↓
Binary Search answer
        ↓
Count multiples using Inclusion-Exclusion
        ↓
Use LCM for intersections
        ↓
Find smallest x with count(x) >= k
```
