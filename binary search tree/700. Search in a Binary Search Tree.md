# 700. Search in a Binary Search Tree

**Difficulty:** Easy  
**Topic:** Binary Search Tree (BST)

---

## Intuition

A Binary Search Tree follows the property:

- Left subtree contains values **smaller** than the current node.
- Right subtree contains values **greater** than the current node.

Instead of traversing the entire tree, we can use this property:

- If `val < root.val` → search in the **left subtree**.
- If `val > root.val` → search in the **right subtree**.
- If `val == root.val` → node found.

This reduces the search to a single path from the root.

---

## Approach (Iterative)

- Start from the root.
- While the current node is not `null`:
  - If the current node contains the target value, return it.
  - If the target is smaller, move to the left child.
  - Otherwise, move to the right child.
- If the loop ends, the value is not present, so return `null`.

---

## Algorithm

1. Initialize `root` as the current node.
2. While `root != null`:
   - If `root.val == val`, return `root`.
   - If `val < root.val`, move to `root.left`.
   - Else move to `root.right`.
3. Return `null` if the value is not found.

---

## Code (Java)

```java
class Solution {
    public TreeNode searchBST(TreeNode root, int val) {
        while (root != null && root.val != val) {
            root = (val < root.val) ? root.left : root.right;
        }
        return root;
    }
}
```

---

## Complexity Analysis

- **Time Complexity:** `O(H)`
  - `H` = Height of the BST.
  - Balanced BST: **O(log n)**
  - Skewed BST: **O(n)**

- **Space Complexity:** `O(1)`
  - No extra space is used.

---

## Key Takeaways

- Utilize the **BST property** to avoid traversing unnecessary nodes.
- Only one path from the root is explored.
- Iterative solution is more space-efficient than recursion.
