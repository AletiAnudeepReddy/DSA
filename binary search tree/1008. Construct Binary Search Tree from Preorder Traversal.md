# 1008. Construct Binary Search Tree from Preorder Traversal

**Difficulty:** Medium  
**Topics:** Binary Search Tree, Binary Tree, Divide and Conquer, Recursion

---

## Problem Statement

Given an integer array `preorder`, which represents the preorder traversal of a Binary Search Tree (BST), construct the BST and return its root.

A preorder traversal visits nodes in the order:

- Root
- Left Subtree
- Right Subtree

The constructed tree must satisfy all BST properties.

---

## Approach: Recursive Construction with Upper Bound

### Intuition

A preorder traversal always visits nodes in this order:

```
Root → Left → Right
```

In a BST:

- Every value in the left subtree is **less than the root**
- Every value in the right subtree is **greater than the root**

Instead of searching for where the left subtree ends (which would take extra time), we maintain an **upper bound** for every recursive call.

At every step:

- The current preorder element becomes the root.
- Build the left subtree with an upper bound equal to the root value.
- Build the right subtree with the current upper bound.
- If the current value exceeds the bound, it does not belong to this subtree, so return `null`.

Using a single index that moves forward through the preorder array ensures every element is processed exactly once.

---

## Algorithm

1. Maintain a global/current index in the preorder array.
2. If the index reaches the end of the array, return `null`.
3. If the current value is greater than the allowed upper bound, return `null`.
4. Create the root using the current preorder value.
5. Increment the index.
6. Construct the left subtree using the root value as the new upper bound.
7. Construct the right subtree using the previous upper bound.
8. Return the constructed root.

## Java Solution

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */

class Solution {

    public TreeNode bstFromPreorder(int[] preorder) {
        return build(preorder, Integer.MAX_VALUE, new int[]{0});
    }

    private TreeNode build(int[] preorder, int bound, int[] index) {

        if (index[0] == preorder.length || preorder[index[0]] > bound) {
            return null;
        }

        TreeNode root = new TreeNode(preorder[index[0]++]);

        root.left = build(preorder, root.val, index);
        root.right = build(preorder, bound, index);

        return root;
    }
}
```

---

## Why does the Bound work?

Suppose we are constructing the subtree rooted at **5**.

```
      8
     /
    5
```

Every node in this subtree must satisfy

```
value < 8
```

Therefore the upper bound is **8**.

When constructing the left child of 5:

```
value < 5
```

So the bound becomes **5**.

When constructing the right child of 5:

```
5 < value < 8
```

The recursive calls naturally enforce these limits using only the upper bound.

Whenever a value exceeds the current bound, we know it belongs to an ancestor's right subtree, so we stop building the current subtree.

---

## Complexity Analysis

### Time Complexity

```
O(n)
```

- Every preorder element is processed exactly once.

### Space Complexity

```
O(h)
```

where **h** is the height of the BST due to recursion.

- Worst case: **O(n)** (skewed tree)
- Balanced BST: **O(log n)**

---

## Key Takeaways

- Preorder always gives the root first.
- BST properties eliminate the need to search for subtree boundaries.
- An upper bound determines whether a node belongs to the current subtree.
- Each node is visited exactly once, giving an optimal **O(n)** solution.
- This is one of the most elegant recursive BST construction techniques and is frequently asked in interviews.
