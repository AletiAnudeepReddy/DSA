# 701. Insert into a Binary Search Tree

**Difficulty:** Medium  
**Topic:** Binary Search Tree (BST)

---

## Intuition

A Binary Search Tree follows the property:

- Left subtree contains values **smaller** than the current node.
- Right subtree contains values **greater** than the current node.

To insert a new value:

- Traverse the tree just like searching for the value.
- When a `null` position is reached, insert the new node there.
- Since the value is guaranteed to be unique, we don't need to handle duplicates.

---

## Approach (Iterative)

- If the tree is empty, create a new node and return it.
- Start from the root.
- Traverse the tree:
  - If `val` is greater than the current node, move to the right.
    - If the right child is `null`, insert the new node there.
  - Otherwise, move to the left.
    - If the left child is `null`, insert the new node there.
- Return the original root.

---

## Algorithm

1. If `root == null`, return `new TreeNode(val)`.
2. Initialize `curr = root`.
3. Traverse until insertion:
   - If `val > curr.val`:
     - If `curr.right` exists, move right.
     - Otherwise insert the new node as the right child.
   - Else:
     - If `curr.left` exists, move left.
     - Otherwise insert the new node as the left child.
4. Return the original root.

---

## Code (Java)

```java
class Solution {
    public TreeNode insertIntoBST(TreeNode root, int val) {
        if (root == null) {
            return new TreeNode(val);
        }

        TreeNode curr = root;

        while (true) {
            if (curr.val <= val) {
                if (curr.right != null) {
                    curr = curr.right;
                } else {
                    curr.right = new TreeNode(val);
                    break;
                }
            } else {
                if (curr.left != null) {
                    curr = curr.left;
                } else {
                    curr.left = new TreeNode(val);
                    break;
                }
            }
        }

        return root;
    }
}
```

---

## Complexity Analysis

- **Time Complexity:** `O(H)`
  - `H` = Height of the BST.
  - Balanced BST: **O(log n)**
  - Skewed BST: **O(n)**

- **Space Complexity:** `O(1)`
  - Iterative solution uses constant extra space.

---

## Key Takeaways

- Traverse the BST using its ordering property.
- Insert the node at the first available `null` position.
- No tree restructuring is needed because BST insertion naturally preserves the BST property.
- Iterative approach avoids recursion stack space.
