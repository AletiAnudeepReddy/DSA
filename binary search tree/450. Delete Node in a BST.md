# 450. Delete Node in a BST

**Difficulty:** Medium  
**Topic:** Binary Search Tree (BST)

---

## Intuition

Deleting a node from a BST is slightly more involved than insertion because we must preserve the BST property.

There are **three possible cases**:

### Case 1: Node has no left child
Return its right child.

```
    5
     \
      8

Delete 5

    8
```

---

### Case 2: Node has no right child
Return its left child.

```
      5
     /
    3

Delete 5

    3
```

---

### Case 3: Node has both children

```
       5
      / \
     3   8
    / \
   2   4
```

We cannot simply delete `5`.

Steps:

- Save the right subtree.
- Find the **rightmost node** in the left subtree (Inorder Predecessor).
- Attach the saved right subtree to that node.
- Return the left subtree as the new root.

After deletion:

```
       3
      / \
     2   4
          \
           8
```

The BST property is preserved.

---

## Approach

1. Search for the node having the given key.
2. If the node is the root, directly delete it using the helper function.
3. Otherwise, search until its parent is found.
4. Replace the parent's child with the subtree returned by the helper.
5. Return the original root.

The helper function handles the three deletion cases.

---

## Algorithm

### Searching

- If root is null, return null.
- If root itself contains the key, return `helper(root)`.
- Otherwise keep moving left or right based on BST property.
- Once the parent of the node is found, delete that child using helper.

### Helper

- If left child is null → return right child.
- If right child is null → return left child.
- Otherwise:
  - Save right subtree.
  - Find the rightmost node in left subtree.
  - Connect saved right subtree there.
  - Return left subtree.

---

## Code (Java)

```java
class Solution {

    public TreeNode deleteNode(TreeNode root, int key) {

        if (root == null) {
            return null;
        }

        if (root.val == key) {
            return helper(root);
        }

        TreeNode dummy = root;

        while (root != null) {

            if (key < root.val) {

                if (root.left != null && root.left.val == key) {
                    root.left = helper(root.left);
                    break;
                }

                root = root.left;

            } else {

                if (root.right != null && root.right.val == key) {
                    root.right = helper(root.right);
                    break;
                }

                root = root.right;
            }
        }

        return dummy;
    }

    private TreeNode helper(TreeNode root) {

        if (root.left == null) {
            return root.right;
        }

        if (root.right == null) {
            return root.left;
        }

        TreeNode rightChild = root.right;
        TreeNode lastRight = findLastRight(root.left);

        lastRight.right = rightChild;

        return root.left;
    }

    private TreeNode findLastRight(TreeNode root) {

        while (root.right != null) {
            root = root.right;
        }

        return root;
    }
}
```

## Complexity Analysis

- **Time Complexity:** `O(H)`
  - Searching the node: `O(H)`
  - Finding the predecessor: `O(H)`
  - Overall: `O(H)`

- **Space Complexity:** `O(1)`
  - Iterative solution with constant extra space.

---

## Key Takeaways

- BST deletion has **3 cases**:
  - No left child
  - No right child
  - Both children
- For the third case, attach the right subtree to the **rightmost node of the left subtree** (inorder predecessor).
- The BST property remains intact after deletion.
- Overall complexity depends only on the tree height.
class Solution {
    public TreeNode deleteNode(TreeNode root, int val) {
        if (root == null) {
            return null;
        }
        
        if (val < root.val) {
            root.left = deleteNode(root.left, val);
        } else if (val > root.val) {
            root.right = deleteNode(root.right, val);
        } else {
            if (root.left == null) {
                return root.right;
            } else if (root.right == null) {
                return root.left;
            } else {
                TreeNode successor = findMin(root.right);
                root.val = successor.val;
                root.right = deleteNode(root.right, successor.val);
            }
        }
        
        return root;
    }
    private TreeNode findMin(TreeNode root) {
        while (root.left != null) {
            root = root.left;
        }
        return root;
    }
}
