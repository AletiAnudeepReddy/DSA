# 99. Recover Binary Search Tree

**Difficulty:** Medium  
**Topic:** Binary Search Tree, Inorder Traversal, DFS

## Problem Statement

You are given the root of a Binary Search Tree (BST), where the values of exactly **two nodes have been swapped** by mistake.

Recover the tree **without changing its structure**.

---

### Example

**Input**

```
        1
       /
      3
       \
        2
```

**Output**

```
        3
       /
      1
       \
        2
```

---

# Intuition

A **BST's inorder traversal is always sorted**.

Example of a valid BST:

```
        4
      /   \
     2     6
    / \   / \
   1  3  5   7

Inorder:

1 2 3 4 5 6 7
```

If two nodes are swapped, the inorder traversal is no longer sorted.

Example:

```
Original:

1 2 3 4 5 6 7

Swap 3 and 6

1 2 6 4 5 3 7
```

Notice where the ordering breaks:

```
6 > 4   ❌
5 > 3   ❌
```

We simply need to identify these misplaced nodes and swap them back.

---

# Key Observation

While doing inorder traversal, every previous node should satisfy:

```
prev.val < current.val
```

If

```
prev.val > current.val
```

then an inversion has occurred.

There are two possible cases.

---

# Case 1: Swapped Nodes are Adjacent

Example:

```
Original

1 2 3 4 5

Swap 2 and 3

1 3 2 4 5
```

Only one inversion exists.

```
3 > 2
```

We store

```
first = 3
middle = 2
```

Finally swap

```
first ↔ middle
```

---

# Case 2: Swapped Nodes are Not Adjacent

Example

```
Original

1 2 3 4 5 6 7

Swap 2 and 6

1 6 3 4 5 2 7
```

Inorder becomes

```
1 6 3 4 5 2 7
```

Violations:

```
6 > 3
5 > 2
```

First violation:

```
first = 6
middle = 3
```

Second violation:

```
last = 2
```

Finally swap

```
first ↔ last
```

BST becomes valid again.

---

# Algorithm

1. Perform inorder traversal.
2. Maintain a `prev` node.
3. Whenever `prev.val > current.val`:
   - First violation:
     - `first = prev`
     - `middle = current`
   - Second violation:
     - `last = current`
4. After traversal:
   - If `last` exists, swap `first` and `last`.
   - Otherwise, swap `first` and `middle`.
