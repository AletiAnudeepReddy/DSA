# 99. Recover Binary Search Tree

**Difficulty:** Medium  
**Topic:** Binary Search Tree, Inorder Traversal, DFS

## Problem Statement

You are given the root of a Binary Search Tree (BST), where the values of exactly **two nodes have been swapped** by mistake.

Recover the tree **without changing its structure**.

---

### Example

**Input**

```
        1
       /
      3
       \
        2
```

**Output**

```
        3
       /
      1
       \
        2
```

---

# Intuition

A **BST's inorder traversal is always sorted**.

Example of a valid BST:

```
        4
      /   \
     2     6
    / \   / \
   1  3  5   7

Inorder:

1 2 3 4 5 6 7
```

If two nodes are swapped, the inorder traversal is no longer sorted.

Example:

```
Original:

1 2 3 4 5 6 7

Swap 3 and 6

1 2 6 4 5 3 7
```

Notice where the ordering breaks:

```
6 > 4   ❌
5 > 3   ❌
```

We simply need to identify these misplaced nodes and swap them back.

---

# Key Observation

While doing inorder traversal, every previous node should satisfy:

```
prev.val < current.val
```

If

```
prev.val > current.val
```

then an inversion has occurred.

There are two possible cases.

---

# Case 1: Swapped Nodes are Adjacent

Example:

```
Original

1 2 3 4 5

Swap 2 and 3

1 3 2 4 5
```

Only one inversion exists.

```
3 > 2
```

We store

```
first = 3
middle = 2
```

Finally swap

```
first ↔ middle
```

---

# Case 2: Swapped Nodes are Not Adjacent

Example

```
Original

1 2 3 4 5 6 7

Swap 2 and 6

1 6 3 4 5 2 7
```

Inorder becomes

```
1 6 3 4 5 2 7
```

Violations:

```
6 > 3
5 > 2
```

First violation:

```
first = 6
middle = 3
```

Second violation:

```
last = 2
```

Finally swap

```
first ↔ last
```

BST becomes valid again.

---

# Algorithm

1. Perform inorder traversal.
2. Maintain a `prev` node.
3. Whenever `prev.val > current.val`:
   - First violation:
     - `first = prev`
     - `middle = current`
   - Second violation:
     - `last = current`
4. After traversal:
   - If `last` exists, swap `first` and `last`.
   - Otherwise, swap `first` and `middle`.

---

# Java Code

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */

class Solution {

    private TreeNode first;
    private TreeNode middle;
    private TreeNode last;
    private TreeNode prev;

    private void inorder(TreeNode root) {

        if (root == null)
            return;

        inorder(root.left);

        if (prev != null && prev.val > root.val) {

            if (first == null) {
                first = prev;
                middle = root;
            } else {
                last = root;
            }
        }

        prev = root;

        inorder(root.right);
    }

    public void recoverTree(TreeNode root) {

        first = middle = last = null;
        prev = new TreeNode(Integer.MIN_VALUE);

        inorder(root);

        if (first != null && last != null) {

            int temp = first.val;
            first.val = last.val;
            last.val = temp;

        } else if (first != null && middle != null) {

            int temp = first.val;
            first.val = middle.val;
            middle.val = temp;
        }
    }
}
```

```

```
        2

         3
```

```
1 2 3 4
```

# Why Does This Work?

The inorder traversal of a BST must always be sorted.

Swapping two nodes introduces either:

- **One inversion** (adjacent swap)
- **Two inversions** (non-adjacent swap)

By recording the first misplaced node and the last misplaced node encountered during inorder traversal, we can recover the original BST by swapping only their values.

---

# Complexity Analysis

- **Time Complexity:** O(n)
- **Space Complexity:** O(h)

where:

- `n` = number of nodes
- `h` = height of the tree (recursion stack)

Worst case:

- **Time:** O(n)
- **Space:** O(n) (skewed tree)

Balanced tree:

- **Space:** O(log n)

---

# Key Takeaways

- Inorder traversal of a BST is always sorted.
- Any violation (`prev.val > current.val`) indicates misplaced nodes.
- There are only **two possible cases**:
  - Adjacent swapped nodes → swap `first` and `middle`
  - Non-adjacent swapped nodes → swap `first` and `last`
- Only the **values** are swapped; the tree structure remains unchanged.
- This is the standard **O(n)** solution using inorder traversal.
