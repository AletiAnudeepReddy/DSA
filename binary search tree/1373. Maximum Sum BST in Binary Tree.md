# 1373. Maximum Sum BST in Binary Tree

**Difficulty:** Hard  
**Topic:** Binary Tree, Binary Search Tree, DFS, Postorder Traversal, Tree DP

## Problem Statement

Given the root of a binary tree, return the **maximum sum of all keys of any subtree that is also a Binary Search Tree (BST).**

A subtree is considered a BST if:

- The left subtree contains only values **less than** the current node.
- The right subtree contains only values **greater than** the current node.
- Both left and right subtrees are themselves BSTs.

If no valid BST exists, return `0`.

---

### Example

**Input**

```
           1
         /   \
        4     3
       / \   / \
      2   4 2   5
               / \
              4   6
```

**Output**

```
20
```

**Explanation**

The subtree rooted at **3** is a valid BST.

```
      3
     / \
    2   5
       / \
      4   6
```

Sum =

```
3 + 2 + 5 + 4 + 6 = 20
```

---

# Intuition

For every node, we need to determine:

- Is the subtree rooted at this node a BST?
- If yes, what is its sum?
- What is its minimum value?
- What is its maximum value?

These pieces of information are required by the parent to determine whether the parent's subtree is also a BST.

Therefore, we perform a **postorder traversal (Left → Right → Root)** so that both children's information is available before processing the parent.

---

# Information Returned by Every Node

For every subtree we return a `Node` containing:

- `minNode` → Minimum value in this subtree
- `maxNode` → Maximum value in this subtree
- `sum` → Sum of all nodes in this subtree

```java
class Node {
    int minNode;
    int maxNode;
    int sum;

    Node(int minNode, int maxNode, int sum) {
        this.minNode = minNode;
        this.maxNode = maxNode;
        this.sum = sum;
    }
}
```

---

# Base Case

For a null node:

```
min = +∞
max = -∞
sum = 0
```

```java
new Node(Integer.MAX_VALUE, Integer.MIN_VALUE, 0)
```

Why?

This ensures

```
left.max < root < right.min
```

always holds for leaf nodes.

---

# Valid BST Condition

Suppose

```
        root
       /    \
    left    right
```

Current subtree is a BST only if

```
left.maxNode < root.val < right.minNode
```

If true,

```
currentSum =
left.sum + right.sum + root.val
```

Update answer.

Return

```
min =
min(left.minNode, root.val)

max =
max(right.maxNode, root.val)

sum =
currentSum
```

---

# Invalid BST

If BST property fails,

```
return

min = -∞
max = +∞
sum = 0
```

```java
new Node(Integer.MIN_VALUE,
         Integer.MAX_VALUE,
         0);
```

Why?

Because the parent's condition

```
left.max < parent < right.min
```

will automatically fail.

Thus an invalid BST can never become part of a larger BST.

---

# Algorithm

1. Traverse left subtree.
2. Traverse right subtree.
3. Check if current subtree satisfies BST property.
4. If valid:
   - Calculate subtree sum.
   - Update global answer.
   - Return min, max and sum.
5. Otherwise return an invalid marker.

---

# Java Code

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */

class Node {

    int minNode;
    int maxNode;
    int sum;

    Node(int minNode, int maxNode, int sum) {
        this.minNode = minNode;
        this.maxNode = maxNode;
        this.sum = sum;
    }
}

class Solution {

    int ans = 0;

    private Node helper(TreeNode root) {

        if (root == null) {
            return new Node(
                Integer.MAX_VALUE,
                Integer.MIN_VALUE,
                0
            );
        }

        Node left = helper(root.left);
        Node right = helper(root.right);

        if (left.maxNode < root.val &&
            root.val < right.minNode) {

            int currSum =
                left.sum + right.sum + root.val;

            ans = Math.max(ans, currSum);

            return new Node(
                Math.min(left.minNode, root.val),
                Math.max(right.maxNode, root.val),
                currSum
            );
        }

        return new Node(
            Integer.MIN_VALUE,
            Integer.MAX_VALUE,
            0
        );
    }

    public int maxSumBST(TreeNode root) {

        helper(root);

        return ans;
    }
}
```

# Why Postorder Traversal?

The parent node needs information from both children before determining whether its own subtree is a BST.

Therefore the processing order is

```
Left

↓

Right

↓

Current Node
```

which is exactly **Postorder Traversal**.

---

# Complexity Analysis

- **Time Complexity:** O(n)
- **Space Complexity:** O(h)

where

- `n` = number of nodes
- `h` = height of the tree

Worst case (skewed tree):

- Space = O(n)

Balanced tree:

- Space = O(log n)

---

# Key Takeaways

- This is a classic **Tree DP** problem.
- Perform a **postorder traversal** so child information is available before processing the parent.
- Each recursive call returns:
  - Minimum value
  - Maximum value
  - Sum of the subtree
- A subtree is a BST only if:

```
left.max < root.val < right.min
```

- Invalid BSTs return sentinel values (`-∞`, `+∞`) so they can never be merged into a larger BST.
- The global answer is updated whenever a valid BST subtree is found.
