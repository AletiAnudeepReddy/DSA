# 98. Validate Binary Search Tree

**Difficulty:** Medium  
**Topic:** Binary Search Tree (BST), Inorder Traversal, DFS

---

# Approach 1: Inorder Traversal

## Intuition

A Binary Search Tree (BST) has a special property:

- An **Inorder Traversal (Left → Root → Right)** always produces the nodes in **strictly increasing order**.

So,

- Perform an inorder traversal.
- Store all node values in a list.
- If every element is smaller than the next element, the tree is a valid BST.
- Otherwise, it is not.

---

## Approach

1. Perform inorder traversal.
2. Store all visited nodes in a list.
3. Traverse the list once.
4. If any adjacent elements are not strictly increasing, return `false`.
5. Otherwise return `true`.

---

## Algorithm

1. Perform inorder traversal.
2. Store values in `ArrayList`.
3. Compare every adjacent pair.
4. If `list[i] >= list[i+1]`, return `false`.
5. Return `true`.

---

## Code (Java)

```java
class Solution {

    List<Integer> ls = new ArrayList<>();

    public boolean isValidBST(TreeNode root) {
        inorder(root);

        for (int i = 0; i < ls.size() - 1; i++) {
            if (ls.get(i + 1) <= ls.get(i)) {
                return false;
            }
        }

        return true;
    }

    public void inorder(TreeNode root) {

        if (root == null) {
            return;
        }

        inorder(root.left);
        ls.add(root.val);
        inorder(root.right);
    }
}
```

---

## Complexity Analysis

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)`

(Extra space is used to store the inorder traversal.)

# Approach 2: Recursive Range Check (Optimal)

## Intuition

Instead of checking only the parent-child relationship, every node must satisfy a **valid range**.

For every node:

- Left subtree values must lie in `(min, root.val)`
- Right subtree values must lie in `(root.val, max)`

Initially,

```
(-∞, +∞)
```

As we move down the tree, we keep narrowing the allowed range.

---

## Example

```
        5
       / \
      3   7
     / \   \
    2   4   8
```

Ranges become

```
5 : (-∞, +∞)

3 : (-∞, 5)

2 : (-∞, 3)

4 : (3, 5)

7 : (5, +∞)

8 : (7, +∞)
```

Every node lies within its valid range.

---

### Invalid Example

```
        5
       / \
      4   6
         / \
        3   7
```

Node **3** is in the right subtree of **5**.

Its valid range should be

```
(5, 6)
```

But

```
3 < 5
```

So the tree is **not** a BST.

Notice that simply comparing with its parent (`6`) is not enough. We must maintain the valid range from all ancestors.

---

## Approach

- Start with

```
(-∞, +∞)
```

- At every node:
  - If the node value is outside its allowed range, return `false`.
  - Recur on the left subtree with `(min, root.val)`.
  - Recur on the right subtree with `(root.val, max)`.

---

## Algorithm

1. Call the recursive function with

```
(Long.MIN_VALUE, Long.MAX_VALUE)
```

2. If the node is `null`, return `true`.
3. If

```
root.val <= min
or
root.val >= max
```

return `false`.
4. Recursively validate:
   - Left subtree with `(min, root.val)`
   - Right subtree with `(root.val, max)`
5. Return the logical AND of both recursive calls.

---

## Code (Java)

```java
class Solution {

    public boolean isValidBST(TreeNode root) {
        return isValid(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }

    public boolean isValid(TreeNode root, long minVal, long maxVal) {

        if (root == null) {
            return true;
        }

        if (root.val <= minVal || root.val >= maxVal) {
            return false;
        }

        return isValid(root.left, minVal, root.val)
                && isValid(root.right, root.val, maxVal);
    }
}
```

---

## Complexity Analysis

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(h)`

where `h` is the height of the tree (recursive stack).

- Balanced Tree → `O(log n)`
- Skewed Tree → `O(n)`

---

# Comparison

| Approach | Time | Space | Extra Data Structure |
|----------|------|--------|----------------------|
| Inorder Traversal | O(n) | O(n) | ArrayList |
| Range Check (Optimal) | O(n) | O(h) | No |

---

## Key Takeaways

- Inorder traversal of a BST must be **strictly increasing**.
- The inorder approach is simple but requires an extra list.
- The optimal solution validates every node using a **minimum and maximum allowed range**.
- Checking only the parent node is **not sufficient**; ancestor constraints must also be satisfied.
- The range-check approach is the preferred interview solution.
