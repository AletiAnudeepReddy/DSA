# 653. Two Sum IV - Input is a BST

**Difficulty:** Easy  
**Topic:** Binary Search Tree, Two Pointers, Stack, Iterator

## Problem Statement

Given the root of a Binary Search Tree (BST) and an integer `k`, return `true` if there exist two elements in the BST such that their sum is equal to `k`, otherwise return `false`.

### Example

**Input:**
```
root = [5,3,6,2,4,null,7], k = 9
```

**Output:**
```
true
```

**Explanation:**
The nodes `2` and `7` sum to `9`.

---

# Approach 1: BST Iterators + Two Pointers (Optimal)

## Intuition

Since an inorder traversal of a BST gives nodes in **sorted order**, we can simulate the classic **Two Sum in Sorted Array** problem.

Instead of storing the entire inorder traversal (which requires O(n) space), we create:

- One iterator that gives the **next smallest** element.
- One iterator that gives the **next largest** element.

Then we use the standard two-pointer technique.

This saves memory because each iterator only stores the path from the root to the current node.

---

## Algorithm

1. Create an inorder iterator (`left`) to get the smallest elements.
2. Create a reverse inorder iterator (`right`) to get the largest elements.
3. Initialize:
   - `i = left.next()`
   - `j = right.next()`
4. While `i < j`
   - If `i + j == k`, return `true`.
   - If sum is smaller than `k`, move the left iterator.
   - Otherwise, move the right iterator.
5. If pointers meet, return `false`.

---

## Java Code

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */

public class BSTiterator {
    private Stack<TreeNode> stack = new Stack<>();
    boolean reverse = true;

    public BSTiterator(TreeNode root, boolean isreverse) {
        reverse = isreverse;
        pushAll(root);
    }

    public boolean hasNext() {
        return !stack.isEmpty();
    }

    public int next() {
        TreeNode temp = stack.pop();

        if (!reverse) {
            pushAll(temp.right);
        } else {
            pushAll(temp.left);
        }

        return temp.val;
    }

    private void pushAll(TreeNode root) {
        while (root != null) {
            stack.push(root);

            if (reverse) {
                root = root.right;
            } else {
                root = root.left;
            }
        }
    }
}

class Solution {
    public boolean findTarget(TreeNode root, int k) {

        if (root == null)
            return false;

        BSTiterator left = new BSTiterator(root, false);
        BSTiterator right = new BSTiterator(root, true);

        int i = left.next();
        int j = right.next();

        while (i < j) {

            if (i + j == k) {
                return true;
            }

            else if (i + j < k) {
                i = left.next();
            }

            else {
                j = right.next();
            }
        }

        return false;
    }
}
```

## Complexity Analysis

- **Time Complexity:** O(n)
- **Space Complexity:** O(h)

where `h` is the height of the BST.

# Approach 2: Inorder Traversal + Two Pointers

## Intuition

Since inorder traversal of a BST is always sorted:

```
BST
        5
      /   \
     3     6
    / \     \
   2   4     7

↓

Inorder = [2,3,4,5,6,7]
```

Now the problem becomes identical to **Two Sum in a Sorted Array**.

Use two pointers:

- `left = 0`
- `right = n-1`

Move them exactly like the classic Two Sum problem.

---

## Algorithm

1. Perform inorder traversal.
2. Store nodes in an array/list.
3. Keep two pointers:
   - Left at beginning
   - Right at end
4. If sum equals `k`, return true.
5. If sum is smaller, move left.
6. Else move right.
7. If pointers cross, return false.

---

## Java Code

```java
class Solution {

    List<Integer> inorder = new ArrayList<>();

    public boolean findTarget(TreeNode root, int k) {

        dfs(root);

        int left = 0;
        int right = inorder.size() - 1;

        while (left < right) {

            int sum = inorder.get(left) + inorder.get(right);

            if (sum == k) {
                return true;
            }

            if (sum < k) {
                left++;
            } else {
                right--;
            }
        }

        return false;
    }

    private void dfs(TreeNode root) {

        if (root == null)
            return;

        dfs(root.left);
        inorder.add(root.val);
        dfs(root.right);
    }
}
```

---

## Complexity Analysis

- **Time Complexity:** O(n)
- **Space Complexity:** O(n)

because the entire inorder traversal is stored.

---

# Comparison

| Approach | Time | Space | Extra Data Structure |
|----------|------|-------|----------------------|
| BST Iterators + Two Pointers | O(n) | O(h) | Two stacks |
| Inorder + Two Pointers | O(n) | O(n) | Array/List |

---

# Key Takeaways

- Inorder traversal of a BST is always sorted.
- The iterator approach is essentially a space-optimized inorder traversal.
- Using two BST iterators allows solving the problem in **O(h)** auxiliary space instead of **O(n)**.
- This is one of the most elegant applications of **BST Iterators + Two Pointers**.
