# 101. Symmetric Tree

**Difficulty:** Easy  
**Topics:** Binary Tree, DFS, Recursion

---

# Problem Statement

Given the root of a binary tree, determine whether it is **symmetric around its center**.

A tree is symmetric if its **left subtree is the mirror image of its right subtree**.

---

# Intuition

Instead of comparing the tree with itself, compare:

- Left subtree
- Right subtree

For the tree to be symmetric:

- Root values must be equal.
- Left child of the first tree should match the right child of the second tree.
- Right child of the first tree should match the left child of the second tree.

This is exactly a **mirror comparison**.

---

# Mirror Property

Two trees are mirrors if:

```
Node Values are Equal

AND

Left of Tree 1 == Right of Tree 2

AND

Right of Tree 1 == Left of Tree 2
```

Recurrence

```
Mirror(t1, t2)

=

t1.val == t2.val

&&

Mirror(t1.left, t2.right)

&&

Mirror(t1.right, t2.left)
```

# Algorithm

1. If the tree is empty, return `true`.
2. Compare the left and right subtrees.
3. If both nodes are `null`, return `true`.
4. If only one node is `null`, return `false`.
5. Compare:
   - Current node values.
   - Left subtree of first tree with right subtree of second tree.
   - Right subtree of first tree with left subtree of second tree.
6. Return the final result.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(h)` *(Recursion Stack)*

Where:

- `n` = Number of nodes
- `h` = Height of the tree

---

## Java Solution

```java
class Solution {

    public boolean isSymmetric(TreeNode root) {

        if (root == null) {
            return true;
        }

        return isMirror(root.left, root.right);
    }

    private boolean isMirror(TreeNode t1, TreeNode t2) {

        if (t1 == null && t2 == null) {
            return true;
        }

        if (t1 == null || t2 == null) {
            return false;
        }

        return (t1.val == t2.val)
                && isMirror(t1.left, t2.right)
                && isMirror(t1.right, t2.left);
    }
}
```

# Same Tree vs Symmetric Tree

| Same Tree | Symmetric Tree |
|------------|----------------|
| Compare Left ↔ Left | Compare Left ↔ Right |
| Compare Right ↔ Right | Compare Right ↔ Left |
| Structures must be identical | Structures must be mirror images |

---

# Key Takeaways

- A tree is symmetric if its left and right subtrees are **mirror images**.
- Compare nodes in a **crosswise** manner:
  - Left ↔ Right
  - Right ↔ Left
- Base cases:
  - Both `null` → `true`
  - One `null` → `false`
- Every node is visited exactly once, giving an **`O(n)`** solution.
