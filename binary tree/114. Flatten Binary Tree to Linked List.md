# 114. Flatten Binary Tree to Linked List

**Difficulty:** Medium  
**Topics:** Binary Tree, DFS, Stack, Morris Traversal

---

# Problem Statement

Given the root of a binary tree, flatten it into a linked list **in-place**.

The linked list should:

- Use the same `TreeNode`.
- `left` pointer should always be `null`.
- `right` pointer should point to the next node.
- Follow the **Preorder Traversal** order.

```
Preorder = Root → Left → Right
```

---

# Approach 1: Using Stack (Preorder Traversal)

## Intuition

The flattened tree should follow **Preorder Traversal**.

So simply perform a preorder traversal using a stack.

For every node:

1. Push right child.
2. Push left child.
3. The next node on the stack is the next node in preorder.
4. Connect current node's `right` to that node.
5. Set `left = null`.

Since stack is **LIFO**, we push **right first**, then **left**, so that left is processed first.

---

# Algorithm

1. Push root into the stack.
2. While stack is not empty:
   - Pop the current node.
   - Push right child.
   - Push left child.
   - Connect current node's `right` to the top of the stack.
   - Set current node's `left` to `null`.
3. Continue until the stack becomes empty.

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)`

---

## Java Solution (Stack)

```java
class Solution {

    public void flatten(TreeNode root) {

        if (root == null)
            return;

        Stack<TreeNode> stack = new Stack<>();
        stack.push(root);

        while (!stack.isEmpty()) {

            TreeNode curr = stack.pop();

            if (curr.right != null)
                stack.push(curr.right);

            if (curr.left != null)
                stack.push(curr.left);

            if (!stack.isEmpty())
                curr.right = stack.peek();

            curr.left = null;
        }
    }
}
```

# Approach 2: Morris Traversal (Optimal)

## Intuition

Instead of using a stack, we modify the tree in-place.

For every node having a left subtree:

1. Find the **rightmost node** of its left subtree.
2. Attach the original right subtree to this rightmost node.
3. Move the left subtree to the right.
4. Set left pointer to `null`.
5. Move to the next right node.

This is similar to **Morris Traversal**, where we rewire pointers instead of using extra space.

---

# Why Find the Rightmost Node?

Suppose

```
        1
       / \
      2   5
     / \
    3   4
```

The preorder should be

```
1 → 2 → 3 → 4 → 5
```

If we simply move the left subtree to the right,

```
1
 \
 2
/ \
3 4
```

we lose the original right subtree (`5`).

Instead,

Find the **rightmost node** of the left subtree.

```
4
```

Attach

```
4 → 5
```

Now move the left subtree.

Result

```
1
 \
 2
/ \
3 4
     \
      5
```

Finally,

```
left = null
```

Continue the same process.

---

# Algorithm

For every node:

If left child exists:

- Find rightmost node of left subtree.
- Connect

```
rightmost.right = current.right
```

- Move

```
current.right = current.left
```

- Set

```
current.left = null
```

Move to

```
current.right
```

Repeat until the end.

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)`

---

## Java Solution (Morris Traversal)

```java
class Solution {

    public void flatten(TreeNode root) {

        TreeNode curr = root;

        while (curr != null) {

            if (curr.left != null) {

                TreeNode prev = curr.left;

                while (prev.right != null) {
                    prev = prev.right;
                }

                prev.right = curr.right;

                curr.right = curr.left;

                curr.left = null;
            }

            curr = curr.right;
        }
    }
}
```

|----------|------|-------|

---

# Key Takeaways

- The flattened tree must follow **Preorder Traversal**.
- **Stack approach** directly simulates preorder traversal.
- **Push right before left** because of LIFO order.
- **Morris Traversal** rewires pointers without extra memory.
- Morris Traversal is the **optimal solution** with **O(1)** extra space.
