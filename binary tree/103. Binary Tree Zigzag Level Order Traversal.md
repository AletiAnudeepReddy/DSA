# 103. Binary Tree Zigzag Level Order Traversal

**Difficulty:** Medium  
**Topics:** Binary Tree, BFS, Queue

---

# Problem Statement

Given the root of a binary tree, return its **zigzag level order traversal**.

The traversal should be:

- First level → **Left to Right**
- Second level → **Right to Left**
- Third level → **Left to Right**
- Continue alternating for every level.

---

# Intuition

This problem is an extension of **Level Order Traversal (LeetCode 102)**.

The only difference is that the order of elements changes at every level.

Instead of reversing each level after traversal, we can directly place every node at its correct position.

---

# Idea

Use **BFS (Queue)** to process the tree level by level.

For every level:

- Create an array of size equal to the number of nodes in that level.
- If traversing **Left → Right**, place values normally.
- If traversing **Right → Left**, place values from the end of the array.

After processing a level, simply flip the direction.

---

# Index Calculation

Suppose the current level contains **`sz`** nodes.

### Left to Right

Store normally.

```
Index = i
```

Example

```
Nodes

3  9  20

Indices

0  1   2
```

---

### Right to Left

Store from the opposite end.

```
Index = sz - (i + 1)
```

Example

```
Nodes

9   20

i

0   1

Indices

1   0
```

Stored array becomes

```
20  9
```

No reversing is required.

# Algorithm

1. If the tree is empty, return an empty list.
2. Perform **BFS** using a queue.
3. For each level:
   - Create an array of size `levelSize`.
   - Place nodes according to the current direction.
   - Add children to the queue.
4. Flip the traversal direction.
5. Add the current level to the answer.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)`

Where:

- `n` = Number of nodes

---

## Java Solution

```java
class Solution {

    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {

        List<List<Integer>> result = new ArrayList<>();

        if (root == null) {
            return result;
        }

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        boolean leftToRight = true;

        while (!queue.isEmpty()) {

            int size = queue.size();
            Integer[] level = new Integer[size];

            for (int i = 0; i < size; i++) {

                TreeNode node = queue.poll();

                int index = leftToRight
                        ? i
                        : size - i - 1;

                level[index] = node.val;

                if (node.left != null) {
                    queue.offer(node.left);
                }

                if (node.right != null) {
                    queue.offer(node.right);
                }
            }

            result.add(Arrays.asList(level));

            leftToRight = !leftToRight;
        }

        return result;
    }
}
```

# Key Takeaways

- This is an extension of **Level Order Traversal (BFS)**.
- Use a queue to process nodes level by level.
- Instead of reversing each level, place values directly at the correct index.
- Index calculation:
  - Left → Right: `i`
  - Right → Left: `size - i - 1`
- Toggle the traversal direction after every level.
- The solution runs in **`O(n)`** time with **`O(n)`** space.
