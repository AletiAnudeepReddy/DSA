# 222. Count Complete Tree Nodes

**Difficulty:** Easy  
**Topics:** Binary Tree, Complete Binary Tree, Recursion

---

# Problem Statement

Given the root of a **Complete Binary Tree**, return the total number of nodes.

A **Complete Binary Tree** is a tree where:

- Every level except the last is completely filled.
- The last level is filled from left to right.

The expected solution should run in **less than O(n)** time.

---

# Intuition

A **Complete Binary Tree** has a special property.

If the **leftmost height** and the **rightmost height** of a subtree are equal, then the subtree is a **Perfect Binary Tree**.

For a Perfect Binary Tree,

```
Number of Nodes = 2^(height+1) - 1
```

So instead of traversing every node, we can directly calculate its size.

If the heights are different, recursively count nodes in the left and right subtrees.

# Why Leftmost and Rightmost Heights?

To check whether a subtree is **perfect**, we only need to compare:

- Height obtained by moving completely left.
- Height obtained by moving completely right.

If both are equal,

```
The subtree is completely full.
```

Otherwise,

```
The subtree is incomplete.
```

# Formula for Perfect Binary Tree

If

```
Height = h
```

Then

```
Nodes = 2^(h+1) - 1
```

In Java,

```java
(2 << h) - 1
```

works because

```
2 << h

=

2^(h+1)
```

Example

```
h = 2

2 << 2

=

8

8 - 1

=

7
```

# Algorithm

1. If the root is `null`, return `0`.
2. Compute:
   - Leftmost height
   - Rightmost height
3. If both heights are equal:
   - Return `(2 << height) - 1`.
4. Otherwise:
   - Return

```
1 + count(left) + count(right)
```

---

## Complexity

### Height Calculation

```
O(log n)
```

performed at every recursive level.

### Overall

- **Time Complexity:** `O((log n)²)`
- **Space Complexity:** `O(log n)` *(Recursion Stack)*

---

## Java Solution

```java
class Solution {

    public int countNodes(TreeNode root) {

        if (root == null) {
            return 0;
        }

        int leftHeight = getLeftHeight(root);
        int rightHeight = getRightHeight(root);

        if (leftHeight == rightHeight) {
            return (2 << leftHeight) - 1;
        }

        return 1 + countNodes(root.left) + countNodes(root.right);
    }

    private int getLeftHeight(TreeNode root) {

        int height = 0;

        while (root.left != null) {
            height++;
            root = root.left;
        }

        return height;
    }

    private int getRightHeight(TreeNode root) {

        int height = 0;

        while (root.right != null) {
            height++;
            root = root.right;
        }

        return height;
    }
}
```

# Why is it Faster than O(n)?

A normal traversal visits every node.

Here,

- We calculate heights in `O(log n)`.
- If a subtree is perfect, we **do not traverse its nodes**.
- Only incomplete subtrees are explored recursively.

This reduces the overall complexity to

```
O((log n)²)
```

instead of

```
O(n)
```

---

# Key Takeaways

- A complete binary tree can contain **perfect subtrees**.
- Compare the **leftmost** and **rightmost** heights.
- Equal heights ⇒ Perfect Binary Tree ⇒ Use the formula directly.
- Different heights ⇒ Recursively count left and right subtrees.
- Achieves **`O((log n)²)`** time instead of **`O(n)`**.
