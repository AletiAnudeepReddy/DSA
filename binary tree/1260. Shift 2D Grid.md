# 1260. Shift 2D Grid

**Difficulty:** Easy  
**Topics:** Matrix, Simulation, Math

---

# Problem Statement

Given an `m x n` grid and an integer `k`, shift the grid `k` times.

In one shift:

- Each element moves one position to the right.
- The last element of a row moves to the first column of the next row.
- The last element of the grid moves to the first position of the grid.

Return the shifted grid.

---

# Intuition

Instead of performing **k shifts one by one**, think of the 2D grid as a **1D array**.

Every cell can be represented by a unique index.

```
2D Grid

1 2 3
4 5 6
7 8 9
```

Flatten it

```
1 2 3 4 5 6 7 8 9

Index

0 1 2 3 4 5 6 7 8
```

Now shifting by `k` simply means moving every element to

```
newIndex = (oldIndex + k) % totalElements
```

Finally, convert the new 1D index back into 2D coordinates.

---

# Mapping Formula

### Convert 2D → 1D

```
index = row * columns + col
```

### Shift

```
newIndex = (index + k) % (rows * columns)
```

### Convert 1D → 2D

```
newRow = newIndex / columns

newCol = newIndex % columns
```

# Algorithm

1. Compute the total number of elements.
2. Reduce `k` using modulo:
   ```
   k %= total
   ```
3. Create an empty answer matrix.
4. For every cell:
   - Convert `(row, col)` into a 1D index.
   - Compute the shifted index.
   - Convert it back into `(newRow, newCol)`.
   - Place the element in the new position.
5. Return the answer.

---

## Complexity

- **Time Complexity:** `O(m × n)`
- **Space Complexity:** `O(m × n)`

---

## Java Solution

```java
class Solution {

    public List<List<Integer>> shiftGrid(int[][] grid, int k) {

        int rows = grid.length;
        int cols = grid[0].length;

        int total = rows * cols;

        k %= total;

        List<List<Integer>> ans = new ArrayList<>();

        for (int i = 0; i < rows; i++) {
            List<Integer> row = new ArrayList<>();

            for (int j = 0; j < cols; j++) {
                row.add(0);
            }

            ans.add(row);
        }

        for (int i = 0; i < rows; i++) {

            for (int j = 0; j < cols; j++) {

                int index = i * cols + j;

                int newIndex = (index + k) % total;

                int newRow = newIndex / cols;
                int newCol = newIndex % cols;

                ans.get(newRow).set(newCol, grid[i][j]);
            }
        }

        return ans;
    }
}
```

# Key Takeaways

- Treat the **2D matrix as a virtual 1D array**.
- No need to simulate each shift individually.
- Use modulo to handle circular wrapping.
- Conversion formulas:
  - **2D → 1D:** `index = row * cols + col`
  - **1D → 2D:** `row = index / cols`, `col = index % cols`
- Runs in **`O(m × n)`** time.
