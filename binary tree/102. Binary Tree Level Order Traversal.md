# 102. Binary Tree Level Order Traversal

**Difficulty:** Medium  
**Topics:** Binary Tree, BFS, DFS, Queue, Recursion

---

# Problem Statement

Given the root of a binary tree, return the **level order traversal** of its nodes' values (from left to right, level by level).

---

# Approach 1: Breadth First Search (Queue)

## Intuition

Level order traversal naturally follows **Breadth First Search (BFS)**.

Use a queue to process nodes level by level.

- Insert the root into the queue.
- Process all nodes currently in the queue (one level).
- While processing a node, push its left and right children into the queue.
- Repeat until the queue becomes empty.

---

## Example

```
        3
       / \
      9   20
         /  \
        15   7
```

Initially

```
Queue

[3]
```

### Level 0

```
Process 3

Queue

[9,20]

Result

[[3]]
```

---

### Level 1

```
Process 9

Process 20

Queue

[15,7]

Result

[[3],
 [9,20]]
```

---

### Level 2

```
Process 15

Process 7

Queue

[]

Result

[[3],
 [9,20],
 [15,7]]
```

---

## Algorithm

1. Insert the root into the queue.
2. While the queue is not empty:
   - Store the current queue size (number of nodes in this level).
   - Process exactly those many nodes.
   - Add their children to the queue.
3. Store every level separately.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)` *(queue in the worst case)*

---

## Java Solution (BFS)

```java
class Solution {

    public List<List<Integer>> levelOrder(TreeNode root) {

        Queue<TreeNode> queue = new LinkedList<>();
        List<List<Integer>> result = new LinkedList<>();

        if (root == null) {
            return result;
        }

        queue.offer(root);

        while (!queue.isEmpty()) {

            int levelSize = queue.size();
            List<Integer> level = new LinkedList<>();

            for (int i = 0; i < levelSize; i++) {

                TreeNode node = queue.poll();

                level.add(node.val);

                if (node.left != null) {
                    queue.offer(node.left);
                }

                if (node.right != null) {
                    queue.offer(node.right);
                }
            }

            result.add(level);
        }

        return result;
    }
}
```

# Approach 2: DFS (Recursion)

## Intuition

Although this is a level-order traversal, we can also solve it using **Depth First Search (DFS)**.

Pass the current **level** during recursion.

Whenever we visit a node:

- If this level is encountered for the first time, create a new list.
- Add the node to its corresponding level.
- Recursively process the left and right children with `level + 1`.

---

## Example

```
helper(3,0)

↓

helper(9,1)

↓

helper(20,1)

↓

helper(15,2)

↓

helper(7,2)
```

Result

```
[
 [3],
 [9,20],
 [15,7]
]
```

---

## Algorithm

1. Start DFS from the root with level `0`.
2. If `level == result.size()`, create a new list.
3. Add the current node to its level.
4. Recurse on the left and right children with `level + 1`.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(h)` *(recursion stack, where `h` is the tree height)*

> **Note:** In the worst case (a skewed tree), the recursion stack can grow to `O(n)`. The result list itself stores all nodes in both approaches.

---

## Java Solution (DFS)

```java
class Solution {

    List<List<Integer>> result = new ArrayList<>();

    public List<List<Integer>> levelOrder(TreeNode root) {
        helper(root, 0);
        return result;
    }

    private void helper(TreeNode root, int level) {

        if (root == null) return;

        if (level == result.size()) {
            result.add(new ArrayList<>());
        }

        result.get(level).add(root.val);

        helper(root.left, level + 1);
        helper(root.right, level + 1);
    }
}
```

---

# BFS vs DFS

| BFS (Queue) | DFS (Recursion) |
|--------------|-----------------|
| Uses a queue | Uses recursion (call stack) |
| Processes nodes level by level | Traverses depth first while tracking the level |
| Natural solution for level order traversal | Alternative recursive solution |
| Space: `O(n)` (queue) | Space: `O(h)` (recursion stack) |

---

# Key Takeaways

- **BFS (Queue)** is the standard and most intuitive solution for level-order traversal.
- Process one level at a time using the current queue size.
- **DFS** also works by passing the current level during recursion.
- Whenever `level == result.size()`, create a new list for that level.
- Both approaches visit every node exactly once, giving **`O(n)`** time complexity.
