# 110. Balanced Binary Tree

**Difficulty:** Easy  
**Topics:** Binary Tree, DFS, Recursion

---

# Problem Statement

A binary tree is **height-balanced** if, for every node,

```
|Height(Left Subtree) - Height(Right Subtree)| ≤ 1
```

Return `true` if the given tree is balanced; otherwise, return `false`.

---

# Intuition

A straightforward approach is:

- Compute the height of the left subtree.
- Compute the height of the right subtree.
- Check if their difference is at most `1`.
- Repeat this for every node.

However, this repeatedly recalculates heights, leading to **O(n²)** time complexity.

A better approach is to compute the **height and balance check together** in a single DFS traversal.

---

# Optimized Idea

Instead of returning only the height,

- Return the **height** if the subtree is balanced.
- Return **`-1`** immediately if the subtree is unbalanced.

The value `-1` acts as a special marker indicating that an imbalance has already been found.

This allows us to stop further unnecessary computations.

---

## Recursive Relation

For every node:

1. Compute the height of the left subtree.
2. If the left subtree is unbalanced (`-1`), return `-1`.
3. Compute the height of the right subtree.
4. If the right subtree is unbalanced (`-1`), return `-1`.
5. If the height difference is greater than `1`, return `-1`.
6. Otherwise, return:

```
1 + max(leftHeight, rightHeight)
```

---

## Example 1 (Balanced)

```
        3
       / \
      9   20
         /  \
        15   7
```

Compute from the bottom:

```
Height(9)  = 1

Height(15) = 1

Height(7)  = 1
```

```
Height(20)

=

1 + max(1,1)

=

2
```

```
Height(3)

=

1 + max(1,2)

=

3
```

Every node satisfies

```
|Left - Right| ≤ 1
```

Answer

```
true
```

---

## Example 2 (Unbalanced)

```
        1
       /
      2
     /
    3
```

```
Height(3) = 1

Height(2) = 2

Height(1)

Left = 2

Right = 0

Difference = 2
```

Since

```
2 > 1
```

Return

```
-1
```

Final Answer

```
false
```

## Algorithm

1. If the node is `null`, return height `0`.
2. Recursively compute the left subtree height.
3. If it returns `-1`, propagate `-1`.
4. Recursively compute the right subtree height.
5. If it returns `-1`, propagate `-1`.
6. If the height difference exceeds `1`, return `-1`.
7. Otherwise, return the current subtree height.

Finally,

```
height(root) != -1
```

means the tree is balanced.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(h)` *(recursion stack)*

Where:

- `n` = Number of nodes
- `h` = Height of the tree

---

## Java Solution

```java
class Solution {

    public boolean isBalanced(TreeNode root) {
        return height(root) != -1;
    }

    private int height(TreeNode root) {

        if (root == null) {
            return 0;
        }

        int leftHeight = height(root.left);

        if (leftHeight == -1) {
            return -1;
        }

        int rightHeight = height(root.right);

        if (rightHeight == -1) {
            return -1;
        }

        if (Math.abs(leftHeight - rightHeight) > 1) {
            return -1;
        }

        return 1 + Math.max(leftHeight, rightHeight);
    }
}
```

# Key Takeaways

- A tree is balanced if, for **every node**:

  ```
  |Left Height - Right Height| ≤ 1
  ```

- Compute the height and balance check together in a **single DFS traversal**.
- Use **`-1` as a sentinel value** to indicate an unbalanced subtree.
- If any subtree returns `-1`, immediately propagate it upward without further processing.
- This optimization reduces the complexity from **`O(n²)`** (recomputing heights) to **`O(n)`**.
