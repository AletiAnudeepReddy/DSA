# 987. Vertical Order Traversal of a Binary Tree

**Difficulty:** Hard  
**Topics:** Binary Tree, BFS, TreeMap, Priority Queue

---

# Problem Statement

Given the root of a binary tree, return its **vertical order traversal**.

Each node has a position:

- Root → `(row = 0, col = 0)`
- Left Child → `(row + 1, col - 1)`
- Right Child → `(row + 1, col + 1)`

Return the nodes column by column from **leftmost to rightmost**.

If multiple nodes are in:

- the **same column**
- the **same row**

then sort them by **their node values**.

---

### TreeMap (Inner)

### Priority Queue

If two nodes have

- same row
- same column

then they must be sorted by value.

Example

```
      1
     / \
    2   3
     \ /
      5 4
```

Coordinates

| Node | Column | Row |
|------|--------|-----|
|5|0|2|
|4|0|2|

Same position.

Output should be

```

```

not

```
5 4
```

Hence we use a **Min Heap (Priority Queue)**.

# Why BFS?

We need to visit every node exactly once while tracking its

- column
- row

So we perform **Level Order Traversal (BFS)**.

Each queue element stores

```
(Node, Column, Row)
```

Your `Tuple` class stores exactly this.

```java
class Tuple{
    TreeNode node;
    int row;
    int col;
}
```

# Algorithm

1. Perform BFS.
2. Store every node using

```
Column

↓

Row

↓

Priority Queue
```

3. Insert the node value into its corresponding priority queue.
4. Push left child with

```
Column - 1

Row + 1
```

5. Push right child with

```
Column + 1

Row + 1
```

6. Traverse the TreeMaps in sorted order.
7. Remove values from the Priority Queue and build the answer.

## Java Solution

```java
class Tuple {

    TreeNode node;
    int row;
    int col;

    public Tuple(TreeNode node, int row, int col) {
        this.node = node;
        this.row = row;
        this.col = col;
    }
}

class Solution {

    public List<List<Integer>> verticalTraversal(TreeNode root) {

        TreeMap<Integer,
                TreeMap<Integer,
                        PriorityQueue<Integer>>> map = new TreeMap<>();

        Queue<Tuple> queue = new LinkedList<>();

        queue.offer(new Tuple(root, 0, 0));

        while (!queue.isEmpty()) {

            Tuple tuple = queue.poll();

            TreeNode node = tuple.node;
            int column = tuple.row;
            int row = tuple.col;

            map.putIfAbsent(column, new TreeMap<>());
            map.get(column).putIfAbsent(row, new PriorityQueue<>());

            map.get(column).get(row).offer(node.val);

            if (node.left != null) {
                queue.offer(new Tuple(node.left, column - 1, row + 1));
            }

            if (node.right != null) {
                queue.offer(new Tuple(node.right, column + 1, row + 1));
            }
        }

        List<List<Integer>> result = new ArrayList<>();

        for (TreeMap<Integer, PriorityQueue<Integer>> rows : map.values()) {

            List<Integer> current = new ArrayList<>();

            for (PriorityQueue<Integer> values : rows.values()) {

                while (!values.isEmpty()) {
                    current.add(values.poll());
                }
            }

            result.add(current);
        }

        return result;
    }
}
```

# Key Takeaways

- Every node is assigned a **(Column, Row)** coordinate.
- Use **BFS** to traverse the tree while tracking coordinates.
- Use:

  ```
  TreeMap
      ↓
  TreeMap
      ↓
  PriorityQueue
  ```

  to maintain the required ordering:
  - **Columns** from left to right.
  - **Rows** from top to bottom.
  - **Values** in ascending order when nodes share the same position.
- The Priority Queue is necessary because multiple nodes can have the **same row and same column**, and they must be sorted by value.
- Overall complexity is **`O(n log n)`** due to ordered insertions.
