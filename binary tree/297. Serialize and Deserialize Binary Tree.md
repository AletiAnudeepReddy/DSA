# 297. Serialize and Deserialize Binary Tree

**Difficulty:** Hard  
**Topics:** Binary Tree, BFS, Queue, Design

---

# Problem Statement

Design an algorithm to:

- **Serialize** a binary tree into a string.
- **Deserialize** the string back into the original binary tree.

The reconstructed tree must be exactly the same as the original.

---

# Intuition

We perform a **Level Order Traversal (BFS)** and store every node.

For missing children, we store a special marker:

```
n
```

This ensures that the exact tree structure is preserved.

During deserialization, we again perform a BFS and reconstruct the tree level by level.

---

# Serialization

We use a queue.

For every node:

- If node exists
  - Append its value.
  - Push its left and right children into the queue.
- If node is null
  - Append `"n"`.

Example

```
        1
      /   \
     2     3
          / \
         4   5
```

Level Order

```
1
2 3
n n 4 5
n n n n
```

Serialized String

```
1 2 3 n n 4 5 n n n n
```

Notice how every missing child is stored.

This allows us to reconstruct the exact tree later.

---

# Deserialization

Again use a queue.

### Step 1

The first value is always the root.

```
1
```

Push it into the queue.

---

### Step 2

Pop one parent at a time.

Read the next two values.

First value

```
Left Child
```

Second value

```
Right Child
```

If the value is

```
n
```

leave that child as `null`.

Otherwise,

- Create the node.
- Attach it to the parent.
- Push it into the queue.

Repeat until all values are processed.

---

# Algorithm

### Serialization

1. Create a queue.
2. Push the root.
3. Perform BFS.
4. Store node values.
5. Store `"n"` for null nodes.
6. Return the generated string.

---

### Deserialization

1. Split the serialized string.
2. Create the root.
3. Push the root into the queue.
4. For every parent:
   - Read left child.
   - Read right child.
   - Create nodes if value is not `"n"`.
5. Return the reconstructed tree.

---

## Complexity

### Serialization

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)`

### Deserialization

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)`

Where `n` is the number of nodes.
