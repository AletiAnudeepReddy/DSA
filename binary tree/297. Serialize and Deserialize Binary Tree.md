# 297. Serialize and Deserialize Binary Tree

**Difficulty:** Hard  
**Topics:** Binary Tree, BFS, Queue, Design

---

# Problem Statement

Design an algorithm to:

- **Serialize** a binary tree into a string.
- **Deserialize** the string back into the original binary tree.

The reconstructed tree must be exactly the same as the original.

---

# Intuition

We perform a **Level Order Traversal (BFS)** and store every node.

For missing children, we store a special marker:

```
n
```

This ensures that the exact tree structure is preserved.

During deserialization, we again perform a BFS and reconstruct the tree level by level.

---

# Serialization

We use a queue.

For every node:

- If node exists
  - Append its value.
  - Push its left and right children into the queue.
- If node is null
  - Append `"n"`.

Example

```
        1
      /   \
     2     3
          / \
         4   5
```

Level Order

```
1
2 3
n n 4 5
n n n n
```

Serialized String

```
1 2 3 n n 4 5 n n n n
```

Notice how every missing child is stored.

This allows us to reconstruct the exact tree later.

---

# Deserialization

Again use a queue.

### Step 1

The first value is always the root.

```
1
```

Push it into the queue.

---

### Step 2

Pop one parent at a time.

Read the next two values.

First value

```
Left Child
```

Second value

```
Right Child
```

If the value is

```
n
```

leave that child as `null`.

Otherwise,

- Create the node.
- Attach it to the parent.
- Push it into the queue.

Repeat until all values are processed.

# Algorithm

### Serialization

1. Create a queue.
2. Push the root.
3. Perform BFS.
4. Store node values.
5. Store `"n"` for null nodes.
6. Return the generated string.

---

### Deserialization

1. Split the serialized string.
2. Create the root.
3. Push the root into the queue.
4. For every parent:
   - Read left child.
   - Read right child.
   - Create nodes if value is not `"n"`.
5. Return the reconstructed tree.

---

## Complexity

### Serialization

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)`

### Deserialization

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)`

Where `n` is the number of nodes.

---

## Java Solution

```java
public class Codec {

    // Serialize
    public String serialize(TreeNode root) {

        Queue<TreeNode> q = new LinkedList<>();
        StringBuilder res = new StringBuilder();

        q.offer(root);

        while (!q.isEmpty()) {

            TreeNode node = q.poll();

            if (node == null) {
                res.append("n ");
                continue;
            }

            res.append(node.val).append(" ");

            q.offer(node.left);
            q.offer(node.right);
        }

        return res.toString();
    }

    // Deserialize
    public TreeNode deserialize(String data) {

        if (data.equals("n ")) {
            return null;
        }

        String[] values = data.split(" ");

        if (values.length == 0 || values[0].equals("n")) {
            return null;
        }

        TreeNode root = new TreeNode(Integer.parseInt(values[0]));

        Queue<TreeNode> q = new LinkedList<>();
        q.offer(root);

        for (int i = 1; i < values.length; i++) {

            TreeNode parent = q.poll();

            if (!values[i].equals("n")) {

                TreeNode left = new TreeNode(Integer.parseInt(values[i]));
                parent.left = left;
                q.offer(left);
            }

            if (!values[++i].equals("n")) {

                TreeNode right = new TreeNode(Integer.parseInt(values[i]));
                parent.right = right;
                q.offer(right);
            }
        }

        return root;
    }
}
```

# Key Takeaways

- Uses **Level Order Traversal (BFS)**.
- Store `"n"` for every null child to preserve the tree structure.
- During deserialization, process nodes level by level.
- Queue helps reconstruct parent-child relationships correctly.
- Serialization and deserialization both run in **O(n)** time.
