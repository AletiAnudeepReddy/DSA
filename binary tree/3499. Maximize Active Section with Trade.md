# 3499. Maximize Active Section with Trade I

**Difficulty:** Medium  
**Topics:** Greedy, String, Two Pointers, Simulation

> **Pattern:** Block Processing (Run-Length Traversal)

---

# Problem Statement

You are given a binary string `s`.

- `'1'` represents an **active** section.
- `'0'` represents an **inactive** section.

You can perform **at most one trade**:

1. Convert one contiguous block of **1's** (surrounded by 0's) into **0's**.
2. Then convert one contiguous block of **0's** (surrounded by 1's) into **1's**.

Return the maximum number of active sections after the optimal trade.

> For easier handling, imagine the string is surrounded by `1` on both sides.

```
t = "1" + s + "1"
```

These added `1`s are only for processing and **are not counted** in the final answer.

---

# Which Topic Does This Problem Belong To?

This problem mainly belongs to:

- **Greedy**
- **String Traversal**
- **Two Pointers**
- **Simulation**
- **Run-Length Encoding (Block Processing)**

> It is **not** a Sliding Window problem because we are processing **blocks (groups of consecutive characters)** instead of maintaining a dynamic window.

# Intuition

Suppose we have

```
001110000111100
```

The string consists of alternating blocks.

```
00 | 111 | 0000 | 1111 | 00
```

A valid trade is always

```
0-block
↓

1-block

↓

0-block
```

Like

```
000

111

0000
```

If we remove the middle `1-block`

```
0001110000

↓

0000000000
```

Now both surrounding zero blocks merge into one large zero block.

```
000 + 111 + 0000

↓

0000000000
```

That merged block is surrounded by ones, so we can convert the whole merged block into ones.

Notice that

```
Lose = middle 1-block

Gain = left0 + middle1 + right0
```

Net increase

```
= left0 + right0
```

So instead of computing

```
ones - middle1 + left0 + middle1 + right0
```

we simply write

```
ones + left0 + right0
```

which is exactly what the code does.

# Algorithm

1. Count total active sections (`ones`).
2. Add imaginary boundaries.

```
s = "1" + s + "1"
```

3. Traverse block by block.
4. Read

```
Left Zero Block

↓

Middle One Block

↓

Right Zero Block
```

5. Compute

```
ones + leftZero + rightZero
```

6. Update the maximum answer.
7. Move to the next block.

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)`

---

## Java Solution

```java
class Solution {

    public int maxActiveSectionsAfterTrade(String s) {

        int ones = 0;

        for (char c : s.toCharArray()) {
            if (c == '1')
                ones++;
        }

        s = "1" + s + "1";

        int n = s.length();
        int i = 0;

        int ans = ones;

        // Skip first block of 1's
        while (i < n && s.charAt(i) == '1')
            i++;

        // Read first zero block
        int leftZero = 0;

        while (i < n && s.charAt(i) == '0') {
            leftZero++;
            i++;
        }

        while (i < n) {

            // Middle one block
            int oneBlock = 0;

            while (i < n && s.charAt(i) == '1') {
                oneBlock++;
                i++;
            }

            if (oneBlock == 0)
                break;

            // Right zero block
            int rightZero = 0;

            while (i < n && s.charAt(i) == '0') {
                rightZero++;
                i++;
            }

            if (rightZero == 0)
                break;

            ans = Math.max(ans, ones + leftZero + rightZero);

            // Slide to next block
            leftZero = rightZero;
        }

        return ans;
    }
}
```

# Key Takeaways

- Think in terms of **blocks**, not individual characters.
- A valid trade always involves

```
0-block

↓

1-block

↓

0-block
```

- Removing the middle one block merges the surrounding zero blocks.
- The final increase is simply

```
Left Zero + Right Zero
```

- Traverse the string once by processing consecutive blocks.
