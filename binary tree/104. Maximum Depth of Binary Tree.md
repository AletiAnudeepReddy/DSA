# 104. Maximum Depth of Binary Tree

**Difficulty:** Easy  
**Topics:** Binary Tree, DFS, Recursion

---

# Problem Statement

Given the root of a binary tree, return its **maximum depth**.

The maximum depth is the number of nodes along the **longest path** from the root to any leaf node.

---

# Intuition

The depth of a tree depends on the deeper of its two subtrees.

For every node:

- Find the depth of the left subtree.
- Find the depth of the right subtree.
- The current node's depth is:

```
1 + max(leftDepth, rightDepth)
```

The `1` represents the current node itself.

---

## Recursive Relation

```
Depth(node)

=

1 + max(Depth(left), Depth(right))
```

### Base Case

If the node is `null`,

```
Depth = 0
```

because an empty tree has no nodes.

---

## Example

```
        3
       / \
      9   20
         /  \
        15   7
```

Compute from the bottom:

```
Depth(9)  = 1

Depth(15) = 1

Depth(7)  = 1
```

Now,

```
Depth(20)

=

1 + max(1,1)

=

2
```

Finally,

```
Depth(3)

=

1 + max(1,2)

=

3
```

Answer

```
3
```

---

## Algorithm

1. If the current node is `null`, return `0`.
2. Recursively compute the depth of the left subtree.
3. Recursively compute the depth of the right subtree.
4. Return:

```
1 + max(leftDepth, rightDepth)
```

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(h)` *(recursion stack)*

Where:

- `n` = Number of nodes
- `h` = Height of the tree

Worst case (skewed tree): `O(n)`

Balanced tree: `O(log n)`

---

## Java Solution

```java
class Solution {

    public int maxDepth(TreeNode root) {

        if (root == null) {
            return 0;
        }

        int leftHeight = maxDepth(root.left);
        int rightHeight = maxDepth(root.right);

        return 1 + Math.max(leftHeight, rightHeight);
    }
}
```

# Key Takeaways

- The maximum depth is the **longest path from the root to a leaf**.
- Solve recursively using:

  ```
  Depth(node) = 1 + max(Depth(left), Depth(right))
  ```

- Base case:

  ```
  null → 0
  ```

- This is one of the most fundamental binary tree recursion problems and forms the basis for many other tree algorithms (diameter, balanced tree, etc.).
