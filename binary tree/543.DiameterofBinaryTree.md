# 543. Diameter of Binary Tree

**Difficulty:** Easy  
**Topics:** Binary Tree, DFS, Recursion

---

# Problem Statement

The **diameter** of a binary tree is the **length of the longest path between any two nodes**.

- The path **may or may not pass through the root**.
- The length is measured in **number of edges**, not nodes.

Return the diameter of the tree.

---

# Intuition

At every node, the **longest path passing through that node** is:

```
Height of Left Subtree + Height of Right Subtree
```

Why?

- The deepest node in the left subtree contributes `leftHeight` edges.
- The deepest node in the right subtree contributes `rightHeight` edges.
- Joining them through the current node gives the longest path passing through that node.

The answer is the maximum such value over all nodes.

---

## Important Observation

The diameter **does not always pass through the root**.

```
        1
       /
      2
     / \
    3   4
   /
  5
```

The longest path is

```
5 → 3 → 2 → 4
```

It never passes through node `1`.

Therefore, we must compute the diameter at **every node**.

---

# Recursive Relation

For every node:

1. Compute the height of the left subtree.
2. Compute the height of the right subtree.
3. The diameter passing through the current node is:

```
leftHeight + rightHeight
```

4. Update the global maximum diameter.
5. Return the current subtree height:

```
1 + max(leftHeight, rightHeight)
```

## Algorithm

1. If the node is `null`, return height `0`.
2. Compute the left subtree height.
3. Compute the right subtree height.
4. Update the global diameter using:

```
leftHeight + rightHeight
```

5. Return:

```
1 + max(leftHeight, rightHeight)
```

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(h)` *(recursion stack)*

Where:

- `n` = Number of nodes
- `h` = Height of the tree

---

## Java Solution

```java
class Solution {

    public int diameterOfBinaryTree(TreeNode root) {

        int[] diameter = new int[1];

        height(root, diameter);

        return diameter[0];
    }

    private int height(TreeNode root, int[] diameter) {

        if (root == null) {
            return 0;
        }

        int leftHeight = height(root.left, diameter);
        int rightHeight = height(root.right, diameter);

        diameter[0] = Math.max(diameter[0], leftHeight + rightHeight);

        return 1 + Math.max(leftHeight, rightHeight);
    }
}
```

# Key Takeaways

- The diameter is the **longest path between any two nodes**, measured in **edges**.
- The longest path through a node is:

  ```
  leftHeight + rightHeight
  ```

- Compute the **height** and **diameter** together in one DFS traversal.
- Store the maximum diameter in a global variable (or an array as in this solution).
- The diameter **may or may not pass through the root**, so every node must be considered.
- This single traversal gives an optimal **`O(n)`** solution.
