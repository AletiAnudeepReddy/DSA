# 236. Lowest Common Ancestor of a Binary Tree

**Difficulty:** Medium  
**Topics:** Binary Tree, DFS, Recursion

---

# Problem Statement

Given the root of a binary tree and two nodes `p` and `q`, return their **Lowest Common Ancestor (LCA)**.

The **Lowest Common Ancestor** is the **lowest node** in the tree that has both `p` and `q` as descendants (a node can be a descendant of itself).

---

# Intuition

For every node, there are only three possibilities:

1. Both `p` and `q` are in the **left subtree**.
2. Both `p` and `q` are in the **right subtree**.
3. One is in the left subtree and the other is in the right subtree.

The first node where the paths split is the **Lowest Common Ancestor**.

We recursively search both subtrees and use the returned results to determine the answer.

---

# Key Observations

### Case 1 : Current node is `p` or `q`

```
        p
       / \
      .   .
```

If the current node itself is one of the target nodes, return it immediately.

```java
if(root == p || root == q)
    return root;
```

---

### Case 2 : Both nodes are in different subtrees

```
          3
        /   \
       5     1
```

Recursive calls return

```

Right -> 1
```

Since both are non-null,

```
LCA = 3
```

### Case 3 : Both nodes are in the same subtree

```
          3
         /
        5
       /
      6
```

Suppose

```

```

The left recursion returns

```
5
```

The right recursion returns

```
null
```

So we simply return

```
5
```

# Algorithm

1. If the current node is `null`, return `null`.
2. If the current node is `p` or `q`, return the current node.
3. Recursively search in the left subtree.
4. Recursively search in the right subtree.
5. If both recursive calls return non-null, the current node is the LCA.
6. Otherwise, return the non-null result.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(h)` *(Recursion Stack)*

Where:

- `n` = Number of nodes
- `h` = Height of the tree

---

## Java Solution

```java
class Solution {

    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {

        if (root == null) {
            return null;
        }

        if (root == p || root == q) {
            return root;
        }

        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);

        if (left != null && right != null) {
            return root;
        }

        return (left != null) ? left : right;
    }
}
```

# Key Takeaways

- Recursively search both left and right subtrees.
- If the current node is `p` or `q`, return it immediately.
- If both recursive calls return non-null, the current node is the **Lowest Common Ancestor**.
- Otherwise, propagate the non-null node upward.
- Every node is visited only once, giving an **`O(n)`** solution.
