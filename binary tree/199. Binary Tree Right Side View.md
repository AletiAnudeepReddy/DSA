# 199. Binary Tree Right Side View

**Difficulty:** Medium  
**Topics:** Binary Tree, DFS, Recursion

---

# Problem Statement

Given the root of a binary tree, imagine yourself standing on the **right side** of the tree.

Return the values of the nodes that are visible from **top to bottom**.

---

# Intuition

At every level, only **one node** is visible from the right side.

If we perform a **DFS** and always visit the **right child before the left child**, then the **first node** we encounter at every depth will be the rightmost node.

We simply store the first node encountered at each depth.

---

# Key Observation

Suppose the tree is

```
        1
      /   \
     2     3
      \     \
       5     4
```

The visible nodes are

```
1

↓

3

↓

4
```

Answer

```
[1,3,4]
```

---

# Why Visit Right First?

Normally DFS is

```
Root

↓

Left

↓

Right
```

For Right Side View, we reverse it.

```
Root

↓

Right

↓

Left
```

This guarantees that the first node visited at every level is the node visible from the right side.

---

# How Do We Know It's the First Node?

Maintain the current depth.

Initially

```
Depth = 0
```

Whenever

```
currentDepth == result.size()
```

it means this is the **first node** we have reached at this depth.

So we add it to the answer.

Subsequent nodes at the same depth are ignored.

# Algorithm

1. Start DFS from the root.
2. Visit the **right subtree before the left subtree**.
3. If `currentDepth == result.size()`, add the current node.
4. Continue recursively.
5. Return the result.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(h)` *(Recursion Stack)*

Where:

- `n` = Number of nodes
- `h` = Height of the tree

---

## Java Solution

```java
class Solution {

    public List<Integer> rightSideView(TreeNode root) {

        List<Integer> result = new ArrayList<>();

        rightView(root, result, 0);

        return result;
    }

    private void rightView(TreeNode root, List<Integer> result, int depth) {

        if (root == null) {
            return;
        }

        if (depth == result.size()) {
            result.add(root.val);
        }

        rightView(root.right, result, depth + 1);
        rightView(root.left, result, depth + 1);
    }
}
```

# Left View vs Right View

| Left View | Right View |
|-----------|------------|
| Visit Left first | Visit Right first |
| First node at every depth | First node at every depth |
| Root → Left → Right | Root → Right → Left |

---

# Key Takeaways

- Traverse the tree using **DFS**.
- Visit the **right subtree before the left subtree**.
- The first node encountered at each depth is the visible node.
- Use the condition:

```java
depth == result.size()
```

to identify the first node at every level.
- Runs in **`O(n)`** time and **`O(h)`** recursion space.
