# 863. All Nodes Distance K in Binary Tree

**Difficulty:** Medium  
**Topics:** Binary Tree, BFS, Graph, HashMap

---

# Problem Statement

Given the root of a binary tree, a **target** node, and an integer `k`, return all the node values that are exactly **distance `k`** away from the target node.

You may return the answer in any order.

---

# Intuition

A binary tree allows movement only from **parent → child**.

However, from the target node, we need to move in **all possible directions**:

- Left Child
- Right Child
- Parent

Therefore, we first convert the tree into an **undirected graph** by storing the **parent of every node**.

Once parent links are available, we perform a **BFS starting from the target node**.

The nodes remaining in the queue after exactly `k` levels are the required answer.

---

# Why Store Parent Pointers?

Normally we can only move

```
Parent

↓

Child
```

But from the target we also need to move

```
Child

↓

Parent
```

So for every node we store

```
Child -> Parent
```

using a HashMap.

Example

```
        3
       / \
      5   1
```

Parent Map

```
5 -> 3

1 -> 3
```

Now every node has three possible neighbors:

```
Left Child

Right Child

Parent
```

making the tree behave like an **undirected graph**.

---

# Overall Approach

### Step 1

Traverse the tree once and build

```
Child -> Parent
```

mapping.

---

### Step 2

Start BFS from the target node.

Maintain

- Queue
- Visited Set

to avoid revisiting nodes.

---

### Step 3

Each BFS level represents

```
Distance = 1
```

After traversing exactly `k` levels,

all nodes currently inside the queue are at distance `k`.

# Why Visited Array?

Since we added parent pointers,

the tree behaves like a graph.

Without marking visited,

```
5

↓

3

↓

5

↓

3
```

would create an infinite loop.

So every visited node is stored in

```
HashMap<TreeNode, Boolean>

(or HashSet<TreeNode>)
```

---

# Algorithm

### Step 1

Build a parent map using BFS.

```
Child -> Parent
```

---

### Step 2

Start BFS from the target node.

---

### Step 3

Repeat until distance becomes `k`

For every node

- Visit Left Child
- Visit Right Child
- Visit Parent

only if not visited.

---

### Step 4

When distance equals `k`,

all nodes remaining in the queue form the answer.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)`

Where:

- `n` = Number of nodes

---

## Java Solution

```java
class Solution {

    public void markParents(TreeNode root, Map<TreeNode, TreeNode> parents) {

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {

            TreeNode curr = queue.poll();

            if (curr.left != null) {
                parents.put(curr.left, curr);
                queue.offer(curr.left);
            }

            if (curr.right != null) {
                parents.put(curr.right, curr);
                queue.offer(curr.right);
            }
        }
    }

    public List<Integer> distanceK(TreeNode root, TreeNode target, int k) {

        Map<TreeNode, TreeNode> parents = new HashMap<>();
        markParents(root, parents);

        Map<TreeNode, Boolean> visited = new HashMap<>();
        Queue<TreeNode> queue = new LinkedList<>();

        queue.offer(target);
        visited.put(target, true);

        int currentLevel = 0;

        while (!queue.isEmpty()) {

            if (currentLevel == k) {
                break;
            }

            int size = queue.size();
            currentLevel++;

            for (int i = 0; i < size; i++) {

                TreeNode curr = queue.poll();

                if (curr.left != null && !visited.containsKey(curr.left)) {
                    queue.offer(curr.left);
                    visited.put(curr.left, true);
                }

                if (curr.right != null && !visited.containsKey(curr.right)) {
                    queue.offer(curr.right);
                    visited.put(curr.right, true);
                }

                if (parents.get(curr) != null && !visited.containsKey(parents.get(curr))) {
                    queue.offer(parents.get(curr));
                    visited.put(parents.get(curr), true);
                }
            }
        }

        List<Integer> ans = new ArrayList<>();

        while (!queue.isEmpty()) {
            ans.add(queue.poll().val);
        }

        return ans;
    }
}
```

# Key Takeaways

- Convert the binary tree into an **undirected graph** by storing parent pointers.
- Perform **BFS from the target node**.
- Every BFS level represents one unit of distance.
- Stop after reaching distance `k`.
- The remaining nodes in the queue are exactly `k` distance away.
- Use a **visited set** to avoid revisiting parent-child pairs.
- Runs in **`O(n)`** time.
