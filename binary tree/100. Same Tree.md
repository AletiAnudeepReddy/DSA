# 100. Same Tree

**Difficulty:** Easy  
**Topics:** Binary Tree, DFS, Recursion

---

# Problem Statement

Given the roots of two binary trees `p` and `q`, determine whether they are **identical**.

Two binary trees are considered the same if:

- They have the **same structure**.
- Corresponding nodes have the **same values**.

Return `true` if both trees are identical; otherwise, return `false`.

---

# Intuition

To determine whether two trees are identical, we compare them **node by node**.

For every pair of nodes:

- If both are `null`, they are identical.
- If only one is `null`, the trees differ.
- If their values are different, the trees differ.
- Otherwise, recursively compare their left and right subtrees.

Since every node must match, recursion is the most natural approach.

---

# Base Cases

### Case 1: Both Nodes are `null`

```
p = null

q = null
```

Both trees have ended at the same position.

Return

```
true
```

---

### Case 2: One Node is `null`

```
p = 5

q = null
```

Structures are different.

Return

```
false
```

Your code handles both cases together:

```java
if (p == null || q == null) {
    return p == q;
}
```

Explanation:

- `null == null` → `true`
- `node == null` → `false`

---

# Recursive Relation

If both nodes exist,

they must satisfy all three conditions:

```
Current values are equal

AND

Left subtrees are identical

AND

Right subtrees are identical
```

Mathematically,

```
SameTree(p, q)

=

(p.val == q.val)

&&

SameTree(p.left, q.left)

&&

SameTree(p.right, q.right)
```

```

```

```

Compare right

```

```

Answer

```

# Algorithm

1. If one or both nodes are `null`, return whether they are equal.
2. Compare the current node values.
3. Recursively compare the left subtrees.
4. Recursively compare the right subtrees.
5. Return `true` only if all comparisons are true.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(h)` *(recursion stack)*

Where:

- `n` = Number of nodes
- `h` = Height of the tree

---

## Java Solution

```java
class Solution {

    public boolean isSameTree(TreeNode p, TreeNode q) {

        if (p == null || q == null) {
            return p == q;
        }

        return (p.val == q.val)
                && isSameTree(p.left, q.left)
                && isSameTree(p.right, q.right);
    }
}
```

# Key Takeaways

- Two trees are identical only if:
  - Their structures are the same.
  - Corresponding node values are equal.
- Base cases:
  - Both `null` → `true`
  - One `null` → `false`
- Recursively compare:
  - Current node values.
  - Left subtrees.
  - Right subtrees.
- Every node is visited once, resulting in an **`O(n)`** solution.
