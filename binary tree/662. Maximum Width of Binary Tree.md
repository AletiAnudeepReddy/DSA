# 662. Maximum Width of Binary Tree

**Difficulty:** Medium  
**Topics:** Binary Tree, BFS, Queue

---

# Problem Statement

Given the root of a binary tree, return the **maximum width** of the tree.

The width of a level is the distance between the **leftmost** and **rightmost** non-null nodes, including the **null nodes** that would exist in a complete binary tree.

---

# Intuition

The tricky part is that **missing (null) nodes also contribute to the width**.

Instead of actually storing null nodes, assign every node an **index** as if the tree were a **Complete Binary Tree**.

For any node with index `i`:

```
Left Child  -> 2 * i + 1

Right Child -> 2 * i + 2
```

The width of a level becomes

```
Last Index - First Index + 1
```

---

# Why Assign Indices?

Consider

```
          1
        /   \
       3     2
      / \     \
     5   3     9
```

Assign Complete Binary Tree indices

```
                1(0)

         3(1)         2(2)

     5(3)   3(4)   null   9(6)
```

Notice that

```
Third Level

Indices

3       4      5      6

Nodes

5       3    null     9
```

Width

```
6 - 3 + 1 = 4
```

Even though node `5` and node `9` are not adjacent, the missing node is counted.

---

# Why Normalize Indices?

Indices can become extremely large for deep trees.

Before processing each level, subtract the first index of that level.

```
Normalized Index

=

Current Index - First Index
```

Example

Instead of

```
1024

1025

1026
```

we use

```
0

1

2
```

This avoids integer overflow while preserving the width.

# Algorithm

1. Perform **Level Order Traversal (BFS)**.
2. Store each node along with its complete binary tree index.
3. At every level:
   - Normalize indices.
   - Record the first and last indices.
   - Width = `last - first + 1`.
4. Update the maximum width.
5. Push children with:
   - Left → `2*i + 1`
   - Right → `2*i + 2`

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)`

Where:

- `n` = Number of nodes

---

## Java Solution

```java
class Pair {

    TreeNode node;
    int num;

    Pair(TreeNode node, int num) {
        this.node = node;
        this.num = num;
    }
}

class Solution {

    public int widthOfBinaryTree(TreeNode root) {

        if (root == null) {
            return 0;
        }

        int maxWidth = 0;

        Queue<Pair> queue = new LinkedList<>();
        queue.offer(new Pair(root, 0));

        while (!queue.isEmpty()) {

            int size = queue.size();

            int minIndex = queue.peek().num;

            int first = 0;
            int last = 0;

            for (int i = 0; i < size; i++) {

                Pair current = queue.poll();

                int currentIndex = current.num - minIndex;

                if (i == 0) {
                    first = currentIndex;
                }

                if (i == size - 1) {
                    last = currentIndex;
                }

                if (current.node.left != null) {
                    queue.offer(new Pair(current.node.left, currentIndex * 2 + 1));
                }

                if (current.node.right != null) {
                    queue.offer(new Pair(current.node.right, currentIndex * 2 + 2));
                }
            }

            maxWidth = Math.max(maxWidth, last - first + 1);
        }

        return maxWidth;
    }
}
```

# Key Takeaways

- Treat the binary tree as a **Complete Binary Tree** by assigning indices.
- The width of a level is:

```text
lastIndex - firstIndex + 1
```

- Normalize indices at every level to avoid integer overflow.
- Use **BFS** because width is calculated level by level.
- Runs in **`O(n)`** time.
