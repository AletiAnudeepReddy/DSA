# 105. Construct Binary Tree from Preorder and Inorder Traversal

**Difficulty:** Medium  
**Topics:** Binary Tree, DFS, Recursion, HashMap

---

# Problem Statement

Given the **Preorder** and **Inorder** traversal of a binary tree, construct and return the original binary tree.

It is guaranteed that the tree can be uniquely reconstructed.

---

# Intuition

The solution is based on the properties of tree traversals.

### Preorder Traversal

```
Root → Left → Right
```

The **first element** is always the **root** of the current subtree.

### Inorder Traversal

```
Left → Root → Right
```

The root divides the inorder array into:

- Left Subtree
- Right Subtree

So at every recursive call:

1. Pick the first node from preorder as the root.
2. Find that node in inorder.
3. Everything left of it belongs to the left subtree.
4. Everything right of it belongs to the right subtree.
5. Repeat recursively.

# Why HashMap?

Finding the root in inorder using a loop would take

```
O(n)
```

for every recursive call.

Instead, store

```
Value → Index
```

inside a HashMap.

Example

```
Inorder

[9,3,15,20,7]
```

Map

```
9  -> 0

3  -> 1

15 -> 2

20 -> 3

7  -> 4
```

Now every lookup takes

```
O(1)
```

```

```

# Algorithm

1. Store all inorder indices in a HashMap.
2. Pick the first preorder element as the root.
3. Find its position in inorder.
4. Calculate the number of nodes in the left subtree.
5. Recursively construct:
   - Left subtree
   - Right subtree
6. Return the root.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)`

Where:

- `n` = Number of nodes

---

## Java Solution

```java
class Solution {

    public TreeNode buildTree(int[] preorder, int[] inorder) {

        Map<Integer, Integer> inorderMap = new HashMap<>();

        for (int i = 0; i < inorder.length; i++) {
            inorderMap.put(inorder[i], i);
        }

        return build(preorder, 0, preorder.length - 1,
                     inorder, 0, inorder.length - 1,
                     inorderMap);
    }

    private TreeNode build(int[] preorder,
                           int preStart,
                           int preEnd,
                           int[] inorder,
                           int inStart,
                           int inEnd,
                           Map<Integer, Integer> inorderMap) {

        if (preStart > preEnd || inStart > inEnd) {
            return null;
        }

        TreeNode root = new TreeNode(preorder[preStart]);

        int inRoot = inorderMap.get(root.val);

        int numsLeft = inRoot - inStart;

        root.left = build(preorder,
                          preStart + 1,
                          preStart + numsLeft,
                          inorder,
                          inStart,
                          inRoot - 1,
                          inorderMap);

        root.right = build(preorder,
                           preStart + numsLeft + 1,
                           preEnd,
                           inorder,
                           inRoot + 1,
                           inEnd,
                           inorderMap);

        return root;
    }
}
```

# Key Takeaways

- **Preorder** always gives the **root** of the current subtree.
- **Inorder** divides the tree into **left** and **right** subtrees.
- A **HashMap** is used for `O(1)` lookup of the root index in inorder.
- Carefully calculate preorder ranges using the size of the left subtree.
- Every node is processed exactly once, resulting in **`O(n)`** time complexity.
