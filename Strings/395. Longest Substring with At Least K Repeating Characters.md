# 395. Longest Substring with At Least K Repeating Characters

**Difficulty:** Medium
**Topics:** String, Hash Table, Divide and Conquer, Recursion

---

## Problem

Given a string `s` and an integer `k`, find the length of the longest substring in which **every character appears at least `k` times**.

If no valid substring exists, return `0`.

### Example 1

```text
s = "aaabb"
k = 3
```

The answer is:

```text
"aaa" → 3
```

because `a` occurs 3 times.

### Example 2

```text
s = "ababbc"
k = 2
```

The answer is:

```text
"ababb" → 5
```

because:

```text
a → 2
b → 3
```

Both frequencies are at least `2`.

---

# Approach — Divide and Conquer

Your solution uses a very good **divide-and-conquer** idea.

The key observation is:

> If a character occurs fewer than `k` times in the current substring, that character can NEVER belong to a valid answer inside this substring.

So that character becomes a **splitting point**.

---

## Step 1: Count frequencies

For the current range:

```text
[s, e)
```

count the frequency of every character.

```java
int[] freq = new int[26];

for (int i = s; i < e; i++) {
    freq[str.charAt(i) - 'a']++;
}
```

For example:

```text
s = "ababbc"
k = 2
```

Frequency:

```text
a → 2
b → 3
c → 1
```

`c` occurs only once.

Therefore, `c` cannot be part of any valid substring.

---

# Step 2: Find an invalid character

You then scan the current substring:

```java
for (int i = s; i < e; i++) {

    if (freq[str.charAt(i) - 'a'] < k) {
        ...
    }
}
```

Suppose:

```text
ababbc
     ↑
     c
```

Since:

```text
freq[c] = 1 < k
```

`c` cannot be part of the answer.

Therefore, split the problem into:

```text
ababb | c
```

and solve both sides independently.

---

# Step 3: Recursively solve both halves

Your code:

```java
int l = recur(str, s, i, k);
int r = recur(str, i + 1, e, k);

return Math.max(l, r);
```

So:

```text
             ababbc
                |
             c invalid
             /      \
         ababb       ""
```

We find the best valid substring on the left and right.

---

# Why can we split here?

This is the most important intuition.

Suppose:

```text
s = "aaabbxccc"
k = 3
```

Frequency:

```text
a → 3
b → 2
x → 1
c → 3
```

`b` and `x` are invalid because:

```text
frequency < k
```

A valid substring cannot contain either of them.

Therefore, the answer must lie completely inside one of these sections:

```text
aaa | bbx | ccc
```

So instead of checking every possible substring, we break the problem at characters that are guaranteed not to belong to a valid answer.

---

# Step 4: Base / Valid Case

If we scan the entire substring and **don't find any character whose frequency is less than `k`**, then every character satisfies the requirement.

Therefore, the entire substring is valid:

```java
return e - s;
```

For example:

```text
s = "ababb"
k = 2
```

Frequencies:

```text
a → 2
b → 3
```

Everything is valid.

Therefore:

```text
answer = 5
```

---

# Complete Code

```java
class Solution {

    public int recur(String str, int s, int e, int k) {

        int[] freq = new int[26];

        // Count frequencies in current substring [s, e)
        for (int i = s; i < e; i++) {
            freq[str.charAt(i) - 'a']++;
        }

        // Find a character that cannot be part of a valid answer
        for (int i = s; i < e; i++) {

            if (freq[str.charAt(i) - 'a'] < k) {

                int l = recur(str, s, i, k);
                int r = recur(str, i + 1, e, k);

                return Math.max(l, r);
            }
        }

        // Every character occurs at least k times
        return e - s;
    }

    public int longestSubstring(String s, int k) {
        return recur(s, 0, s.length(), k);
    }
}
```

# Important Insight

The entire solution depends on this statement:

> **A character whose frequency is less than `k` cannot appear in any valid substring containing it.**

Therefore, such a character acts as a **separator**.

Think of:

```text
"aabbcdeeff"
```

with:

```text
k = 2
```

Frequencies:

```text
a → 2 ✓
b → 2 ✓
c → 1 ✗
d → 1 ✗
e → 2 ✓
f → 2 ✓
```

So the invalid characters `c` and `d` divide the string:

```text
aabb | c | d | eeff
```

The answer can only come from:

```text
aabb
```

or

```text
eeff
```

Both have length `4`.

---

# Why `e - s`?

Your recursive range is:

```text
[s, e)
```

Notice that `e` is **exclusive**.

For example:

```text
s = 2
e = 5
```

means:

```text
indices: 2, 3, 4
```

Number of elements:

```text
5 - 2 = 3
```

Therefore:

```java
return e - s;
```

is the correct length.

---

# Complexity

Let `n` be the length of the string.

For each recursive call, we scan the current substring to:

1. count frequencies
2. find an invalid character

So each call takes:

```text
O(length of current substring)
```

The practical complexity is generally close to:

```text
O(26 × n)
```

for the common divide-and-conquer analysis because there are only 26 lowercase characters, though the exact recursive behavior can depend on the splits.

Space complexity:

```text
O(n)
```

in the worst case due to the recursion stack.

The frequency array itself is only:

```text
O(26) = O(1)
```

# Pattern to Remember

This problem is a classic example of:

```text
Divide and Conquer
        ↓
Count frequencies
        ↓
Find an element violating the condition
        ↓
Split around that element
        ↓
Solve left + right
        ↓
Take maximum
```

The template is:

```java
int solve(String s, int l, int r) {

    // 1. Count frequency

    // 2. Find an element that makes the current
    //    range impossible

    // 3. Split around it

    return Math.max(
        solve(s, l, split),
        solve(s, split + 1, r)
    );

    // 4. If no invalid element exists,
    //    entire range is valid
}
```

### Core intuition

**`frequency < k` → cannot be part of answer → split there.**

That is the main trick behind **LeetCode 395**.
