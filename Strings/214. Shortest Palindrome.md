# 214. Shortest Palindrome

**Difficulty:** Hard  
**Topic:** String, KMP (Prefix Function), Two Pointers

## Problem Statement

Given a string `s`, you can add characters **only at the beginning** of the string.

Return the **shortest palindrome** that can be formed.

### Example 1

```text
Input:  s = "aacecaaa"
Output: "aaacecaaa"
```

### Example 2

```text
Input:  s = "abcd"
Output: "dcbabcd"
```

---

# Approach 1: Brute Force (Check Longest Palindromic Prefix)

## Intuition

Since we can **only add characters to the front**, we want to keep the **largest prefix that is already a palindrome**.

For every possible ending index (starting from the last character):

- Check if `s[0...end]` is a palindrome.
- The first valid one is the **longest palindromic prefix**.
- Reverse the remaining suffix and prepend it.

### Example

```text
s = "abcd"

Longest palindromic prefix = "a"

Remaining = "bcd"

Reverse remaining = "dcb"

Answer = "dcbabcd"
```

---

## Algorithm

1. Traverse from the last index to the first.
2. Check whether `s[0...end]` is a palindrome.
3. If yes:
   - Take the remaining suffix.
   - Reverse it.
   - Add it before the original string.
4. Return the result.

---

## Java Code

```java
class Solution {
    public String shortestPalindrome(String s) {
        int n = s.length();

        for (int end = n - 1; end >= 0; end--) {
            if (isPalindrome(s, 0, end)) {
                String remain = s.substring(end + 1);
                return new StringBuilder(remain).reverse().toString() + s;
            }
        }

        return s;
    }

    public boolean isPalindrome(String s, int l, int r) {
        while (l < r) {
            if (s.charAt(l) != s.charAt(r))
                return false;

            l++;
            r--;
        }
        return true;
    }
}
```

---

## Complexity Analysis

- **Time Complexity:** **O(n²)**
- **Space Complexity:** **O(n)**

# Approach 2: Optimal (KMP Prefix Function)

## Key Observation

We only need to find the **longest prefix of `s` that is already a palindrome**.

Instead of checking every prefix, KMP helps us compute it in **O(n)**.

---

## Trick

Create

```text
t = s + "#" + reverse(s)
```

Example:

```text
s = "abcd"

reverse = "dcba"

t = "abcd#dcba"
```

Now compute the **LPS (Longest Prefix Suffix)** array of `t`.

The last value of the LPS array tells us:

> Length of the **longest prefix of `s`** that also matches a suffix of `reverse(s)`.

This is exactly the **longest palindromic prefix**.

---

## Example

```text
s = "abcd"

reverse = "dcba"

t = "abcd#dcba"
```

LPS:

```text
0 0 0 0 0 0 0 0 1
```

Last value = **1**

Meaning:

```text
Longest palindromic prefix = "a"
```

Remaining:

```text
"bcd"
```

Reverse it:

```text
"dcb"
```

Answer:

```text
"dcbabcd"
```

---

## Why does this work?

Suppose

```text
s = aacecaaa
```

Reverse:

```text
aaacecaa
```

Construct

```text
aacecaaa#aaacecaa
```

The prefix function finds the largest prefix of `s` that also appears as a suffix of `reverse(s)`.

That common part represents the **longest prefix that reads the same forward and backward**, i.e., the longest palindromic prefix.

Everything after that prefix must be reversed and added to the front.

---

## Algorithm

1. Reverse the string.
2. Create

   ```text
   s + "#" + reverse(s)
   ```

3. Compute the KMP LPS array.
4. The last LPS value gives the length of the longest palindromic prefix.
5. Reverse the remaining suffix.
6. Add it before the original string.

---

## Java Code

```java
class Solution {
    public String shortestPalindrome(String s) {

        String rev = new StringBuilder(s).reverse().toString();

        String t = s + "#" + rev;

        int[] lps = new int[t.length()];

        for (int i = 1; i < t.length(); i++) {

            int j = lps[i - 1];

            while (j > 0 && t.charAt(i) != t.charAt(j)) {
                j = lps[j - 1];
            }

            if (t.charAt(i) == t.charAt(j)) {
                j++;
            }

            lps[i] = j;
        }

        int len = lps[t.length() - 1];

        String remaining = s.substring(len);

        return new StringBuilder(remaining).reverse().toString() + s;
    }
}
```

---

## Complexity Analysis

- **Time Complexity:** **O(n)**
- **Space Complexity:** **O(n)**

---

# Comparison

| Approach | Time | Space |
|----------|------|-------|
| Brute Force | O(n²) | O(n) |
| KMP (Optimal) | O(n) | O(n) |

---

# Key Takeaways

- Since characters can only be added **at the front**, we need the **longest palindromic prefix**.
- Brute force checks every prefix individually.
- KMP efficiently finds the longest palindromic prefix in linear time.
- Constructing `s + "#" + reverse(s)` transforms the problem into a standard **Longest Prefix Suffix (LPS)** computation.
- The optimal KMP solution runs in **O(n)** time and is the preferred approach for large inputs.
