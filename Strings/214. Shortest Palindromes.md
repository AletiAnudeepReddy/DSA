# 214. Shortest Palindrome

**Difficulty:** Hard  
**Topics:** String, Two Pointers, Greedy, KMP (Prefix Function)

---

## Problem

You are given a string `s`.

You may add characters **only in front** of the string.

Return the **shortest palindrome** that can be obtained.

---

## Example 1

```text
Input: s = "aacecaaa"

Output: "aaacecaaa"
```

**Explanation**

The longest palindromic prefix is

```
aacecaa
```

Remaining part

```
a
```

Reverse it and add in front

```
a + aacecaaa

= aaacecaaa
```

---

## Example 2

```text
Input: s = "abcd"

Output: "dcbabcd"
```

**Explanation**

Only `"a"` is a palindromic prefix.

Remaining part

```
bcd
```

Reverse it

```
dcb
```

Add in front

```
dcbabcd
```

---

# Key Observation

We are allowed to insert characters **only at the beginning**.

Therefore,

we should keep the **longest prefix that is already a palindrome**.

Everything after that prefix must be reversed and added to the front.

So the entire problem becomes:

> **Find the longest palindromic prefix.**

---

# Approach 1 — Brute Force

## Intuition

Start from the entire string.

Check whether the prefix ending at index `end` is a palindrome.

If not,

shrink the prefix by one character and try again.

The first palindrome found is the **longest palindromic prefix**.

---

## Algorithm

1. Start with `end = n-1`.
2. Check if `s[0...end]` is a palindrome.
3. If yes:
   - Reverse the remaining suffix.
   - Add it to the front.
4. Otherwise decrease `end`.
5. Continue until found.

---

## Java Solution

```java
class Solution {
    public String shortestPalindrome(String s) {

        int n = s.length();

        for (int end = n - 1; end >= 0; end--) {

            if (isPalindrome(s, 0, end)) {

                String remain = s.substring(end + 1);

                return new StringBuilder(remain).reverse().toString() + s;
            }
        }

        return s;
    }

    public boolean isPalindrome(String s, int l, int r) {

        while (l < r) {

            if (s.charAt(l) != s.charAt(r))
                return false;

            l++;
            r--;
        }

        return true;
    }
}
```

# Approach 2 — KMP (Optimal)

## Intuition

Instead of checking every prefix,

we can directly find the **longest prefix which is also a palindrome**.

This is achieved using the **LPS (Longest Prefix Suffix)** array from KMP.

---

## Trick

Reverse the string.

```
rev = reverse(s)
```

Create

```
t = s + "#" + rev
```

Example

```
s   = aacecaaa

rev = aaacecaa

t = aacecaaa#aaacecaa
```

The last value of the LPS array gives

> Longest prefix of `s`
that is also a suffix of `rev`.

Since

suffix of reverse
⇔ reverse of prefix

this exactly represents the

**Longest Palindromic Prefix**.

---

# Why Add '#'

Suppose

```
s = abcd
rev = dcba
```

Without separator

```
abcddcba
```

KMP could incorrectly match across the boundary.

Using

```
abcd#dcba
```

prevents false matches.

---

# Building LPS

Exactly like the standard KMP prefix function.

```
lps[i]

=

length of longest proper prefix
which is also suffix
ending at i
```

The last LPS value gives

```
Longest Palindromic Prefix Length
```

---

## Java Solution

```java
class Solution {
    public String shortestPalindrome(String s) {

        String rev = new StringBuilder(s).reverse().toString();

        String t = s + "#" + rev;

        int[] lps = new int[t.length()];

        for (int i = 1; i < t.length(); i++) {

            int j = lps[i - 1];

            while (j > 0 && t.charAt(i) != t.charAt(j)) {
                j = lps[j - 1];
            }

            if (t.charAt(i) == t.charAt(j)) {
                j++;
            }

            lps[i] = j;
        }

        int len = lps[t.length() - 1];

        String remaining = s.substring(len);

        return new StringBuilder(remaining).reverse().toString() + s;
    }
}
```

# Why KMP Works

The LPS array finds the longest prefix that also appears as a suffix.

After constructing

```
s + "#" + reverse(s)
```

that suffix corresponds exactly to the reverse of a prefix.

Therefore,

the longest prefix-suffix match is precisely the **longest prefix of `s` that is a palindrome**.

Once that prefix is known,

only the remaining suffix needs to be reversed and inserted at the front.

# Key Takeaways

- We can only add characters **at the front**, so we must preserve the **longest palindromic prefix**.
- The brute-force solution checks every prefix.
- The optimal solution cleverly converts the problem into a **KMP prefix-function** problem.
- The last value of the LPS array gives the length of the longest palindromic prefix.
- This is a classic application of **KMP beyond pattern matching**.
