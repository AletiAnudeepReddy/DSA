# 3016. Minimum Number of Pushes to Type Word II

**Difficulty:** Medium  
**Topics:** Greedy, Hashing, Sorting, Counting

---

## Problem

You are given a string `word` consisting of lowercase English letters.

A telephone keypad has **8 available keys (2–9)**. You are allowed to **remap** the letters to these keys in any way, but:

- Every letter must be assigned to exactly one key.
- A key can contain any number of letters.
- The first letter on a key requires **1 push**.
- The second letter requires **2 pushes**.
- The third letter requires **3 pushes**, and so on.

Unlike **Word I**, letters **can repeat** in the input.

Return the **minimum number of pushes** needed to type the word.

---

## Example 1

```text
Input: word = "abcde"

Output: 5
```

**Explanation**

Every letter appears once.

Assign each letter as the first letter on a different key.

```
1 + 1 + 1 + 1 + 1 = 5
```

---

## Example 2

```text
Input: word = "xyzxyzxyzxyz"

Output: 12
```

**Explanation**

Frequency:

```
x → 4
y → 4
z → 4
```

Assign each to the first position of different keys.

```
4×1 + 4×1 + 4×1 = 12
```

---

## Example 3

```text
Input: word = "aabbccddeeffgghhiiiiii"

Output: 24
```

---

# Intuition

Unlike **3014**, letters can appear multiple times.

A letter that appears many times contributes more to the total cost.

Therefore,

- **Most frequent letters should require fewer pushes.**
- Less frequent letters can be placed deeper inside the keys.

This is a classic **Greedy** strategy.

---

# Greedy Observation

Suppose two letters have frequencies:

```
a → 20
b → 2
```

If

```
a costs 2 pushes
b costs 1 push
```

Total cost

```
20×2 + 2×1 = 42
```

Swap them

```
a costs 1 push
b costs 2 pushes

20×1 + 2×2 = 24
```

Much smaller.

So,

> **Higher frequency letters must always receive smaller push counts.**

---

# Approach 1 (HashMap + Sorting)

### Idea

1. Count the frequency of every distinct letter.
2. Sort frequencies in descending order.
3. The first 8 frequencies cost **1 push**.
4. Next 8 cost **2 pushes**.
5. Continue similarly.

---

## Algorithm

1. Count frequencies using HashMap.
2. Store frequencies in a list.
3. Sort in descending order.
4. For every frequency

```
cost = (index / 8) + 1
```

5. Add

```
frequency × cost
```

---

## Java Solution

```java
class Solution {
    public int minimumPushes(String word) {

        Map<Character, Integer> map = new HashMap<>();

        for (char ch : word.toCharArray()) {
            map.put(ch, map.getOrDefault(ch, 0) + 1);
        }

        List<Integer> freq = new ArrayList<>(map.values());

        freq.sort(Collections.reverseOrder());

        int ans = 0;

        for (int i = 0; i < freq.size(); i++) {
            ans += freq.get(i) * (i / 8 + 1);
        }

        return ans;
    }
}
```
