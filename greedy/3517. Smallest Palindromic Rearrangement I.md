# 3517. Smallest Palindromic Rearrangement I

**Difficulty:** Medium  
**Topics:** Greedy, String, Counting

---

## Problem

You are given a **palindromic string** `s`.

Return the **lexicographically smallest palindromic permutation** of `s`.

It is guaranteed that the given string can always be rearranged into a palindrome.

---

## Example

### Example 1

```text
Input: s = "z"

Output: "z"
```

**Explanation**

A single character is already the smallest possible palindrome.

---

### Example 2

```text
Input: s = "cabbac"

Output: "abccba"
```

**Explanation**

Possible palindromic rearrangements include:

```
abccba
acbbca
baccab
...
```

Among them,

```
abccba
```

is lexicographically smallest.

---

# Intuition

A palindrome is completely determined by:

- its **left half**
- an optional **middle character** (for odd length)
- the mirror image of the left half

Since the input itself is already a palindrome,

- the **first half already contains exactly half of every character's occurrences**
- the middle character (if any) is fixed.

Therefore,

1. Count the characters in the **first half**.
2. Arrange them in **sorted order**.
3. Mirror them to form the right half.

Sorting the first half guarantees the smallest lexicographical palindrome.

---

# Approach

1. Store the middle character (only if the length is odd).
2. Count frequencies of characters only in the **first half**.
3. Build the left half in alphabetical order.
4. Reverse it to obtain the right half.
5. Return:

```
left + middle + reverse(left)
```

---

# Algorithm

1. Let `middle` be the center character if the length is odd.
2. Traverse only the first half of the string.
3. Count character frequencies.
4. Build the smallest possible left half by appending characters from `'a'` to `'z'`.
5. Reverse the left half.
6. Concatenate:

```
left + middle + reversed(left)
```

---

# Java Solution

```java
class Solution {
    public String smallestPalindrome(String s) {
        int[] freq = new int[26];
        int n = s.length();

        String middle = (n % 2 == 0) ? "" : String.valueOf(s.charAt(n >> 1));

        n >>= 1;

        for (int i = 0; i < n; i++) {
            freq[s.charAt(i) - 'a']++;
        }

        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < 26; i++) {
            sb.append(String.valueOf((char)(i + 'a')).repeat(freq[i]));
        }

        return sb.toString() + middle + sb.reverse().toString();
    }
}
```

# Dry Run

### Input

```text
s = "cabbac"
```

First half:

```text
cab
```

Frequency:

```
a → 1
b → 1
c → 1
```

Sorted left half:

```
abc
```

Reverse:

```
cba
```

Final palindrome:

```
abc + "" + cba

= abccba
```

---

### Odd Length Example

```text
s = "racecar"
```

Middle character:

```
e
```

First half:

```
rac
```

Sorted:

```
acr
```

Reverse:

```
rca
```

Result:

```
acr + e + rca

= acrerca
```

This is the lexicographically smallest palindromic rearrangement.

---

# Why Greedy Works

A palindrome is completely determined by its left half.

To obtain the smallest lexicographical palindrome, we should make the **left half as small as possible**.

Placing smaller characters earlier automatically minimizes the entire palindrome because:

- the right half is fixed as the mirror image,
- the middle character (if present) is fixed.

Thus, sorting the left half is always optimal.

---

# Complexity Analysis

- **Time Complexity:** `O(n)`
  - Counting characters: `O(n/2)`
  - Building the answer: `O(n)`

- **Space Complexity:** `O(26)` ≈ `O(1)`

---

# Key Takeaways

- Since the input is already a palindrome, only the **first half** needs to be processed.
- The second half is simply the mirror image.
- The middle character never changes.
- Build the left half in sorted order to obtain the lexicographically smallest palindrome.
- This is a **Greedy + String + Counting** problem.
