# 3014. Minimum Number of Pushes to Type Word I

**Difficulty:** Easy  
**Topics:** Greedy, Math, Simulation

---

## Problem

You are given a string `word` containing **distinct lowercase English letters**.

You can freely remap the letters to the **8 available keys (2–9)** on a phone keypad.

- The **first letter** assigned to a key requires **1 push**.
- The **second letter** on the same key requires **2 pushes**.
- The **third letter** requires **3 pushes**, and so on.

Return the **minimum number of pushes** required to type the word.

---

## Example

### Example 1

```text
Input: word = "abcde"

Output: 5
```

**Explanation**

There are only 5 letters, so each can be assigned as the first letter of a different key.

```
1 + 1 + 1 + 1 + 1 = 5
```

---

### Example 2

```text
Input: word = "abcdefghijkl"

Output: 16
```

**Explanation**

- First 8 letters → 1 push each
- Remaining 4 letters → 2 pushes each

```
8 × 1 + 4 × 2 = 16
```

---

# Intuition

Since the letters are **distinct**, every letter appears exactly once.

To minimize the total number of pushes:

- Put **up to 8 letters** in the **first position** of each key (cost = 1).
- Next **8 letters** occupy the second position (cost = 2).
- Next **8 letters** cost 3 pushes, and so on.

Every group of **8 letters** has the same push count.

---

# Approach

1. Let `k = word.length()`.
2. Process the letters in groups of **8**.
3. Maintain the current push count (`1, 2, 3...`).
4. Add:

   - `8 × pushCount` if at least 8 letters remain.
   - Otherwise `remaining × pushCount`.

5. Continue until all letters are assigned.

---

# Algorithm

1. Count the number of letters.
2. Initialize:
   - `answer = 0`
   - `push = 1`
3. While letters remain:
   - Assign at most 8 letters.
   - Add their contribution.
   - Increase push count.
4. Return the answer.

---

# Java Solution

```java
class Solution {
    public int minimumPushes(String word) {
        int k = word.length();

        if (k <= 8) {
            return k;
        }

        int ans = 0;
        int push = 1;

        while (k > 0) {
            if (k >= 8) {
                ans += 8 * push;
            } else {
                ans += k * push;
            }

            k -= 8;
            push++;
        }

        return ans;
    }
}
```

# Why Greedy Works

Each letter contributes exactly once.

To minimize the total pushes:

- Assign as many letters as possible to **push count = 1**
- Then assign the remaining to **push count = 2**
- Then **3**, and so on.

Since there are **8 keys**, each push level can accommodate **at most 8 letters**.

Any other arrangement would place some letter at a higher push count unnecessarily, increasing the total cost.

Thus, the greedy assignment is optimal.

# Complexity Analysis

- **Time Complexity:** `O(1)` (maximum 26 letters)
- **Space Complexity:** `O(1)`

---

# Key Takeaways

- Classic **Greedy** problem.
- Fill the **cheapest push positions first**.
- Every group of **8 letters** shares the same push count.
- No sorting or frequency counting is required because all letters are distinct.
