# 402. Remove K Digits

**Difficulty:** Medium  
**Topics:** Greedy, Monotonic Stack, String

---

# Problem Statement

Given a non-negative integer represented as a string `num` and an integer `k`, remove exactly `k` digits so that the remaining number is the **smallest possible**.

Return the resulting number as a string.

> **Note:** The answer should not contain leading zeros. If all digits are removed, return `"0"`.

---

# Intuition

To make a number as small as possible, we want **smaller digits to appear earlier**.

If we encounter a digit that is smaller than the previous digit, keeping the larger previous digit would only increase the number.

So,

- Remove larger digits that appear before a smaller digit.
- Continue removing as long as we still have deletions (`k > 0`).

This naturally leads to a **Monotonic Increasing Stack**.

---

# Greedy Rule

While processing each digit,

If

```
Stack Top > Current Digit
```

and

```
k > 0
```

then remove the stack top.

Condition:

```java
while (!stack.isEmpty()
       && stack.peek() > currentDigit
       && k > 0)
```

This ensures smaller digits move towards the front, producing the smallest possible number.

# Why Remove Remaining Digits?

Suppose

```
num = "12345"

k = 2
```

The digits are already increasing.

Nothing gets removed during traversal.

After processing,

```
Stack

[1,2,3,4,5]
```

Still need to remove `2` digits.

Remove from the end.

```
123
```

Hence,

```java
while (k > 0)
    stack.pop();
```

# Why Remove Leading Zeros?

Example

```
num = "10200"

k = 1
```

After removing `1`

```
0200
```

Leading zeros are not allowed.

Remove them.

Result

```
200
```

If everything becomes empty,

Return

```
0
```

# Algorithm

1. Traverse every digit.
2. While:
   - stack is not empty,
   - current digit is smaller than stack top,
   - and `k > 0`,
   pop the stack.
3. Push the current digit.
4. If deletions remain, remove digits from the end.
5. Build the answer from the stack.
6. Remove leading zeros.
7. If the result is empty, return `"0"`.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)`

Each digit is pushed and popped at most once.

---

## Java Solution

```java
class Solution {

    public String removeKdigits(String num, int k) {

        Stack<Character> stack = new Stack<>();

        for (char digit : num.toCharArray()) {

            while (!stack.isEmpty()
                    && stack.peek() > digit
                    && k > 0) {

                stack.pop();
                k--;
            }

            stack.push(digit);
        }

        while (k > 0 && !stack.isEmpty()) {
            stack.pop();
            k--;
        }

        StringBuilder sb = new StringBuilder();

        while (!stack.isEmpty()) {
            sb.append(stack.pop());
        }

        sb.reverse();

        int i = 0;

        while (i < sb.length() && sb.charAt(i) == '0') {
            i++;
        }

        String ans = sb.substring(i);

        return ans.isEmpty() ? "0" : ans;
    }
}
```

# Key Takeaways

- Use a **monotonic increasing stack**.
- Remove larger previous digits whenever a smaller digit appears.
- If removals remain after traversal, remove digits from the end.
- Always remove leading zeros before returning the answer.
- Each digit is pushed and popped at most once, giving an **`O(n)`** solution.

### Memory Trick

```
Smaller digit arrives?

↓

Still have removals?

↓

Pop larger digits

↓

Push current digit
```

```
Traversal finished?

↓

Still k > 0?

↓

Remove from end

↓

Remove leading zeros

↓

Return answer
```

> This is one of the classic applications of the **Greedy + Monotonic Stack** pattern and is closely related to problems like **1673. Most Competitive Subsequence**, **316. Remove Duplicate Letters**, and **1081. Smallest Subsequence of Distinct Characters**.
