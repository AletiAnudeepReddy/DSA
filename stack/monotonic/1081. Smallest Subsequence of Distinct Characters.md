# 1081. Smallest Subsequence of Distinct Characters

**Difficulty:** Medium  
**Topics:** Monotonic Stack, Greedy, String

---

# Problem Statement

Given a string `s`, return the **lexicographically smallest subsequence** that contains **every distinct character exactly once**.

A **subsequence** is formed by deleting zero or more characters without changing the order of the remaining characters.

---

# Intuition

We need to satisfy two conditions:

- Every distinct character should appear **exactly once**.
- The resulting subsequence should be **lexicographically smallest**.

This is a classic **Greedy + Monotonic Stack** problem.

For every character:

- Ignore it if it is already included.
- Otherwise, try to place it as early as possible.
- If the current character is smaller than the stack's top, remove the larger character **only if it appears again later**.

This greedy choice always leads to the smallest possible answer.

---

# Key Observations

We need two pieces of information:

### 1. Last Occurrence of Every Character

Store the last index where each character appears.

```
last[ch] = last index of ch
```

Example

```
s = "bcabc"

Character : Last Index

b : 3
c : 4
a : 2
```

This tells us whether a character can be safely removed because it will appear again later.

---

### 2. Visited Array

```
visited[ch] = true
```

means the character is already present in the stack.

This prevents duplicate characters.

---

# Greedy Rule

While processing a character:

```
Current Character < Stack Top
```

AND

```
Stack Top appears again later
```

Then remove the stack top.

Condition in code:

```java
while (!stack.isEmpty()
       && stack.peek() > ch
       && last[stack.peek() - 'a'] > i)
```

# Algorithm

1. Store the last occurrence of every character.
2. Traverse the string.
3. Skip the character if it is already visited.
4. Otherwise:
   - Remove larger characters from the stack while they appear again later.
5. Push the current character.
6. Mark it as visited.
7. Build the answer from the stack.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(26)` = `O(1)`

Each character is pushed and popped at most once.

---

## Java Solution

```java
class Solution {

    public String smallestSubsequence(String s) {

        int[] last = new int[26];

        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i;
        }

        Stack<Character> stack = new Stack<>();
        boolean[] visited = new boolean[26];

        for (int i = 0; i < s.length(); i++) {

            char ch = s.charAt(i);

            if (visited[ch - 'a']) {
                continue;
            }

            while (!stack.isEmpty()
                    && stack.peek() > ch
                    && last[stack.peek() - 'a'] > i) {

                visited[stack.pop() - 'a'] = false;
            }

            stack.push(ch);
            visited[ch - 'a'] = true;
        }

        StringBuilder ans = new StringBuilder();

        for (char c : stack) {
            ans.append(c);
        }

        return ans.toString();
    }
}
```

# Key Takeaways

- Use a **monotonic increasing stack** to build the smallest lexicographical subsequence.
- Store the **last occurrence** of every character to know whether it can be removed safely.
- Use a **visited array** to ensure each character appears only once.
- Pop characters only when:
  - The current character is smaller.
  - The stack top appears again later.
- Each character is pushed and popped at most once, giving an **`O(n)`** solution.

### Memory Trick

```
Already used?

↓

Skip
```

```
Smaller character found?

↓

Can the stack top appear again?

↓

Yes

↓

Pop

↓

Push current character
```

This is one of the most important applications of the **Greedy + Monotonic Stack** pattern.
