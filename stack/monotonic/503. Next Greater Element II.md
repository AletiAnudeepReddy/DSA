503. Next Greater Element II
Problem

Given a circular array, find the next greater element for every element.

The next greater element of nums[i] is the first element encountered while moving to the right that is strictly greater than nums[i].

Because the array is circular, after reaching the last element, we continue from the beginning.

If no greater element exists, return -1.

Example
Input:
nums = [1, 2, 1]

Output:
[2, -1, 2]

For the last 1:

1 -> [back to beginning] -> 2

So its next greater element is 2.

Approach — Monotonic Stack

This is a classic Monotonic Decreasing Stack problem.

The main difficulty is the circular nature of the array.

Normally, for:

[1, 2, 1]

we would stop after reaching the end.

But here we need to imagine the array as:

[1, 2, 1, 1, 2, 1]

So we traverse the array twice.

Instead of actually creating a new array, we use:

nums[i % n]

to simulate the circular array.

Why Monotonic Stack?

Suppose we are processing:

[1, 2, 1]

We want to remember elements that are still waiting for a greater element.

The stack stores indices whose next greater element has not been found yet.

We maintain the stack such that values are in decreasing order from bottom to top.

Whenever we encounter a number greater than the stack's top:

while (!stk.isEmpty() && nums[stk.peek()] < num)

we have found the next greater element for that index.

So:

res[stk.pop()] = num;
Why Do We Traverse 2 * n Elements?

Because the array is circular.

For an array:

[1, 2, 1]

the second 1 needs to look beyond the end:

1 -> 1 -> 2

Therefore, we simulate:

[1, 2, 1, 1, 2, 1]

using:

for (int i = 0; i < 2 * n; i++) {
    int num = nums[i % n];
}

The % n gives us the corresponding original index.

For:

n = 3

we get:

i	i % n	Element
0	0	1
1	1	2
2	2	1
3	0	1
4	1	2
5	2	1

Thus we simulate two complete traversals.

Important Trick — Push Only During the First Traversal

Your code contains:

if (i < n) {
    stk.push(i);
}

This is very important.

We traverse twice to find answers, but we only want each original index to be inserted into the stack once.

Otherwise, during the second traversal we would push duplicate indices.

So:

First traversal:
    Find greater elements
    Push indices

Second traversal:
    Only resolve remaining elements
Code
class Solution {
    public int[] nextGreaterElements(int[] nums) {

        int n = nums.length;

        int[] res = new int[n];
        Arrays.fill(res, -1);

        Stack<Integer> stk = new Stack<>();

        for (int i = 0; i < 2 * n; i++) {

            int num = nums[i % n];

            while (!stk.isEmpty() && nums[stk.peek()] < num) {
                res[stk.pop()] = num;
            }

            if (i < n) {
                stk.push(i);
            }
        }

        return res;
    }
}

Why Do We Use < and Not <=?

The problem asks for a strictly greater element.

Therefore:

nums[stk.peek()] < num

is correct.

Suppose:

nums = [2, 2]

The second 2 is not greater than the first 2.

So the answer is:

[-1, -1]

If we used:

<=

we would incorrectly consider an equal element as the next greater element.

Why Store Indices Instead of Values?

We need to update:

res[index]

when we find a greater element.

Therefore, the stack stores:

indices

not values.

For example:

stack = [0, 2]

means:

nums[0]
nums[2]

are waiting for their next greater elements.

Why Is the Stack Monotonic?

Suppose the stack contains:

[5, 3, 1]

and we encounter:

4

We can resolve:

1 -> 4
3 -> 4

but not 5.

So we pop:

5, 3, 1
      ↑

until the top is greater than or equal to the current value.

This maintains the stack as a monotonic decreasing stack.

Time Complexity

We traverse:

2 * n

elements.

Although there is a while loop inside the for loop, each index is pushed only once and popped at most once.

Therefore:

Time:  O(n)

Not O(n²).

Space Complexity

The stack can contain at most n indices:

Space: O(n)
Key Pattern to Remember

Whenever you see:

Next Greater Element

immediately think:

Monotonic Stack

For a circular array:

Normal NGE:
    traverse n times

Circular NGE:
    traverse 2n times
    use i % n

The general template is:

for (int i = 0; i < 2 * n; i++) {

    int num = nums[i % n];

    while (!stack.isEmpty() && nums[stack.peek()] < num) {
        result[stack.pop()] = num;
    }

    if (i < n) {
        stack.push(i);
    }
}
