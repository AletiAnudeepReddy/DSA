# 78. Subsets

**Difficulty:** Medium  
**Topics:** Backtracking, Bit Manipulation, Recursion

---

## Approach 1: Bit Manipulation (Power Set)

### Intuition

For an array of size `n`, each element has **2 choices**:

- Include it in the subset.
- Exclude it from the subset.

Hence, the total number of subsets is:

```
2 × 2 × ... × 2 = 2ⁿ
```

We can represent every subset using a binary number from `0` to `2ⁿ - 1`.

- Bit `1` → Include the element.
- Bit `0` → Exclude the element.

---

### Example

```
nums = [1,2,3]

Binary   Subset
000      []
001      [1]
010      [2]
011      [1,2]
100      [3]
101      [1,3]
110      [2,3]
111      [1,2,3]
```

For every number from `0` to `(1 << n) - 1`, check each bit and include the corresponding element if that bit is set.

---

### Algorithm

1. Iterate from `0` to `(1 << n) - 1`.
2. For every bit position `i`:
   - If the `i`th bit is set, include `nums[i]`.
3. Add the generated subset to the answer.

---

### Complexity

- **Time Complexity:** `O(n × 2ⁿ)`
- **Space Complexity:** `O(1)` (excluding the output)

---

### Java Solution

```java
class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        int n = nums.length;
        List<List<Integer>> result = new ArrayList<>();

        for (int mask = 0; mask < (1 << n); mask++) {
            List<Integer> subset = new ArrayList<>();

            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) {
                    subset.add(nums[i]);
                }
            }

            result.add(subset);
        }

        return result;
    }
}
```

## Approach 2: Recursion (Backtracking)

### Intuition

For every element, we have two choices:

1. Include it in the current subset.
2. Exclude it from the current subset.

This forms a binary decision tree.

```
                []
              /    \
            1       -
          /  \    /  \
         2    -  2    -
        ...
```

When we reach the end of the array, the current subset is complete.

---

### Algorithm

At index `i`:

- Include `nums[i]` and recurse.
- Backtrack (remove it).
- Exclude `nums[i]` and recurse.

When `i == n`, store the current subset.

---

### Complexity

- **Time Complexity:** `O(n × 2ⁿ)`
- **Space Complexity:** `O(n)` (recursion stack)

---

### Java Solution

```java
class Solution {

    private void recur(int i, int n, int[] nums,
                       List<Integer> subset,
                       List<List<Integer>> result) {

        if (i == n) {
            result.add(new ArrayList<>(subset));
            return;
        }

        // Include current element
        subset.add(nums[i]);
        recur(i + 1, n, nums, subset, result);

        // Backtrack
        subset.remove(subset.size() - 1);

        // Exclude current element
        recur(i + 1, n, nums, subset, result);
    }

    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        recur(0, nums.length, nums, new ArrayList<>(), result);
        return result;
    }
}
```

---

## Key Takeaways

- A set with `n` elements has exactly **2ⁿ subsets**.
- **Bit Manipulation** treats each subset as a binary mask.
- **Backtracking** explores all possible include/exclude decisions recursively.
- Both approaches have **`O(n × 2ⁿ)`** time complexity and are standard solutions for generating the power set.
