# 2220. Minimum Bit Flips to Convert Number

**Difficulty:** Easy  
**Topics:** Bit Manipulation

---

## Intuition

To convert `start` into `goal`, we only need to flip the bits that are different.

The **XOR (`^`)** operation is perfect for finding differing bits:

- `0 ^ 0 = 0`
- `1 ^ 1 = 0`
- `0 ^ 1 = 1`
- `1 ^ 0 = 1`

Thus,

```java
diff = start ^ goal;
```

The `1`s in `diff` represent the bits that need to be flipped.

So, the answer is simply the **number of set bits (1s)** in `diff`.

---

## Example

```
start = 10 = 1010
goal  =  7 = 0111

start ^ goal = 1101
               ↑↑ ↑

There are 3 set bits.
```

Hence, the minimum number of bit flips is **3**.

---

## Algorithm

1. Compute `diff = start ^ goal`.
2. Count the number of set bits in `diff`.
3. Return the count.

---

## Complexity

- **Time Complexity:** `O(31)` ≈ `O(1)`
- **Space Complexity:** `O(1)`

---

## Java Solution

```java
class Solution {
    public int minBitFlips(int start, int goal) {
        int diff = start ^ goal;
        int count = 0;

        for (int i = 0; i < 31; i++) {
            if ((diff & (1 << i)) != 0) {
                count++;
            }
        }

        return count;
    }
}
```

---

## Key Takeaway

- **XOR** identifies the bits that differ between two numbers.
- The **number of set bits in the XOR result** equals the minimum number of bit flips required.
- This is a classic application of **Bit Manipulation + Set Bit Counting**.
