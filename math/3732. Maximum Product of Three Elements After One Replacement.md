# 3732. Maximum Product of Three Elements After One Replacement

**Difficulty:** Medium  
**Topic:** Array, Greedy, Sorting

---

## Problem Statement

You are given an integer array `nums`.

You must replace **exactly one element** in the array with **any integer in the range [-100000, 100000]**.

After performing the replacement, choose **any three distinct elements** from the modified array such that their product is maximized.

Return the maximum possible product.

---

## Key Observation

Since we are allowed to replace **exactly one element** with **either `100000` or `-100000`**, the replacement value should always be one of these extremes.

The only question is:

- Should we replace an element with **100000**?
- Or should we replace an element with **-100000**?

Instead of trying every replacement, we only need to maximize the product of the **other two numbers**.

---

# Approach 1: Sorting (Greedy)

## Intuition

After sorting the array, we only need to check three possible cases.

### Case 1

Replace one element with **100000** and multiply it with the **two largest positive numbers**.

```
largest × secondLargest × 100000
```

---

### Case 2

Replace one element with **100000** and multiply it with the **two smallest (most negative) numbers**.

Since:

```
Negative × Negative = Positive
```

This product may become much larger.

```
smallest × secondSmallest × 100000
```

---

### Case 3

Replace one element with **-100000**.

To obtain a positive product, multiply it with:

- the largest positive number
- the most negative number

```
largest × smallest × (-100000)
```

Since

```
Positive × Negative × Negative = Positive
```

this is another possible maximum.

The answer is simply the maximum among these three values.

---

## Algorithm

1. Sort the array.
2. Compute:
   - Largest × Second Largest × 100000
   - Smallest × Second Smallest × 100000
   - Largest × Smallest × (-100000)
3. Return the maximum.

---

## Code (Java)

```java
class Solution {
    public long maxProduct(int[] nums) {
        Arrays.sort(nums);

        int n = nums.length - 1;

        long res1 = (long) nums[n] * nums[n - 1] * 100000;
        long res2 = (long) nums[0] * nums[1] * 100000;
        long res3 = (long) nums[0] * nums[n] * (-100000);

        return Math.max(res1, Math.max(res2, res3));
    }
}
```

---

## Dry Run

```
nums = [-5, 7, 0]

[-5, 0, 7]

Case 2

(-5) × 0 × 100000 = 0

Case 3

= 3500000

Answer = 3500000
```

# Approach 2: Greedy (Optimal)

## Intuition

Instead of sorting, notice something even simpler.

The replacement number will always have **absolute value = 100000**.

Therefore,

```
Final Product

= 100000 × (product of two existing numbers)
```

So the problem reduces to:

> **Find two numbers whose product has the maximum possible value.**

---

### Which two numbers produce the largest product?

The product is largest when their **absolute values are largest**.

For example,

```
50 × 40 = 2000

(-90) × (-80) = 7200
```

Although both numbers are negative, their product is much larger.

Therefore, we only need the **two numbers with the largest absolute values**.

Once we have them,

```
Answer

= |largest| × |secondLargest| × 100000
```

because we can always choose the sign (`100000` or `-100000`) to make the final product positive.

---

## Why does this work?

Suppose the two numbers are:

```
a and b
```

Their product can be

- Positive
- Negative

Since we are free to choose either

```
100000
```

or

```
-100000
```

we can always make

```
a × b × replacement
```

positive.

Hence only the **absolute values** matter.

---

## Algorithm

1. Traverse the array once.
2. Keep track of the two largest absolute values.
3. Multiply them by `100000`.
4. Return the result.
