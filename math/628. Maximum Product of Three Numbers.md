628. Maximum Product of Three Numbers

Difficulty: Easy
Topic: Array, Sorting, Greedy

Problem Statement

Given an integer array nums, return the maximum product that can be obtained by multiplying any three numbers.

Approach 1: Sorting (Greedy)
Intuition

After sorting the array, there are only two possible candidates for the maximum product:

Three largest numbers
Product = nums[n-1] * nums[n-2] * nums[n-3]
Two smallest numbers + largest number
If the two smallest numbers are negative, their product becomes positive.
Product = nums[0] * nums[1] * nums[n-1]

The answer is the maximum of these two values.

Algorithm
Sort the array.
Compute:
Product of the three largest numbers.
Product of the two smallest numbers and the largest number.
Return the maximum.
Code (Java)
class Solution {
    public int maximumProduct(int[] nums) {
        int n = nums.length;
        Arrays.sort(nums);

        return Math.max(
            nums[0] * nums[1] * nums[n - 1],
            nums[n - 1] * nums[n - 2] * nums[n - 3]
        );
    }
}
Dry Run

[-10, -10, 1, 2, 3]

Candidate 2:
(-10) × (-10) × 3 = 300

Answer = 300
Complexity Analysis
Time Complexity: O(n log n) (sorting)
Space Complexity: O(1) (excluding sorting space)
Approach 2: Single Pass (Optimal)
Intuition

Sorting is unnecessary because we only need:

The three largest numbers
The two smallest numbers

These five values can be found in one traversal.

Maintain:

max1 → largest
max2 → second largest
max3 → third largest

and

min1 → smallest
min2 → second smallest

Finally compute:

max(max1 × max2 × max3,
    max1 × min1 × min2)
Why do we keep two minimum values?

Because:

Negative × Negative = Positive

Sometimes:

(-100) × (-90) × 10

is much larger than

10 × 9 × 8

Hence both possibilities must be checked.

Algorithm
Traverse the array once.
Update the three largest values.
Update the two smallest values.
Return the maximum of:
max1 * max2 * max3
max1 * min1 * min2
Code (Java)
class Solution {
    public int maximumProduct(int[] nums) {

        int max1 = Integer.MIN_VALUE;
        int max2 = Integer.MIN_VALUE;
        int max3 = Integer.MIN_VALUE;

        int min1 = Integer.MAX_VALUE;
        int min2 = Integer.MAX_VALUE;

        for (int num : nums) {

            // Update largest three numbers
            if (num >= max1) {
                max3 = max2;
                max2 = max1;
                max1 = num;
            } else if (num >= max2) {
                max3 = max2;
                max2 = num;
            } else if (num > max3) {
                max3 = num;
            }

            // Update smallest two numbers
            if (num <= min1) {
                min2 = min1;
                min1 = num;
            } else if (num < min2) {
                min2 = num;
            }
        }

        return Math.max(
            max1 * max2 * max3,
            max1 * min1 * min2
        );
    }
}

Time Complexity: O(n)
Space Complexity: O(1)
Key Observation

The maximum product of three numbers can come from only two cases:

Three largest positive numbers
max1 × max2 × max3
Largest positive number + two most negative numbers
max1 × min1 × min2

Checking these two possibilities guarantees the optimal answer.

Comparison
Approach	Time	Space	Idea
Sorting	O(n log n)	O(1)	Sort and compare the two possible products
Single Pass	O(n)	O(1)	Track the three largest and two smallest values while traversing once

Recommended: The Single Pass approach is optimal because it avoids sorting and computes the answer in linear time using constant extra space.
