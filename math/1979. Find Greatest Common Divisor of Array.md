# 1979. Find Greatest Common Divisor of Array

**Difficulty:** Easy  
**Topics:** Math, GCD (Euclidean Algorithm)

---

## Intuition

The problem asks for the **GCD of only the smallest and largest elements** in the array.

So, we need to:

1. Find the minimum element.
2. Find the maximum element.
3. Compute their GCD using the **Euclidean Algorithm**.

---

## Euclidean Algorithm (GCD)

The GCD of two numbers can be computed using the observation:

```
gcd(a, b) = gcd(b % a, a)
```

Repeat this until `a` becomes `0`.

The remaining value of `b` is the GCD.

### Example

Find `gcd(10, 2)`:

```
gcd(10,2)

10 % 2 = 0

gcd(0,2)

Answer = 2
```

Another example:

```
gcd(48,18)

gcd(18,12)

gcd(12,6)

gcd(6,0)

Answer = 6
```

---

## Algorithm

1. Traverse the array to find:
   - Smallest element
   - Largest element
2. Compute the GCD of these two numbers using the Euclidean Algorithm.
3. Return the result.

---

## Complexity

- **Time Complexity:** `O(n + log(min(max, min)))`
- **Space Complexity:** `O(log(min(max, min)))` *(recursive implementation)*

---

## Java Solution

```java
class Solution {

    public int gcd(int a, int b) {
        if (a == 0) return b;
        return gcd(b % a, a);
    }

    public int findGCD(int[] nums) {

        int smallest = Integer.MAX_VALUE;
        int largest = Integer.MIN_VALUE;

        for (int num : nums) {
            smallest = Math.min(smallest, num);
            largest = Math.max(largest, num);
        }

        return gcd(largest, smallest);
    }
}
```

---

## Key Takeaways

- The GCD is required **only for the smallest and largest elements**, not for the entire array.
- Use the **Euclidean Algorithm** for efficient GCD computation:

  ```
  gcd(a, b) = gcd(b % a, a)
  ```

- First find the minimum and maximum values in one traversal, then compute their GCD.
