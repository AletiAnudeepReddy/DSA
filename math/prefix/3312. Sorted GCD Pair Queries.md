# 3312. Sorted GCD Pair Queries

**Difficulty:** Hard  
**Topics:** Math, GCD, Number Theory, Inclusion-Exclusion, Binary Search, Prefix Sum

---

# Problem Statement

Given an array `nums`, compute the GCD of every possible pair `(i, j)` where `i < j`. Sort all these GCD values into an array `gcdPairs`.

For each query `queries[i]`, return the element at index `queries[i]` in the sorted `gcdPairs` array.

---

# Approach 1: Brute Force

## Intuition

The most straightforward solution is:

1. Generate every possible pair.
2. Compute the GCD of each pair.
3. Store all GCD values.
4. Sort the array.
5. Answer each query directly.

Since there are

```
n(n-1)/2
```

pairs, this approach quickly becomes infeasible for large `n`.

---

## Example

```
nums = [2,3,4]
```

Possible pairs

```
(2,3) -> gcd = 1
(2,4) -> gcd = 2
(3,4) -> gcd = 1
```

```
gcdPairs = [1,2,1]

After sorting

[1,1,2]
```

Queries

```
0 -> 1
2 -> 2
2 -> 2
```

Answer

```
[1,2,2]
```

---

## Euclidean Algorithm (GCD)

The GCD is calculated using the Euclidean Algorithm.

```
gcd(a,b)

=

gcd(b%a,a)
```

until `a` becomes `0`.

Example

```
gcd(24,18)

gcd(18,24%18)
= gcd(18,6)

gcd(6,18%6)
= gcd(6,0)

Answer = 6
```

---

## Complexity

Generating pairs

```
O(n²)
```

Sorting

```
O(n² log n)
```

Overall

- **Time Complexity:** `O(n² log n)`
- **Space Complexity:** `O(n²)`

---

## Java Solution

```java
class Solution {

    public int gcd(int a, int b) {
        if (a == 0) return b;
        return gcd(b % a, a);
    }

    public int[] gcdValues(int[] nums, long[] queries) {

        int n = nums.length;
        int totalPairs = n * (n - 1) / 2;

        int[] pairs = new int[totalPairs];

        int k = 0;

        for (int i = 0; i < n - 1; i++) {
            for (int j = i + 1; j < n; j++) {
                pairs[k++] = gcd(nums[i], nums[j]);
            }
        }

        Arrays.sort(pairs);

        int[] ans = new int[queries.length];

        for (int i = 0; i < queries.length; i++) {
            ans[i] = pairs[(int) queries[i]];
        }

        return ans;
    }
}
```

# Approach 2: Number Theory + Inclusion-Exclusion + Binary Search

## Key Observation

Instead of generating every pair, determine **how many pairs have GCD exactly equal to `d`**.

If we know:

```
GCD = 1 -> x pairs

GCD = 2 -> y pairs

GCD = 3 -> z pairs
```

then the sorted `gcdPairs` array can be reconstructed **without ever generating it**.

---

## Step 1: Frequency Array

Count the occurrence of every number.

Example

```
nums = [2,3,4]

freq

2 -> 1
3 -> 1
4 -> 1
```

---

## Step 2: Count Numbers Divisible by Each Divisor

For every divisor `d`,

count how many numbers are divisible by `d`.

Example

```
d = 2

Numbers divisible by 2

2
4

Count = 2
```

---

## Step 3: Total Pairs Divisible by d

If `count` numbers are divisible by `d`

then

```
pairs

=

countC2

=

count*(count-1)/2
```

Example

```
count = 4

Pairs

4C2

=

6
```

These are all pairs whose GCD is **at least** `d`.

---

## Step 4: Inclusion-Exclusion

The above count includes pairs having GCD

```
2d

3d

4d

...
```

We remove those.

Formula

```
ExactPairs[d]

=

Pairs divisible by d

-

ExactPairs[2d]

-

ExactPairs[3d]

...

```

Therefore we process divisors from

```
max

↓

1
```

because larger GCD values are already known.

---

### Example

Suppose

```
Pairs divisible by 2

=

10
```

Among them

```
GCD = 4

-> 3 pairs

GCD = 6

-> 2 pairs
```

Then

```
ExactPairs[2]

=

10

-

3

-

2

=

5
```

Only **5** pairs have GCD exactly **2**.

---

## Step 5: Prefix Sum

Build

```
prefix[i]

=

Number of pairs

whose gcd ≤ i
```

Example

```
ExactPairs

1 -> 4

2 -> 2

3 -> 1
```

Prefix

```
1 -> 4

2 -> 6

3 -> 7
```

Meaning

```
4 pairs have gcd ≤1

6 pairs have gcd ≤2

7 pairs have gcd ≤3
```

---

## Step 6: Binary Search

For every query

find the smallest GCD whose prefix count exceeds the query index.

Example

```
prefix

1 -> 4

2 -> 6

3 -> 7
```

Query

```
5
```

Since

```
prefix[1]=4

prefix[2]=6
```

The 5th element belongs to GCD

```
2
```

Hence answer is

```
2
```

---

## Complexity

Let

```
M = maximum element in nums
```

Frequency

```
O(n)
```

Counting multiples

```
O(M log M)
```

Prefix

```
O(M)
```

Binary Search

```
O(q log M)
```

Overall

- **Time Complexity:** `O(M log M + q log M)`
- **Space Complexity:** `O(M)`

---

## Java Solution

```java
import java.util.*;

class Solution {

    public int[] gcdValues(int[] nums, long[] queries) {

        int max = 0;
        for (int x : nums)
            max = Math.max(max, x);

        int[] freq = new int[max + 1];
        for (int x : nums)
            freq[x]++;

        long[] exactPairs = new long[max + 1];

        for (int d = max; d >= 1; d--) {

            long count = 0;

            for (int multiple = d; multiple <= max; multiple += d) {
                count += freq[multiple];
            }

            long pairs = count * (count - 1) / 2;

            for (int multiple = 2 * d; multiple <= max; multiple += d) {
                pairs -= exactPairs[multiple];
            }

            exactPairs[d] = pairs;
        }

        long[] prefix = new long[max + 1];

        for (int i = 1; i <= max; i++) {
            prefix[i] = prefix[i - 1] + exactPairs[i];
        }

        int[] ans = new int[queries.length];

        for (int i = 0; i < queries.length; i++) {

            long q = queries[i];

            int l = 1;
            int r = max;

            while (l < r) {

                int mid = l + (r - l) / 2;

                if (prefix[mid] > q)
                    r = mid;
                else
                    l = mid + 1;
            }

            ans[i] = l;
        }

        return ans;
    }
}
```

# Key Takeaways

- **Brute Force** generates every pair, computes the GCD, sorts the results, and answers queries directly. It is simple but infeasible for large inputs.
- The **optimal solution** avoids generating pairs entirely by counting how many pairs have each possible GCD.
- Use **frequency counting** to determine how many numbers are divisible by each divisor.
- Apply **Inclusion-Exclusion** to compute the number of pairs with **GCD exactly `d`**.
- Build a **prefix sum** of GCD frequencies to represent the sorted `gcdPairs` array implicitly.
- Use **binary search** on the prefix array to answer each query efficiently.

> **Core Idea:** Instead of constructing the sorted GCD array, compute its frequency distribution mathematically and answer queries using prefix sums.
