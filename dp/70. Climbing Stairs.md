70. Climbing Stairs
Problem

You are climbing a staircase with n steps.

At each move, you can climb either:

1 step
2 steps

Return the number of distinct ways to reach exactly the top.

Example

For:

n = 2

There are two ways:

1 + 1
2

So the answer is:

2
Approach: Dynamic Programming

The key observation is:

To reach step i, your previous position must be either i - 1 or i - 2.

Therefore:

dp[i] = dp[i-1] + dp[i-2]
Base Cases

For n = 0:

dp[0] = 1

There is one way to reach step 0: do nothing.

For n = 1:

dp[1] = 1

Only:

1
Why is this Fibonacci?

The sequence becomes:

dp[0] = 1
dp[1] = 1
dp[2] = 2
dp[3] = 3
dp[4] = 5
dp[5] = 8
...

So Climbing Stairs is essentially a Fibonacci pattern.

Code
class Solution {
    public int climbStairs(int n) {

        if (n == 1 || n == 0) {
            return 1;
        }

        int[] dp = new int[n + 1];

        dp[0] = 1;
        dp[1] = 1;

        for (int i = 2; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }

        return dp[n];
    }
}
Dry Run

Let's take:

n = 5

Initially:

dp[0] = 1
dp[1] = 1
i = 2
dp[2] = dp[1] + dp[0]
      = 1 + 1
      = 2
i = 3
dp[3] = dp[2] + dp[1]
      = 2 + 1
      = 3
i = 4
dp[4] = dp[3] + dp[2]
      = 3 + 2
      = 5
i = 5
dp[5] = dp[4] + dp[3]
      = 5 + 3
      = 8

Therefore:

Answer = 8

The 8 ways are:

1+1+1+1+1
1+1+1+2
1+1+2+1
1+2+1+1
2+1+1+1
1+2+2
2+1+2
2+2+1
Recurrence

The DP relation is:

dp[i] = dp[i-1] + dp[i-2]

Why?

Suppose we want to reach step i.

Case 1: Last move is 1 step

We must have been at:

i - 1

Number of ways:

dp[i-1]
Case 2: Last move is 2 steps

We must have been at:

i - 2

Number of ways:

dp[i-2]

Therefore:

dp[i] = dp[i-1] + dp[i-2]
Space Optimized Approach

We actually don't need the entire dp array.

To calculate:

dp[i]

we only need:

dp[i-1]
dp[i-2]

So we can keep just two variables.

class Solution {
    public int climbStairs(int n) {

        if (n <= 1) {
            return 1;
        }

        int prev2 = 1; // dp[i-2]
        int prev1 = 1; // dp[i-1]

        for (int i = 2; i <= n; i++) {

            int curr = prev1 + prev2;

            prev2 = prev1;
            prev1 = curr;
        }

        return prev1;
    }
}
Example
prev2 = dp[0] = 1
prev1 = dp[1] = 1

i=2 → curr=2
i=3 → curr=3
i=4 → curr=5
i=5 → curr=8
Complexity
Your DP Array Solution

Time:

O(n)

We calculate every dp[i] once.

Space:

O(n)

because of the dp array.

Space-Optimized Solution

Time:

O(n)

Space:

O(1)

because we only maintain three integer variables.

DP Pattern to Remember

This is one of the most important introductory DP patterns:

Current state
     ↓
Can come from previous 1 step
     +
Can come from previous 2 steps
     ↓
dp[i] = dp[i-1] + dp[i-2]

Whenever you see a problem where you can reach a state through a small number of previous states, think:

"Can I define dp[i] as the number of ways to reach state i?"
