198. House Robber
Problem

You are given an array nums, where nums[i] represents the money in the i-th house.

You cannot rob two adjacent houses.

Return the maximum amount of money you can rob.

Example
nums = [2,7,9,3,1]

Rob:
2 + 9 + 1 = 12

Answer = 12
Intuition

At every house, we have two choices:

Pick/Rob the current house

If we rob house ind, we cannot rob ind - 1.
Therefore:
pick = nums[ind] + recur(ind - 2)

Don't pick the current house

We simply consider the previous house.
notPick = recur(ind - 1)

So:

dp[ind] = max(
    nums[ind] + dp[ind - 2],
    dp[ind - 1]
)

The important idea is:

Pick current → skip previous
Don't pick current → move to previous

1. Recursive Solution
Base Cases

If we reach the first house:

if(ind == 0) return nums[ind];

If we go before the first house:

if(ind < 0) return 0;
Code
class Solution {

    private int recur(int ind, int[] nums) {

        // Only the first house is left
        if (ind == 0) {
            return nums[ind];
        }

        // No houses left
        if (ind < 0) {
            return 0;
        }

        // Pick current house
        int pick = nums[ind] + recur(ind - 2, nums);

        // Don't pick current house
        int notPick = recur(ind - 1, nums);

        return Math.max(pick, notPick);
    }

    public int rob(int[] nums) {
        int n = nums.length;

        return recur(n - 1, nums);
    }
}
2. Dry Run — Recursion

Consider:

nums = [2, 7, 9, 3, 1]

Start:

recur(4)

At house 4:

pick    = 1 + recur(2)
notPick = recur(3)

For recur(2):

pick    = 9 + recur(0)
        = 9 + 2
        = 11

notPick = recur(1)
        = 7

Therefore:

recur(2) = 11

For recur(3):

pick    = 3 + recur(1)
        = 3 + 7
        = 10

notPick = recur(2)
        = 11

Therefore:

recur(3) = 11

Finally:

recur(4)

pick    = 1 + 11 = 12
notPick = 11

answer = max(12, 11)
       = 12

So:

Answer = 12
3. Problem With Pure Recursion

The recursive solution repeatedly calculates the same states.

For example:

recur(4)
├── recur(2)
│   ├── recur(0)
│   └── recur(1)
└── recur(3)
    ├── recur(1)   ← repeated
    └── recur(2)   ← repeated

recur(1) and recur(2) are calculated multiple times.

This creates exponential time complexity.

We can solve this using Dynamic Programming / Memoization.

4. Memoization — Top Down DP

We store the answer for every ind in dp[ind].

If we have already calculated it:

if(dp[ind] != -1) return dp[ind];

Then calculate it only once.

Code
class Solution {

    private int recur(int ind, int[] nums, int[] dp) {

        if (ind == 0) {
            return nums[ind];
        }

        if (ind < 0) {
            return 0;
        }

        // Already calculated
        if (dp[ind] != -1) {
            return dp[ind];
        }

        // Pick current house
        int pick = nums[ind] + recur(ind - 2, nums, dp);

        // Don't pick current house
        int notPick = recur(ind - 1, nums, dp);

        return dp[ind] = Math.max(pick, notPick);
    }

    public int rob(int[] nums) {

        int n = nums.length;

        int[] dp = new int[n];

        Arrays.fill(dp, -1);

        return recur(n - 1, nums, dp);
    }
}
5. Dry Run — Memoization

For:

nums = [2,7,9,3,1]

Initially:

dp = [-1, -1, -1, -1, -1]

Calculate recur(4).

recur(4)
pick = 1 + recur(2)
notPick = recur(3)
recur(2)
pick = 9 + recur(0)
     = 9 + 2
     = 11

notPick = recur(1)
        = 7

dp[2] = 11

Now:

dp = [-1, 7, 11, -1, -1]
recur(3)
pick = 3 + recur(1)
     = 3 + 7
     = 10

notPick = recur(2)

But:

dp[2] = 11

So we don't calculate recur(2) again.

dp[3] = max(10, 11)
      = 11

Finally:

dp[4] = max(
    1 + dp[2],
    dp[3]
)

     = max(12, 11)
     = 12

Final:

dp = [2, 7, 11, 11, 12]

Answer:

12
Complexity
Pure Recursion

There are overlapping recursive calls.

Time:  O(2^n)
Space: O(n)

The O(n) space comes from the recursion stack.

Memoization

Each index is calculated only once.

For every state, we perform constant work.

Time:  O(n)
Space: O(n)

O(n) space includes the dp array and recursion stack.

Key Pattern to Remember

This is one of the most important 1D DP patterns.

For each index:

                    Current House
                    /           \
                  Pick        Don't Pick
                   |              |
            nums[i] + dp[i-2]    dp[i-1]

Therefore:

dp[i] = max(nums[i] + dp[i-2], dp[i-1])
Recognition Pattern

Whenever you see:

Choose an element, but you cannot choose its adjacent element

think:

Pick     → i - 2
Not Pick → i - 1

This exact pattern appears in many problems, including House Robber II and other subsequence-style DP problems.
