120. Triangle
🧩 Problem

You are given a triangle represented as a list of rows.

Starting from the top, at every position (i, j), you can move to:

Down → (i + 1, j)
Diagonal → (i + 1, j + 1)

Find the minimum path sum from the top of the triangle to the bottom.

Example
       2
      / \
     3   4
    / \ / \
   6   5   7
  / \ / \ / \
 4   1   8   3

Minimum path:

2 → 3 → 5 → 1

Sum:

2 + 3 + 5 + 1 = 11
💡 Approach 1: Recursion
Intuition

At every cell (i, j), we have exactly two choices:

             (i,j)
             /   \
            /     \
     (i+1,j)     (i+1,j+1)
       Down         Diagonal

So we calculate:

down = current + recur(i+1, j)
diag = current + recur(i+1, j+1)

Then take the minimum:

min(down, diag)
Base Case

When we reach the last row:

if(i == n)
    return triangle.get(i).get(j);

There are no more choices, so simply return the current value.

Code — Recursive Solution
class Solution {

    private int recur(int i, int j, int n, int m,
                      List<List<Integer>> grid) {

        // Reached the last row
        if (i == n) {
            return grid.get(i).get(j);
        }

        // Move down
        int down = grid.get(i).get(j)
                   + recur(i + 1, j, n, m, grid);

        // Move diagonally
        int diag = grid.get(i).get(j)
                   + recur(i + 1, j + 1, n, m, grid);

        return Math.min(down, diag);
    }

    public int minimumTotal(List<List<Integer>> triangle) {

        int n = triangle.size();
        int m = triangle.get(0).size();

        return recur(0, 0, n - 1, m - 1, triangle);
    }
}
⚠️ Problem with recursion

The same states are calculated repeatedly.

For example:

        (0,0)
       /     \
    (1,0)   (1,1)
      \       /
       (2,1)

(2,1) can be reached through multiple paths, so recursion recalculates it.

This makes the recursive solution exponential.

🚀 Approach 2: Dynamic Programming — Bottom Up

This is the better solution.

Key idea

Start from the last row.

The last row already contains the minimum cost from each position to the bottom because those cells are already at the bottom.

For:

       2
      3 4
     6 5 7
    4 1 8 3

Initialize:

dp[last row] = [4, 1, 8, 3]

Now move upward.

For 5:

5 + min(1, 8)
= 6

For 6:

6 + min(4, 1)
= 7

For 7:

7 + min(8, 3)
= 10

So:

       2
      3  4
     7  6 10
    4  1  8  3

Next:

3 + min(7, 6) = 9
4 + min(6, 10) = 10

Finally:

2 + min(9, 10) = 11

Answer:

11
✅ Code — Bottom-Up DP
class Solution {

    public int minimumTotal(List<List<Integer>> triangle) {

        int n = triangle.size();

        int[][] dp = new int[n][n];

        // Copy the last row
        for (int i = 0; i < n; i++) {
            dp[n - 1][i] = triangle.get(n - 1).get(i);
        }

        // Move from bottom to top
        for (int i = n - 2; i >= 0; i--) {

            for (int j = i; j >= 0; j--) {

                int down =
                    triangle.get(i).get(j)
                    + dp[i + 1][j];

                int diag =
                    triangle.get(i).get(j)
                    + dp[i + 1][j + 1];

                dp[i][j] = Math.min(down, diag);
            }
        }

        return dp[0][0];
    }
}

⏱️ Complexity

Let n be the number of rows.

The triangle contains approximately:

1 + 2 + 3 + ... + n
= n(n+1)/2
= O(n²)
Recursive solution
Time:  O(2^n)
Space: O(n)

The O(n) space is due to the recursion stack.

Bottom-Up DP
Time:  O(n²)
Space: O(n²)

because we use a n × n DP table.

⭐ Important DP Pattern

This problem is a classic 2D grid/triangle DP.

The state is:

dp[i][j] = minimum path sum from (i,j) to the bottom

The transition is:

dp[i][j] =
    triangle[i][j]
    + min(dp[i+1][j], dp[i+1][j+1])

This is the most important part to remember:

             dp[i][j]
              /    \
             /      \
     dp[i+1][j]   dp[i+1][j+1]

So whenever you see a problem where each position has two possible downward choices, think:

"Can I define the minimum/maximum answer from this position to the end?"

That naturally leads to top-down memoization or bottom-up DP.
