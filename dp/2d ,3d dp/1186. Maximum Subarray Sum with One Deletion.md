1186. Maximum Subarray Sum with One Deletion
Problem

Given an integer array arr, find the maximum sum of a non-empty subarray after deleting at most one element.

The remaining elements must still form a contiguous subarray after the deletion.

Example
arr = [1, -2, 0, 3]

Delete -2:

[1, 0, 3]

Sum:

1 + 0 + 3 = 4

Answer: 4

Approach 1: DP + Memoization

We can define a DP state using:

solve(i, deleted)

where:

i = current index
deleted = 0 → we haven't deleted any element yet
deleted = 1 → we have already deleted one element

For every element, we have two choices.

Choice 1: Keep the current element

We add arr[i] to the current subarray:

arr[i] + solve(i + 1, deleted)
Choice 2: Delete the current element

We can only do this if we haven't deleted anything yet:

solve(i + 1, 1)

Therefore:

if deleted == 0:


    answer = max(
        keep current element,
        delete current element
    )

We use memoization because the same (i, deleted) states are calculated multiple times.

There are only:

n × 2

different states.

Java Code — DP + Memoization
class Solution {


    Integer[][] memo;


    public int maximumSum(int[] arr) {


        int n = arr.length;
        memo = new Integer[n][2];


        int answer = Integer.MIN_VALUE;


        for (int i = 0; i < n; i++) {
            answer = Math.max(answer, solve(arr, i, 0));
            answer = Math.max(answer, solve(arr, i, 1));
        }


        return answer;
    }


    private int solve(int[] arr, int i, int deleted) {


        if (i == arr.length) {
            return 0;
        }


        if (memo[i][deleted] != null) {
            return memo[i][deleted];
        }


        // Keep current element
        int keep = arr[i] + solve(arr, i + 1, deleted);


        int answer = keep;


        // Delete current element
        if (deleted == 0) {
            int delete = solve(arr, i + 1, 1);
            answer = Math.max(answer, delete);
        }


        return memo[i][deleted] = answer;
    }
}
Complexity
Time  = O(n)
Space = O(n)

O(n) space comes from the memoization table and recursion stack.

Approach 2: Space-Optimized DP

The previous DP has only two states for every index:

no deletion
one deletion

So we don't actually need to store the entire DP table.

We only need the values from the previous index.

We maintain:

nodel → maximum sum ending at current index with no deletion


onedel → maximum sum ending at current index with one deletion
Transition for nodel

Either:

Extend the previous subarray.
Start a new subarray from arr[i].
newNo = Math.max(nodel + arr[i], arr[i]);
Transition for onedel

There are two possibilities:

1. We already deleted an element earlier

onedel + arr[i]

2. Delete the current element

Then we take the previous nodel:

nodel

So:

newOne = Math.max(onedel + arr[i], nodel);

This is the same DP logic as Approach 1, but we only keep the previous values.

Java Code — Space Optimized
class Solution {


    public int maximumSum(int[] arr) {


        int nodel = arr[0];
        int onedel = 0;


        int ans = arr[0];


        for (int i = 1; i < arr.length; i++) {


            // No deletion
            int newNo = Math.max(
                nodel + arr[i],
                arr[i]
            );


            // One deletion
            int newOne = Math.max(
                onedel + arr[i],
                nodel
            );


            nodel = newNo;
            onedel = newOne;


            ans = Math.max(
                ans,
                Math.max(nodel, onedel)
            );
        }


        return ans;
    }
}
Dry Run — Approach 2
arr = [1, -2, 0, 3]

Initial:

nodel = 1
onedel = 0
ans = 1
arr[i] = -2
newNo = max(1 + (-2), -2)
      = -1


newOne = max(0 + (-2), 1)
       = 1

Here, newOne = 1 means we deleted -2.

nodel = -1
onedel = 1
arr[i] = 0
newNo = max(-1 + 0, 0)
      = 0


newOne = max(1 + 0, -1)
       = 1
nodel = 0
onedel = 1
arr[i] = 3
newNo = max(0 + 3, 3)
      = 3


newOne = max(1 + 3, 0)
       = 4

Therefore:

answer = 4

The chosen elements are:

[1, -2, 0, 3]
     ↑
   delete

Result:

[1, 0, 3] → 4
Time & Space Complexity
Approach 1: Memoization
Time  = O(n)
Space = O(n)
Approach 2: Space Optimized DP
Time  = O(n)
Space = O(1)
Key Takeaways
This problem is a variation of Kadane's Algorithm.
DP state has two possibilities:
No deletion
One deletion
The first approach stores these states using memoization.
The second approach observes that we only need the previous state, so we reduce space from O(n) to O(1).
The important transition is:
newOne = max(
    onedel + arr[i],   // deletion already used
    nodel              // delete current element
)
Both approaches have O(n) time.
Approach 2 is the optimized version because it uses O(1) extra space.
