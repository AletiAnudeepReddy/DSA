525. Contiguous Array
Problem

Given a binary array nums, find the maximum length of a contiguous subarray containing an equal number of 0s and 1s.

Example
nums = [0, 1, 0]

Valid subarrays are:

[0, 1] → one 0, one 1 → length 2
[1, 0] → one 1, one 0 → length 2

So the answer is:

2
Approach 1: Brute Force

We can consider every possible subarray using two loops.

For each starting index i, extend the subarray using j and maintain:

even = number of 0s
odd  = number of 1s

Whenever:

even == odd

we have found a valid subarray.

Its length is:

j - i + 1
Java Code
class Solution {
    public int findMaxLength(int[] nums) {


        int n = nums.length;
        int ans = 0;


        for (int i = 0; i < n; i++) {


            int zero = 0;
            int one = 0;


            for (int j = i; j < n; j++) {


                if (nums[j] == 0) {
                    zero++;
                } else {
                    one++;
                }


                if (zero == one) {
                    ans = Math.max(ans, j - i + 1);
                }
            }
        }


        return ans;
    }
}
Complexity
Time  = O(n²)
Space = O(1)

This is too slow for n = 10^5.

Approach 2: Prefix Sum + HashMap

The key idea is to convert the problem into a prefix sum problem.

Instead of counting 0 and 1 separately, assign:

0 → -1
1 → +1

Now a subarray has an equal number of 0s and 1s if its sum is 0.

Why?

Suppose:

[0, 1, 1, 0]

After conversion:

[-1, +1, +1, -1]

Sum:

-1 + 1 + 1 - 1 = 0

So equal number of 0s and 1s means:

prefixSum[j] == prefixSum[i - 1]

If the same prefix sum occurs at two different positions, the elements between those positions have sum 0.

Why Store the First Occurrence?

Suppose the same prefix sum appears at:

index 2
index 7

Then the subarray between them has sum 0, and its length is:

7 - 2 = 5

To get the longest subarray, we should always store the first occurrence of each prefix sum.

That's why we only do:

if (!mpp.containsKey(sum)) {
    mpp.put(sum, i);
}

and never update an existing index.

Why mpp.put(0, -1)?

Initially:

sum = 0

before processing any elements.

We store:

mpp.put(0, -1);

This handles subarrays starting from index 0.

For example:

nums = [0, 1]

Prefix sums:

index    sum
 -1       0
  0      -1
  1       0

At index 1, sum 0 was already seen at -1.

Therefore:

length = 1 - (-1) = 2
Java Code
class Solution {


    public int findMaxLength(int[] nums) {


        Map<Integer, Integer> map = new HashMap<>();


        int sum = 0;
        int ans = 0;


        // Prefix sum before the array starts
        map.put(0, -1);


        for (int i = 0; i < nums.length; i++) {


            // 0 contributes -1
            // 1 contributes +1
            if (nums[i] == 0) {
                sum--;
            } else {
                sum++;
            }


            // Same prefix sum found
            if (map.containsKey(sum)) {


                int prev = map.get(sum);


                ans = Math.max(ans, i - prev);


            } else {


                // Store only the first occurrence
                map.put(sum, i);
            }
        }


        return ans;
    }
}
Dry Run

Consider:

nums = [0, 1, 0, 1]

Convert:

0 → -1
1 → +1

Initially:

sum = 0
map = {0 : -1}
ans = 0
i = 0, nums[0] = 0
sum = -1

-1 is not in the map:

map = {0:-1, -1:0}
i = 1, nums[1] = 1
sum = 0

0 already exists at index -1.

So:

length = 1 - (-1) = 2
ans = 2

The subarray is:

[0,1]
i = 2, nums[2] = 0
sum = -1

-1 already exists at index 0.

Therefore:

length = 2 - 0 = 2

ans remains 2.

i = 3, nums[3] = 1
sum = 0

0 already exists at -1.

Therefore:

length = 3 - (-1) = 4

So:

ans = 4

The entire array has:

2 zeros
2 ones

Therefore the answer is:

4
Time & Space Complexity
Brute Force
Time  = O(n²)
Space = O(1)
Prefix Sum + HashMap
Time  = O(n)
Space = O(n)

The optimized approach is the one to use for this problem.

Key Takeaways

Convert:

0 → -1
1 → +1
Equal number of 0s and 1s becomes subarray sum = 0.
Use a prefix sum to detect zero-sum subarrays.
If the same prefix sum occurs again, the elements between those positions have equal 0s and 1s.
Store the first occurrence of every prefix sum to maximize the length.
map.put(0, -1) handles subarrays beginning at index 0.
Optimized complexity:
Time  = O(n)
Space = O(n)
