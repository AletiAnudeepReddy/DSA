# 3471. Find the Largest Almost Missing Integer

## 1. Problem

You are given:

* An integer array `nums`
* An integer `k`

A number `x` is called **almost missing** if `x` appears in **exactly one subarray of size `k`**.

We need to return the **largest almost missing integer**.

If there is no such integer, return:

```text
-1
```

### Example

```text
nums = [3, 9, 2, 1, 7]
k = 3
```

The subarrays of size `3` are:

```text
[3, 9, 2]
[9, 2, 1]
[2, 1, 7]
```

Now:

```text
3 → appears in 1 subarray
9 → appears in 2 subarrays
2 → appears in 3 subarrays
1 → appears in 2 subarrays
7 → appears in 1 subarray
```

The almost missing numbers are:

```text
3, 7
```

Largest:

```text
7
```

Answer:

```text
7
```

---

# 2. Important Observation

At first, this problem looks like we need to generate every subarray of size `k`.

That would be unnecessary.

The key is to understand **which elements can appear in exactly one subarray**.

Suppose:

```text
nums = [3, 9, 2, 1, 7]
k = 3
```

The windows are:

```text
Window 1 → [3, 9, 2]
Window 2 → [9, 2, 1]
Window 3 → [2, 1, 7]
```

Notice:

```text
3 → only first window
7 → only last window
```

But an element in the middle can belong to multiple windows.

Therefore, when:

```text
1 < k < n
```

the only possible almost-missing values are:

```text
nums[0]
nums[n - 1]
```

But there is one more condition.

The value must occur **only once in the entire array**.

---

# 3. Why Do We Need the Frequency Count?

Consider:

```text
nums = [3, 9, 2, 1, 7, 3]
k = 3
```

`3` occurs at the first position, but it also occurs at the last position.

Therefore, `3` appears in more than one subarray.

So even though `3` is at an endpoint, it is **not** almost missing.

Hence we need:

```text
count[value] == 1
```

For the first and last elements.

---

# 4. Special Cases

There are three important cases.

## Case 1: `k == n`

There is only **one subarray**:

```text
[entire array]
```

Therefore, every value that exists in the array appears in exactly one subarray.

So the answer is simply:

```text
maximum element in nums
```

Example:

```text
nums = [4, 2, 9, 1]
k = 4
```

Only one subarray exists:

```text
[4, 2, 9, 1]
```

Therefore:

```text
answer = 9
```

---

## Case 2: `k == 1`

Every element forms its own subarray.

For:

```text
nums = [3, 9, 2, 1, 7]
k = 1
```

The subarrays are:

```text
[3]
[9]
[2]
[1]
[7]
```

A value appears in exactly one subarray **if and only if it occurs exactly once in the entire array**.

Therefore, we find the largest value whose frequency is `1`.

---

## Case 3: `1 < k < n`

Now there are multiple overlapping windows.

Only the elements at the two endpoints can appear in exactly one window:

```text
nums[0]
nums[n - 1]
```

But they must occur exactly once in the entire array.

So we check:

```java
count[nums[0]] == 1
```

and:

```java
count[nums[n - 1]] == 1
```

Then take the maximum.

---

# 5. Approach

### Step 1: Get the length

```java
int n = nums.length;
```

---

### Step 2: Handle `k == n`

If the entire array is one subarray, simply return the maximum element.

---

### Step 3: Count frequencies

Create:

```java
int[] count = new int[51];
```

The problem constraints allow values from `1` to `50`.

Then:

```java
for (int x : nums) {
    count[x]++;
}
```

Now:

```text
count[x] = number of times x occurs in nums
```

---

### Step 4: Handle `k == 1`

If `k == 1`, find the largest value whose frequency is exactly `1`.

We iterate from `50` down to `0`.

Why from largest to smallest?

Because we immediately find the largest valid value.

---

### Step 5: Handle `1 < k < n`

Check the first element:

```java
if (count[nums[0]] == 1)
```

If it occurs only once, it is almost missing.

Then check the last element:

```java
if (count[nums[n - 1]] == 1)
```

Finally return the larger one.

---

# 6. Java Code

```java
class Solution {

    public int largestInteger(int[] nums, int k) {

        int n = nums.length;

        // Case 1: Only one subarray exists
        if (n == k) {

            int res = nums[0];

            for (int x : nums) {
                res = Math.max(res, x);
            }

            return res;
        }

        // Count frequency of every number
        int[] count = new int[51];

        for (int x : nums) {
            count[x]++;
        }

        // Case 2: k == 1
        if (k == 1) {

            // Search from largest to smallest
            for (int i = 50; i >= 0; --i) {

                if (count[i] == 1) {
                    return i;
                }
            }

            return -1;
        }

        // Case 3: 1 < k < n

        int res = -1;

        // Check first element
        if (count[nums[0]] == 1) {
            res = Math.max(res, nums[0]);
        }

        // Check last element
        if (count[nums[n - 1]] == 1) {
            res = Math.max(res, nums[n - 1]);
        }

        return res;
    }
}
```

# 11. Why Don't We Generate All Subarrays?

A straightforward approach might be:

```text
Generate every subarray of size k
        ↓
Count how many windows contain each number
        ↓
Find the largest number appearing in exactly one window
```

But there are:

```text
n - k + 1
```

subarrays.

We would also have to inspect up to `k` elements in each window.

That gives roughly:

```text
O((n - k + 1) × k)
```

which can become:

```text
O(n × k)
```

The important observation eliminates the need to examine all windows.

For:

```text
1 < k < n
```

we only need:

```text
first element
last element
```

plus their frequencies.

---

# 12. Time Complexity

Let:

```text
n = nums.length
```

### Frequency counting

```text
O(n)
```

### Finding maximum when `k == n`

```text
O(n)
```

### Finding largest unique value when `k == 1`

The value range is only `0...50`, so:

```text
O(51) = O(1)
```

### Overall

```text
Time Complexity = O(n)
```

# 13. Space Complexity

We use:

```java
int[] count = new int[51];
```

The array size is fixed.

Therefore:

```text
Space Complexity = O(1)
```

# 14. Key Takeaways

### 1. The main observation is about the endpoints

When:

```text
1 < k < n
```

only:

```text
nums[0]
nums[n - 1]
```

can appear in exactly one subarray.

---

### 2. Endpoint alone is not enough

We also need:

```text
frequency[value] == 1
```

Otherwise, the same value may occur in another window.

---

### 3. Remember the three cases

```text
k == n
    ↓
Only one subarray
    ↓
Return maximum element
```

```text
k == 1
    ↓
Each element is its own subarray
    ↓
Return largest value with frequency 1
```

```text
1 < k < n
    ↓
Only endpoints can be almost missing
    ↓
Check nums[0] and nums[n-1]
    ↓
Their frequency must be 1
```

---

### 4. The core insight

Instead of thinking:

> "How many subarrays contain this number?"

Think:

> **"Which positions can belong to exactly one window?"**

That observation reduces the problem from potentially checking many subarrays to a simple **frequency + endpoint check**.

```text
Time  → O(n)
Space → O(1)
```
