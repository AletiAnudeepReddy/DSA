# 3238. Find the Number of Winning Players

**Difficulty:** Easy  
**Topics:** Hashing, Counting, Arrays, Simulation

---

## Problem Statement

There are `n` players playing a game.

Each entry in

```text
pick[i] = [player, color]
```

means that the given player picked one ball of the given color.

A player **wins** if they pick **strictly more than their player index** balls of the **same color**.

That means:

- Player `0` needs **1** ball of the same color.
- Player `1` needs **2** balls of the same color.
- Player `2` needs **3** balls of the same color.
- ...
- Player `i` needs **i + 1** balls of the same color.

Return the total number of winning players.

---

# Approach: Counting Frequencies (Hashing)

## Intuition

For every player, we need to know:

> How many balls of each color have they picked?

As we process each pick:

- Increase the frequency of that color for that player.
- The moment the frequency becomes greater than the player's index, the player wins.
- Count the player only once.

---

## Algorithm

1. Create a frequency table

```text
hash[player][color]
```

2. Create a boolean array

```text
used[player]
```

to ensure each player is counted only once.

3. Traverse every pick:

   - Increment the frequency.
   - If

```text
frequency > playerIndex
```

and the player hasn't already been counted:

- Increment answer.
- Mark the player as counted.

4. Return the answer.

## Code (Java)

```java
class Solution {
    public int winningPlayerCount(int n, int[][] pick) {

        int[][] hash = new int[n][11];
        boolean[] used = new boolean[n];

        int ans = 0;

        for (int i = 0; i < pick.length; i++) {

            int player = pick[i][0];
            int color = pick[i][1];

            hash[player][color]++;

            if (hash[player][color] > player && !used[player]) {
                ans++;
                used[player] = true;
            }
        }

        return ans;
    }
}
```

---

## Complexity Analysis

- **Time Complexity:** **O(m)**
  - `m` = number of picks.

- **Space Complexity:** **O(n × C)**
  - `C = 11` (maximum number of colors).
  - Since the number of colors is constant, this is effectively **O(n)**.

---

# Key Insight

The only information we need is:

- Frequency of each color for every player.

As soon as one color's frequency exceeds the player's index, that player wins permanently.

Instead of counting frequencies after processing all picks, we can detect winners **while reading the input**, making the solution simple and efficient.

---

# Interview Tips

- This is a straightforward **Hashing + Frequency Counting** problem.
- The `used[]` array prevents counting the same player multiple times.
- Since the color range is small (`0` to `10`), using a fixed-size 2D array is faster than using a `HashMap`.
- If the color range were much larger, replace the 2D array with:

```java
Map<Integer, Map<Integer, Integer>>
```

or

```java
Map<Integer, Integer>[] freq;
```

to store frequencies dynamically.
