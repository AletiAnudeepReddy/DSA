# 3731. Find Missing Elements

**Difficulty:** Easy  
**Topics:** Array, Hashing

---

## Intuition

The array originally contained **every integer from the minimum value to the maximum value**.

Since:
- All elements are **unique**
- The **smallest and largest elements are guaranteed to exist**

We only need to identify which numbers between **minimum** and **maximum** are missing.

---

## Approach

1. Find the **minimum** and **maximum** element in the array.
2. Create a frequency array of size `(max - min + 1)`.
3. Mark every number present in the array.
4. Traverse the frequency array.
5. Every index with frequency `0` represents a missing number.

---

## Algorithm

1. Find `min` and `max`.
2. Create an array:

```java
int[] freq = new int[max - min + 1];
```

3. Mark every element:

```java
freq[num - min]++;
```

4. Traverse the frequency array.

- If `freq[i] == 0`
  - Missing number is:

```java
i + min
```

5. Return the list.

---

---

## Correctness Proof

- Every number in the original range `[min, max]` corresponds to exactly one index in the frequency array.
- Existing numbers are marked once because all elements are unique.
- Any index left unmarked represents a number missing from the original range.
- Therefore, all and only the missing integers are returned.

Hence, the algorithm is correct.

---

## Complexity Analysis

Finding min/max:

```text
O(n)
```

Marking elements:

```text
O(n)
```

Traversing the range:

```text
O(max - min)
```

Overall:

```text
Time : O(n + (max - min))
Space: O(max - min)
```

## Java Solution

```java
class Solution {
    public List<Integer> findMissingElements(int[] nums) {
        List<Integer> ls = new ArrayList<>();

        int mini = 101;
        int maxi = 0;

        for (int num : nums) {
            mini = Math.min(num, mini);
            maxi = Math.max(num, maxi);
        }

        int[] a = new int[maxi - mini + 1];

        for (int num : nums) {
            a[num - mini]++;
        }

        for (int i = 0; i < a.length; i++) {
            if (a[i] == 0) {
                ls.add(i + mini);
            }
        }

        return ls;
    }
}
```

---

## Key Takeaways

- Since the smallest and largest values are guaranteed to exist, the original range is uniquely determined.
- Using an offset (`num - min`) allows mapping any range to indices starting from `0`.
- This is a simple **frequency-array** technique and works efficiently when the range size is reasonable.
