# 3. Longest Substring Without Repeating Characters

**Difficulty:** Medium  
**Topics:** Sliding Window, HashMap

---

## Intuition

We need the **longest substring** where every character is unique.

Use a **sliding window** `[l...r]` to represent the current substring.

- Expand the window by moving `r`.
- If the current character is already present in the window, move `l` to the position after its last occurrence.
- Store the **last index** of every character in a `HashMap`.

> **Important:** While updating `l`, use:
>
> ```java
> l = Math.max(l, lastIndex + 1);
> ```
>
> This prevents `l` from moving backward.

---

## Example

```
s = "abcabcbb"

r = 0 → "a"      max = 1
r = 1 → "ab"     max = 2
r = 2 → "abc"    max = 3

r = 3 ('a')
'a' was last seen at index 0
Move l = max(0, 0 + 1) = 1

Current window = "bca"
Length = 3
```

The maximum length remains **3**.

---

## Algorithm

1. Maintain a `HashMap<Character, Integer>` storing the last index of each character.
2. Expand the window by moving `r`.
3. If the current character already exists, update:
   ```java
   l = Math.max(l, map.get(ch) + 1);
   ```
4. Update the current character's latest index.
5. Update the maximum window length.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(min(n, charset))`

---

## Java Solution

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        HashMap<Character, Integer> map = new HashMap<>();

        int l = 0;
        int maxLen = 0;

        for (int r = 0; r < s.length(); r++) {

            if (map.containsKey(s.charAt(r))) {
                l = Math.max(l, map.get(s.charAt(r)) + 1);
            }

            map.put(s.charAt(r), r);
            maxLen = Math.max(maxLen, r - l + 1);
        }

        return maxLen;
    }
}
```

---

## Key Takeaways

- Use a **sliding window** to maintain a substring with unique characters.
- The `HashMap` stores the **latest index** of each character.
- `Math.max(l, lastIndex + 1)` ensures the left pointer never moves backward.
- This is a classic **variable-size sliding window** problem.
