# 1423. Maximum Points You Can Obtain from Cards

**Difficulty:** Medium  
**Topics:** Sliding Window, Prefix Sum

---

## Intuition

We must pick exactly `k` cards, and each pick can only be from the **beginning** or the **end** of the array.

Instead of trying every possible sequence of picks, observe that:

- If we take `i` cards from the left,
- then we must take `k - i` cards from the right.

So, we only need to check all possible combinations of:

```
Left cards + Right cards
```

There are only `k + 1` such combinations.

---

## Approach

1. Initially, take **all `k` cards from the left**.
2. This gives the first possible score.
3. Then, one by one:
   - Remove one card from the left sum.
   - Add one card from the right sum.
4. Update the maximum score after each shift.

This effectively checks:

```
k left + 0 right
k-1 left + 1 right
k-2 left + 2 right
...
0 left + k right
```

---

## Example

```
cardPoints = [1,2,3,4,5,6,1]
k = 3
```

Initial:

```
Left = [1,2,3]

Score = 6
```

Shift 1:

```
Left = [1,2]
Right = [1]

Score = 3 + 1 = 4
```

Shift 2:

```
Left = [1]
Right = [6,1]

Score = 1 + 7 = 8
```

Shift 3:

```
Left = []
Right = [5,6,1]

Score = 12
```

Maximum score = **12**

---

## Algorithm

1. Compute the sum of the first `k` cards (`leftSum`).
2. Initialize `maxScore = leftSum`.
3. Traverse backwards through the left-picked cards:
   - Remove one card from `leftSum`.
   - Add one card from the right to `rightSum`.
   - Update `maxScore`.
4. Return the maximum score.

---

## Complexity

- **Time Complexity:** `O(k)`
- **Space Complexity:** `O(1)`

---

## Java Solution

```java
class Solution {
    public int maxScore(int[] cardPoints, int k) {

        int n = cardPoints.length;

        int leftSum = 0;
        for (int i = 0; i < k; i++) {
            leftSum += cardPoints[i];
        }

        int maxScore = leftSum;
        int rightSum = 0;
        int j = n - 1;

        for (int i = k - 1; i >= 0; i--) {

            leftSum -= cardPoints[i];
            rightSum += cardPoints[j--];

            maxScore = Math.max(maxScore, leftSum + rightSum);
        }

        return maxScore;
    }
}
```

---

## Key Takeaways

- Instead of simulating every pick, think in terms of **how many cards are taken from the left and right**.
- There are only **`k + 1` possible combinations**:
  ```
  k left + 0 right
  k-1 left + 1 right
  ...
  0 left + k right
  ```
- Update the score efficiently by removing one card from the left sum and adding one from the right sum.
- This reduces the solution to **`O(k)`** time with **`O(1)`** extra space.
