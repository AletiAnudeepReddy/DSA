# 1248. Count Number of Nice Subarrays

**Difficulty:** Medium  
**Topics:** Sliding Window, Two Pointers

---

## Intuition

A **nice subarray** is one that contains **exactly `k` odd numbers**.

Instead of counting subarrays with **exactly `k` odds** directly, use the same trick as **LeetCode 930 (Binary Subarrays With Sum)**:

```
Exactly(k) = AtMost(k) - AtMost(k - 1)
```

Here, treat:

- **Odd number** → `1`
- **Even number** → `0`

Since:

```java
num % 2
```

returns:

- `1` for odd numbers
- `0` for even numbers

the problem becomes identical to counting binary subarrays with a given sum.

---

## Why does this work?

Suppose:

```
AtMost(3 odds) = 12
AtMost(2 odds) = 10
```

Then,

```
Exactly(3 odds)

= AtMost(3) - AtMost(2)

= 12 - 10

= 2
```

The subtraction removes all subarrays having fewer than `k` odd numbers.

---

## How to Calculate `AtMost(k)`

Maintain a sliding window containing **at most `k` odd numbers**.

- Expand the window by moving `r`.
- Add `nums[r] % 2` to the current odd count.
- If the odd count exceeds `k`, shrink the window from the left.
- Once the window is valid, every subarray ending at `r` and starting between `l` and `r` is valid.

Hence, add:

```
r - l + 1
```

to the answer.

---

## Example

```
nums = [1,1,2,1,1]
k = 3

Odd representation:

[1,1,0,1,1]
```

```
AtMost(3) = 14
AtMost(2) = 12

Exactly(3)

= 14 - 12

= 2
```

Answer = **2**

---

## Algorithm

### Function: `AtMost(k)`

1. Maintain a sliding window.
2. Count odd numbers using `nums[i] % 2`.
3. If the odd count exceeds `k`, shrink the window.
4. Add `r - l + 1` to the answer.
5. Return the total count.

Finally,

```
Answer = AtMost(k) - AtMost(k - 1)
```

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)`

---

## Java Solution

```java
class Solution {

    public int numberOfSubarrays(int[] nums, int k) {
        return calculate(nums, k) - calculate(nums, k - 1);
    }

    private int calculate(int[] nums, int goal) {
        if (goal < 0) return 0;

        int l = 0;
        int sum = 0;
        int count = 0;

        for (int r = 0; r < nums.length; r++) {

            sum += nums[r] % 2;

            while (sum > goal) {
                sum -= nums[l] % 2;
                l++;
            }

            count += (r - l + 1);
        }

        return count;
    }
}
```

---

## Key Takeaways

- Convert the problem into a **binary array** by treating:
  - **Odd = 1**
  - **Even = 0**
- Use the formula:

  ```
  Exactly(k) = AtMost(k) - AtMost(k - 1)
  ```

- While computing **AtMost(k)**, every valid window contributes **`r - l + 1`** subarrays.
- This problem is a direct application of the **At Most Sliding Window** technique used in **LeetCode 930**.
