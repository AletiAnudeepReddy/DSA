# 904. Fruit Into Baskets

**Difficulty:** Medium  
**Topics:** Sliding Window, HashMap, Two Pointers

---

## Intuition

We have **two baskets**, and each basket can hold **only one type of fruit**.

So, we need to find the **longest contiguous subarray containing at most 2 distinct fruit types**.

A **sliding window** is ideal:

- Expand the window by moving `r`.
- Store the frequency of each fruit type in a `HashMap`.
- If the window contains more than **2 distinct fruits**, shrink it from the left until only two types remain.
- The maximum valid window length is the answer.

---

## Example

```
fruits = [0,1,2,2]

Window:

[0,1]        → 2 types ✅

[0,1,2]      → 3 types ❌

Shrink:

Remove 0

[1,2]        → 2 types ✅

Expand:

[1,2,2]      → Length = 3
```

Answer = **3**

---

## Algorithm

1. Maintain a sliding window using two pointers `l` and `r`.
2. Store the frequency of each fruit type in a `HashMap`.
3. Expand the window by moving `r`.
4. If the number of distinct fruit types becomes greater than `2`, shrink the window from the left until it becomes valid.
5. Update the maximum window length.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)` *(at most 3 fruit types are stored in the map at any time)*

---

## Java Solution

```java
class Solution {
    public int totalFruit(int[] fruits) {
        int l = 0;
        int maxLength = 0;
        Map<Integer, Integer> map = new HashMap<>();

        for (int r = 0; r < fruits.length; r++) {
            map.put(fruits[r], map.getOrDefault(fruits[r], 0) + 1);

            while (map.size() > 2) {
                map.put(fruits[l], map.get(fruits[l]) - 1);

                if (map.get(fruits[l]) == 0) {
                    map.remove(fruits[l]);
                }

                l++;
            }

            maxLength = Math.max(maxLength, r - l + 1);
        }

        return maxLength;
    }
}
```

---

## Key Takeaways

- The problem is equivalent to finding the **longest subarray with at most 2 distinct elements**.
- A `HashMap` keeps track of the frequency of fruit types in the current window.
- Shrink the window whenever the number of distinct fruit types exceeds `2`.
- This is a classic **variable-size sliding window** problem where the constraint is on the number of distinct elements.
