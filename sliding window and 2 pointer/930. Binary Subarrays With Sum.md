# 930. Binary Subarrays With Sum

**Difficulty:** Medium  
**Topics:** Sliding Window, Prefix Sum

---

## Intuition

Directly counting subarrays with **sum = goal** using a sliding window is difficult.

Instead, use this observation:

```
Subarrays with sum = goal
=
Subarrays with sum ≤ goal
-
Subarrays with sum ≤ (goal - 1)
```

So,

```
Exactly(goal) = AtMost(goal) - AtMost(goal - 1)
```

Since the array contains only **0s and 1s**, we can efficiently count subarrays with sum **at most** a given value using a sliding window.

---

## Why does this work?

Suppose:

```
AtMost(2) = 10
AtMost(1) = 6
```

Then,

```
Exactly(2)

= AtMost(2) - AtMost(1)

= 10 - 6

= 4
```

The subtraction removes all subarrays whose sum is less than `2`, leaving only those whose sum is exactly `2`.

---

## How to Calculate `AtMost(goal)`

Maintain a sliding window whose sum never exceeds `goal`.

- Expand the window by moving `r`.
- If the sum becomes greater than `goal`, shrink the window from the left.
- Once the window is valid, **every subarray ending at `r` and starting anywhere from `l` to `r` is valid**.

Hence, add:

```
r - l + 1
```

to the answer.

---

## Example

```
nums = [1,0,1,0,1]
goal = 2
```

```
AtMost(2) = 14
AtMost(1) = 10

Exactly(2)

= 14 - 10

= 4
```

Answer = **4**

---

## Algorithm

### Function: `AtMost(goal)`

1. Maintain a sliding window.
2. Keep track of the current window sum.
3. If the sum exceeds `goal`, shrink the window.
4. Add `r - l + 1` to the count.
5. Return the total count.

Finally,

```
Answer = AtMost(goal) - AtMost(goal - 1)
```

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)`

---

## Java Solution

```java
class Solution {

    public int numSubarraysWithSum(int[] nums, int goal) {
        return calculate(nums, goal) - calculate(nums, goal - 1);
    }

    private int calculate(int[] nums, int goal) {
        if (goal < 0) return 0;

        int l = 0;
        int sum = 0;
        int count = 0;

        for (int r = 0; r < nums.length; r++) {

            sum += nums[r];

            while (sum > goal) {
                sum -= nums[l];
                l++;
            }

            count += (r - l + 1);
        }

        return count;
    }
}
```

---

## Key Takeaways

- For binary arrays, counting **exactly `goal`** is easier using:

  ```
  Exactly(goal) = AtMost(goal) - AtMost(goal - 1)
  ```

- While calculating **AtMost(goal)**:
  - Keep the window sum `<= goal`.
  - Every valid window contributes `r - l + 1` subarrays.
- This trick is applicable **only when the sliding window property holds**, such as arrays with **non-negative values** (here, only `0` and `1`).
