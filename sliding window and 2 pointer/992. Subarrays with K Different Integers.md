# 992. Subarrays with K Different Integers

**Difficulty:** Hard  
**Topics:** Sliding Window, HashMap, Two Pointers

---

# Problem Statement

Given an integer array `nums` and an integer `k`, return the number of subarrays that contain **exactly `k` distinct integers**.

---

# Approach 1: Brute Force

## Intuition

Generate every possible subarray starting from each index.

Maintain a `HashMap` to count the frequency of elements in the current subarray.

- If the number of distinct elements becomes exactly `k`, increment the answer.
- If it becomes greater than `k`, stop extending the current subarray since adding more elements cannot reduce the number of distinct integers.

---

## Example

```
nums = [1,2,1,2,3]
k = 2
```

Starting from index `0`:

```
[1]         -> 1 distinct

[1,2]       -> 2 distinct ✅

[1,2,1]     -> 2 distinct ✅

[1,2,1,2]   -> 2 distinct ✅

[1,2,1,2,3] -> 3 distinct ❌
Stop
```

Repeat for every starting index.

---

## Complexity

- **Time Complexity:** `O(n²)`
- **Space Complexity:** `O(k)`

---

## Java Solution

```java
class Solution {

    public int subarraysWithKDistinct(int[] nums, int k) {

        int count = 0;
        int n = nums.length;

        for (int i = 0; i < n; i++) {

            Map<Integer, Integer> map = new HashMap<>();

            for (int j = i; j < n; j++) {

                map.put(nums[j], map.getOrDefault(nums[j], 0) + 1);

                if (map.size() == k) {
                    count++;
                } else if (map.size() > k) {
                    break;
                }
            }
        }

        return count;
    }
}
```

---

# Approach 2: Sliding Window (Optimal)

## Intuition

Counting subarrays with **exactly `k` distinct elements** directly is difficult.

Instead, use the standard sliding window trick:

```
Exactly(k) = AtMost(k) - AtMost(k - 1)
```

So, if we can count the number of subarrays having **at most `k` distinct integers**, then subtract those having **at most `k-1`**, we get the number of subarrays having **exactly `k`** distinct integers.

---

## Why does this work?

Suppose

```
AtMost(2) = 12

AtMost(1) = 5
```

Then

```
Exactly(2)

= AtMost(2) - AtMost(1)

= 12 - 5

= 7
```

The subtraction removes all subarrays having fewer than `k` distinct elements.

---

## How to Calculate `AtMost(k)`

Maintain a sliding window containing **at most `k` distinct integers**.

- Expand the window by moving `r`.
- Store frequencies using a `HashMap`.
- If the number of distinct integers exceeds `k`, shrink the window.
- Once the window becomes valid, every subarray ending at `r` and starting between `l` and `r` is valid.

Hence, add:

```
r - l + 1
```

to the answer.

---

## Example

```
nums = [1,2,1,2,3]
k = 2
```

```
AtMost(2) = 12

AtMost(1) = 5

Exactly(2)

= 12 - 5

= 7
```

---

## Algorithm

### Function: `AtMost(k)`

1. Maintain a sliding window.
2. Store frequencies in a `HashMap`.
3. If distinct elements exceed `k`, shrink the window.
4. Add `r - l + 1` to the answer.
5. Return the count.

Finally,

```
Answer = AtMost(k) - AtMost(k - 1)
```

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(k)`

---

## Java Solution

```java
class Solution {

    public int subarraysWithKDistinct(int[] nums, int k) {
        return calculate(nums, k) - calculate(nums, k - 1);
    }

    private int calculate(int[] nums, int k) {

        if (k == 0) return 0;

        Map<Integer, Integer> map = new HashMap<>();

        int l = 0;
        int count = 0;

        for (int r = 0; r < nums.length; r++) {

            map.put(nums[r], map.getOrDefault(nums[r], 0) + 1);

            while (map.size() > k) {

                map.put(nums[l], map.get(nums[l]) - 1);

                if (map.get(nums[l]) == 0) {
                    map.remove(nums[l]);
                }

                l++;
            }

            count += (r - l + 1);
        }

        return count;
    }
}
```

---

# Key Takeaways

- Brute force generates every subarray and counts distinct elements using a `HashMap`.
- The optimal solution uses the formula:

  ```
  Exactly(k) = AtMost(k) - AtMost(k - 1)
  ```

- While computing **AtMost(k)**:
  - Maintain a sliding window with at most `k` distinct integers.
  - Use a `HashMap` to track frequencies.
  - Every valid window contributes **`r - l + 1`** subarrays.
- This is one of the most important applications of the **At Most Sliding Window** technique.
