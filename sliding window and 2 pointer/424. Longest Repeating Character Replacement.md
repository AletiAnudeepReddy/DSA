# 424. Longest Repeating Character Replacement

**Difficulty:** Medium  
**Topics:** Sliding Window, Two Pointers

---

## Intuition

We want the **longest substring** that can be converted into a string of **all the same character** by replacing at most `k` characters.

For any window:

```
Window Size = r - l + 1
```

Suppose the most frequent character appears `maxFreq` times.

Then the remaining characters are the ones that must be replaced.

```
Replacements Needed = Window Size - maxFreq
```

If:

```
Window Size - maxFreq <= k
```

the window is valid.

Otherwise, shrink the window from the left until it becomes valid.

---

## Example

```
s = "AABABBA"
k = 1

Window = "AABA"

Frequency:

A = 3
B = 1

Window Size = 4
maxFreq = 3

Replacements Needed

= 4 - 3
= 1

Since 1 <= k,
the window is valid.
```

Now consider:

```
Window = "AABABB"

A = 3
B = 3

Window Size = 6
maxFreq = 3

Replacements Needed

= 6 - 3
= 3

Since 3 > 1,
shrink the window.
```

---

## Algorithm

1. Maintain a sliding window using two pointers.
2. Store the frequency of each character.
3. Track the highest frequency (`maxFreq`) in the current window.
4. If

   ```
   Window Size - maxFreq > k
   ```

   shrink the window from the left.
5. Update the maximum valid window length.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)` (26 uppercase letters)

---

## Java Solution

```java
class Solution {
    public int characterReplacement(String s, int k) {
        int[] freq = new int[26];

        int l = 0;
        int maxFreq = 0;
        int maxLen = 0;

        for (int r = 0; r < s.length(); r++) {

            freq[s.charAt(r) - 'A']++;
            maxFreq = Math.max(maxFreq, freq[s.charAt(r) - 'A']);

            while ((r - l + 1) - maxFreq > k) {
                freq[s.charAt(l) - 'A']--;
                l++;
            }

            maxLen = Math.max(maxLen, r - l + 1);
        }

        return maxLen;
    }
}
```

---

## Key Takeaways

- The character with the **maximum frequency** is the one we keep unchanged.
- Every other character in the window must be replaced.
- A window is valid if:

  ```
  Window Size - maxFreq <= k
  ```

- This is a classic **variable-size sliding window** problem where we maximize the window while satisfying the replacement constraint.
