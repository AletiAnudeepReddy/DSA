# 1358. Number of Substrings Containing All Three Characters

**Difficulty:** Medium  
**Topics:** Strings, Last Seen Index

---

## Intuition

Instead of checking every substring, keep track of the **last seen index** of each character:

- `a`
- `b`
- `c`

At every index `i`, update the last occurrence of the current character.

If all three characters have been seen, then every substring that:

- **Ends at `i`**, and
- **Starts from index `0`` to `min(lastSeen)`**

will contain at least one `'a'`, `'b'`, and `'c'`.

Hence, the number of valid substrings ending at `i` is:

```
min(lastSeen['a'], lastSeen['b'], lastSeen['c']) + 1
```

---

## Example

```
s = "abcabc"
```

Initially,

```
lastSeen = [-1, -1, -1]
```

| i | Character | lastSeen (a,b,c) | Contribution |
|---|-----------|------------------|-------------:|
| 0 | a | [0,-1,-1] | 0 |
| 1 | b | [0,1,-1] | 0 |
| 2 | c | [0,1,2] | 0 + 1 = 1 |
| 3 | a | [3,1,2] | 1 + 1 = 2 |
| 4 | b | [3,4,2] | 2 + 1 = 3 |
| 5 | c | [3,4,5] | 3 + 1 = 4 |

```
Total = 1 + 2 + 3 + 4 = 10
```

---

## Why `min(lastSeen) + 1`?

Suppose,

```
lastSeen

a = 5
b = 3
c = 7
```

The earliest occurrence among the three is:

```
min = 3
```

Any substring ending at the current index and starting at:

```
0, 1, 2, or 3
```

will contain all three characters.

So the number of valid starting positions is:

```
3 + 1 = 4
```

---

## Algorithm

1. Maintain a `lastSeen` array of size `3`, initialized to `-1`.
2. For each character, update its latest index.
3. If all three characters have been seen:
   - Compute `min(lastSeen)`.
   - Add `min(lastSeen) + 1` to the answer.
4. Return the total count.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)`

---

## Java Solution

```java
class Solution {
    public int numberOfSubstrings(String s) {
        int result = 0;
        int[] lastSeen = {-1, -1, -1};

        for (int i = 0; i < s.length(); i++) {
            lastSeen[s.charAt(i) - 'a'] = i;

            if (lastSeen[0] != -1 &&
                lastSeen[1] != -1 &&
                lastSeen[2] != -1) {

                result += 1 + Math.min(lastSeen[0],
                          Math.min(lastSeen[1], lastSeen[2]));
            }
        }

        return result;
    }
}
```

---

## Key Takeaways

- Maintain the **last seen index** of `'a'`, `'b'`, and `'c'`.
- For every ending index, the earliest last seen index determines how many valid starting positions exist.
- The contribution at each index is:

  ```
  min(lastSeen) + 1
  ```

- This elegant approach avoids generating substrings explicitly and runs in **`O(n)`** time.
