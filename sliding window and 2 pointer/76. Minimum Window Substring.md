# 76. Minimum Window Substring

**Difficulty:** Hard  
**Topics:** Sliding Window, Two Pointers, Hashing

---

# Intuition

We need to find the **smallest substring of `s`** that contains **all characters of `t` (including duplicates)**.

The idea is to use a **sliding window**:

- Expand the window by moving the right pointer until it contains all required characters.
- Once the window becomes valid, try shrinking it from the left to make it as small as possible.
- Keep track of the minimum valid window encountered.

---

## Role of the Hash Array

Create a frequency array for all characters in `t`.

```text
hash[ch] = number of times ch is still needed
```

Initially,

```
t = "AABC"

hash

A -> 2
B -> 1
C -> 1
```

As characters are included in the window, decrement their counts.

---

## Understanding `cnt`

`cnt` stores **how many required characters have been matched**.

When expanding the window:

```java
if (hash[s.charAt(r)] > 0)
    cnt++;
```

Why?

If the frequency is positive, this character was still needed.

After using it,

```java
hash[s.charAt(r)]--;
```

---

## Example

```
s = "ADOBECODEBANC"
t = "ABC"
```

Initially

```
Need

A = 1
B = 1
C = 1
```

Expand the window

```
ADOBEC

Matched

A ✓
B ✓
C ✓

cnt = 3
```

Now the window is valid.

Try shrinking it.

Eventually we reach

```
BANC
```

which is the smallest valid window.

---

## Why do we increment while shrinking?

Suppose we remove a character from the left.

```java
hash[s.charAt(l)]++;
```

If its count becomes positive,

```java
hash[s.charAt(l)] > 0
```

it means we have removed a **required** character.

So the window is no longer valid.

Hence,

```java
cnt--;
```

---

## Algorithm

1. Store the frequency of every character in `t`.
2. Expand the window using `r`.
3. Whenever a required character is found, increase `cnt`.
4. Once all characters are matched (`cnt == t.length()`):
   - Update the minimum window.
   - Shrink the window from the left.
5. Continue until the entire string is processed.

---

## Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)` (fixed-size array of 256 characters)

---

## Java Solution

```java
class Solution {

    public String minWindow(String s, String t) {

        int[] hash = new int[256];

        for (char ch : t.toCharArray()) {
            hash[ch]++;
        }

        int l = 0;
        int r = 0;

        int count = 0;
        int minLen = Integer.MAX_VALUE;
        int start = -1;

        while (r < s.length()) {

            if (hash[s.charAt(r)] > 0) {
                count++;
            }

            hash[s.charAt(r)]--;
            r++;

            while (count == t.length()) {

                if (r - l < minLen) {
                    minLen = r - l;
                    start = l;
                }

                hash[s.charAt(l)]++;

                if (hash[s.charAt(l)] > 0) {
                    count--;
                }

                l++;
            }
        }

        return start == -1 ? "" : s.substring(start, start + minLen);
    }
}
```

# Key Takeaways

- Maintain a frequency array of characters required from `t`.
- `count` represents the number of matched characters (including duplicates).
- Expand the window until all required characters are present.
- Shrink the window greedily to obtain the minimum valid substring.
- This is a classic **expand-then-shrink sliding window** problem.
- **Important:** The condition `hash[ch] > 0` tells us whether the current character is still needed before adding it to the window.
