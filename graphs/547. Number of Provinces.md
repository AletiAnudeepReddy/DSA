# 547. Number of Provinces

**Difficulty:** Medium  
**Topics:** Graph, DFS, BFS, Connected Components, Union Find

---

## Intuition

Each city is a **node** and every direct connection between two cities is an **undirected edge**.

A **province** is nothing but a **connected component** in the graph.

So the problem becomes:

> Count the number of connected components.

Whenever we find an unvisited city, we start a DFS (or BFS) from it and mark every reachable city as visited.

Each new DFS represents one new province.

---

## Approach

### Step 1: Convert the matrix into an adjacency list

The input is given as an adjacency matrix.

```
isConnected[i][j] == 1
```

means

```
City i <----> City j
```

Since the graph is undirected, add both edges.

---

### Step 2: Traverse every city

If a city has not been visited,

- it starts a new province.
- Run DFS from it.
- Mark all reachable cities as visited.

Increase the province count.

---

## Algorithm

1. Create an adjacency list.
2. Traverse the matrix.
3. For every `1`, add an undirected edge.
4. Create a visited array.
5. Traverse every city.
6. If the city is unvisited:
   - Increment answer.
   - Run DFS.
7. Return the answer.

## Correctness Proof

We prove that the algorithm returns the correct number of provinces.

- A DFS started from any unvisited city visits every city reachable from it.
- Therefore, one DFS completely explores one connected component.
- No city inside that component is visited again.
- Every connected component will eventually have one unvisited city from which DFS starts.

Hence,

- Every province is counted exactly once.
- No province is missed.

Therefore, the algorithm is correct.

---

## Complexity Analysis

Let

```
V = number of cities
```

Building adjacency list

```
O(V²)
```

because every matrix cell is visited once.

DFS traversal

```
O(V + E)
```

Since

```
E ≤ V²
```

Overall

```
Time  : O(V²)

Space : O(V + E)
```

## Java Solution

```java
class Solution {

    private void dfs(int node, ArrayList<ArrayList<Integer>> adjLs, int[] vis) {

        vis[node] = 1;

        for (Integer next : adjLs.get(node)) {
            if (vis[next] == 0) {
                dfs(next, adjLs, vis);
            }
        }
    }

    public int findCircleNum(int[][] isConnected) {

        int V = isConnected.length;

        ArrayList<ArrayList<Integer>> adjLs = new ArrayList<>();

        for (int i = 0; i < V; i++) {
            adjLs.add(new ArrayList<>());
        }

        for (int i = 0; i < V; i++) {
            for (int j = 0; j < V; j++) {

                if (isConnected[i][j] == 1 && i != j) {

                    adjLs.get(i).add(j);
                    adjLs.get(j).add(i);
                }
            }
        }

        int[] vis = new int[V];

        int cnt = 0;

        for (int i = 0; i < V; i++) {

            if (vis[i] == 0) {

                cnt++;

                dfs(i, adjLs, vis);
            }
        }

        return cnt;
    }
}
```

# Better Approach (No Adjacency List)

Since the graph is already given as an **adjacency matrix**, we don't actually need to convert it into an adjacency list.

During DFS, simply iterate over the row corresponding to the current city.

This avoids extra space.

### Java

```java
class Solution {

    private void dfs(int node, int[][] isConnected, boolean[] vis) {

        vis[node] = true;

        for (int next = 0; next < isConnected.length; next++) {

            if (isConnected[node][next] == 1 && !vis[next]) {
                dfs(next, isConnected, vis);
            }
        }
    }

    public int findCircleNum(int[][] isConnected) {

        int n = isConnected.length;

        boolean[] vis = new boolean[n];

        int provinces = 0;

        for (int i = 0; i < n; i++) {

            if (!vis[i]) {

                provinces++;

                dfs(i, isConnected, vis);
            }
        }

        return provinces;
    }
}
```

### Complexity

```
Time  : O(V²)

Space : O(V)
```

This is the most optimal DFS solution.

---

## Key Takeaways

- A **province** is simply a **connected component**.
- DFS/BFS can be used to count connected components.
- Since the input is already an adjacency matrix, constructing an adjacency list is optional.
- The matrix-based DFS is more space efficient.
