785. Is Graph Bipartite?
Problem

We need to determine whether an undirected graph can be divided into two groups such that:

Every edge connects a node from one group to the other group.

This is exactly a 2-coloring problem.

We can assign every node one of two colors:

Color 0
Color 1

For every edge:

u -------- v

u and v must have different colors.

Approach: DFS + 2-Coloring
Core idea

Start from any uncolored node and give it color 0.

Then:

node = 0
color = 0

all its neighbors → color 1
all their neighbors → color 0
all their neighbors → color 1
...

So while doing DFS:

dfs(node, 1 - color[node])

we always assign the opposite color to the neighbor.

The important condition

When we encounter a neighbor:

Case 1: Neighbor is uncolored
if (color[it] == -1)

Give it the opposite color:

dfs(it, 1 - color[node], color, graph)
Case 2: Neighbor is already colored

Then we need to check:

color[it] != color[node]

If:

color[it] == color[node]

we found a contradiction.

Therefore the graph is not bipartite.

Your Code
class Solution {

    private boolean dfs(int node, int col, int color[], int[][] adj) {

        color[node] = col;

        for (int it : adj[node]) {

            // Neighbor is not colored yet
            if (color[it] == -1) {

                if (dfs(it, 1 - col, color, adj) == false) {
                    return false;
                }
            }

            // Neighbor has the same color
            else if (color[it] == col) {
                return false;
            }
        }

        return true;
    }

    public boolean isBipartite(int[][] graph) {

        int v = graph.length;

        int[] color = new int[v];

        // -1 means uncolored
        for (int i = 0; i < v; i++) {
            color[i] = -1;
        }

        // Graph may be disconnected
        for (int i = 0; i < v; i++) {

            if (color[i] == -1) {

                if (dfs(i, 0, color, graph) == false) {
                    return false;
                }
            }
        }

        return true;
    }
}

Why 1 - col?

Because we only have two colors:

0
1

If current color is:

0

then:

1 - 0 = 1

If current color is:

1

then:

1 - 1 = 0

So:

1 - col

simply means:

Give the neighbor the opposite color.

Why do we need the outer for loop?

This is extremely important.

The graph may be disconnected.

For example:

0 ---- 1


2 ---- 3

There is no connection between the two components.

If we only did:

dfs(0, ...)

we would never visit 2 or 3.

Therefore:

for (int i = 0; i < v; i++) {
    if (color[i] == -1) {
        dfs(i, 0, color, graph);
    }
}

means:

Start a new DFS for every disconnected component.

Important Pattern

This problem is fundamentally:

Graph
  ↓
Assign 2 colors
  ↓
Every edge must connect
different colors
  ↓
Conflict?
 ┌───────┴───────┐
Yes              No
 ↓                ↓
false            true

You can remember the rule as:

Bipartite = Can I color the graph using only 2 colors such that no adjacent nodes have the same color?

Odd Cycle Connection

There is another very important theoretical property:

A graph is bipartite if and only if it contains no odd-length cycle.

For example:

Even cycle → Bipartite
0 ---- 1
|      |
|      |
3 ---- 2

Cycle length = 4 → possible.

Odd cycle → Not Bipartite
    0
   / \
  1---2

Cycle length = 3 → impossible.

This is why the coloring algorithm detects a conflict whenever an odd cycle exists.

DFS vs BFS

You can solve this using either:

DFS
dfs(node, oppositeColor)

or

BFS
queue.add(node);

while (!queue.isEmpty()) {
    int node = queue.remove();

    for (int next : graph[node]) {
        if (color[next] == -1) {
            color[next] = 1 - color[node];
            queue.add(next);
        }
    }
}

Both have the same complexity.

Complexity

Let:

V = number of vertices
E = number of edges

Every vertex is colored once and every edge is examined.

Time
O(V + E)
Space

Color array:

O(V)

DFS recursion stack in the worst case:

O(V)

So:

Time  = O(V + E)
Space = O(V)

785. Is Graph Bipartite?

Pattern:
    Graph Coloring

color[i] = -1 → unvisited
color[i] = 0  → first group
color[i] = 1  → second group

For every edge u → v:

if v is uncolored:
    color[v] = 1 - color[u]

else if color[v] == color[u]:
    return false

Graph can be disconnected:
    run DFS/BFS from every uncolored node.

Key property:
    Bipartite ⇔ No odd cycle

Time:  O(V + E)
Space: O(V)

This is the same DFS/BFS traversal pattern you've been using in Number of Provinces, Number of Islands, Flood Fill, Rotting Oranges, and Number of Enclaves; the only new part here is that instead of merely marking visited, we maintain a color/state and detect conflicts.
