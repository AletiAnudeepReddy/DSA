# 733. Flood Fill

**Difficulty:** Easy  
**Topics:** Graph, DFS, BFS, Matrix Traversal

---

## Intuition

Imagine a paint bucket tool in an image editor.

When you click on a pixel:

- That pixel changes color.
- Every connected pixel having the **same original color** also changes.
- The process continues in all **4 directions** (up, down, left, right).

This is exactly a **graph traversal** problem where:

- Each pixel is a node.
- Adjacent pixels form edges.
- We perform DFS/BFS starting from `(sr, sc)`.

---

## Approach (DFS)

### Step 1: Store the Original Color

Before changing anything, store the color of the starting pixel.

```java
int initialColor = image[sr][sc];
```

Only pixels having this color should be recolored.

---

### Step 2: Start DFS

Color the current pixel with the new color.

Then explore all four neighbors.

Visit a neighbor only if:

- It lies inside the grid.
- It has the original color.
- It hasn't already been recolored.

---

### Step 3: Continue Recursively

The recursion continues until every connected pixel of the original color has been recolored.

---

## Algorithm

1. Store the original color.
2. Start DFS from `(sr, sc)`.
3. Change current pixel to the new color.
4. Visit its four neighbors.
5. Continue DFS for every valid neighbor.
6. Return the modified image.

## Correctness Proof

We prove that the algorithm correctly performs flood fill.

- The DFS starts from the given starting pixel.
- It only visits neighboring pixels having the **same original color**.
- Every visited pixel is immediately recolored, preventing repeated visits.
- DFS continues until no valid neighboring pixels remain.

Thus,

- Every connected pixel with the original color is recolored.
- No unrelated pixel is modified.

Hence, the algorithm is correct.

---

## Complexity Analysis

Let

- `n = number of rows`
- `m = number of columns`

Every pixel is visited at most once.

```
Time  : O(n × m)
```

Recursive stack (worst case)

```
Space : O(n × m)
```

## Java Solution

```java
class Solution {

    private void dfs(
            int row,
            int col,
            int[][] ans,
            int[][] image,
            int newColor,
            int[] delRow,
            int[] delCol,
            int initialColor) {

        ans[row][col] = newColor;

        int n = image.length;
        int m = image[0].length;

        for (int i = 0; i < 4; i++) {

            int nrow = row + delRow[i];
            int ncol = col + delCol[i];

            if (nrow >= 0 &&
                nrow < n &&
                ncol >= 0 &&
                ncol < m &&
                image[nrow][ncol] == initialColor &&
                ans[nrow][ncol] != newColor) {

                dfs(
                    nrow,
                    ncol,
                    ans,
                    image,
                    newColor,
                    delRow,
                    delCol,
                    initialColor
                );
            }
        }
    }

    public int[][] floodFill(int[][] image, int sr, int sc, int color) {

        int initialColor = image[sr][sc];

        int[][] ans = image;

        int[] delRow = {-1, 0, 1, 0};
        int[] delCol = {0, 1, 0, -1};

        dfs(
            sr,
            sc,
            ans,
            image,
            color,
            delRow,
            delCol,
            initialColor
        );

        return ans;
    }
}
```

# Better DFS (Without Extra Arrays)

Since `ans` and `image` point to the same matrix, we can simplify the solution.

Also, if the starting color is already equal to the new color, we return immediately.

```java
class Solution {

    int[][] dirs = {
        {-1,0},
        {1,0},
        {0,-1},
        {0,1}
    };

    public void dfs(int[][] image, int r, int c,
                    int originalColor, int newColor) {

        image[r][c] = newColor;

        for (int[] dir : dirs) {

            int nr = r + dir[0];
            int nc = c + dir[1];

            if (nr >= 0 &&
                nr < image.length &&
                nc >= 0 &&
                nc < image[0].length &&
                image[nr][nc] == originalColor) {

                dfs(image, nr, nc, originalColor, newColor);
            }
        }
    }

    public int[][] floodFill(int[][] image,
                             int sr,
                             int sc,
                             int color) {

        int originalColor = image[sr][sc];

        if (originalColor == color)
            return image;

        dfs(image, sr, sc, originalColor, color);

        return image;
    }
}
```

# BFS Solution

Flood fill can also be implemented using BFS.

```java
class Solution {

    public int[][] floodFill(int[][] image, int sr, int sc, int color) {

        int original = image[sr][sc];

        if (original == color)
            return image;

        int[][] dirs = {
            {-1,0},
            {1,0},
            {0,-1},
            {0,1}
        };

        Queue<int[]> q = new LinkedList<>();

        q.offer(new int[]{sr, sc});

        image[sr][sc] = color;

        while (!q.isEmpty()) {

            int[] curr = q.poll();

            for (int[] dir : dirs) {

                int nr = curr[0] + dir[0];
                int nc = curr[1] + dir[1];

                if (nr >= 0 &&
                    nr < image.length &&
                    nc >= 0 &&
                    nc < image[0].length &&
                    image[nr][nc] == original) {

                    image[nr][nc] = color;
                    q.offer(new int[]{nr, nc});
                }
            }
        }

        return image;
    }
}
```

---

## Key Takeaways

- Flood Fill is a classic **graph traversal on a matrix**.
- Pixels are connected only in **4 directions**.
- DFS and BFS both solve the problem efficiently.
- Always save the **original color** before recoloring.
- If the original color equals the new color, return immediately to avoid infinite recursion.
