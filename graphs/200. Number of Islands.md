# 200. Number of Islands

**Difficulty:** Medium  
**Topics:** Graph, BFS, DFS, Matrix Traversal, Connected Components

---

## Intuition

Think of every land cell (`'1'`) as a node in a graph.

Two land cells belong to the same island if they are connected **horizontally or vertically**.

So, each **island is simply a connected component** in the grid.

The idea is:

- Traverse every cell.
- Whenever we encounter an unvisited land cell (`'1'`), we've discovered a new island.
- Start a BFS (or DFS) to visit every land cell belonging to that island.
- Increase the island count.

---

## Approach (BFS)

### Step 1: Traverse the Grid

Visit every cell in the matrix.

If the current cell is:

- Land (`'1'`)
- Not visited

then it is the starting point of a new island.

Increase the answer and start BFS.

---

### Step 2: BFS Traversal

Push the starting cell into a queue.

While the queue is not empty:

- Pop the current cell.
- Visit all 4 neighboring cells.
- If a neighbor is:
  - Inside the grid
  - Land (`'1'`)
  - Not visited

mark it visited and push it into the queue.

This marks the entire island as visited.

---

## Algorithm

1. Create a visited matrix.
2. Traverse every cell.
3. If the cell is unvisited land:
   - Increment island count.
   - Start BFS.
4. BFS visits every connected land cell.
5. Continue scanning the grid.
6. Return the total islands.

## Correctness Proof

We prove that the algorithm returns the correct number of islands.

Whenever an unvisited land cell is found:

- It must belong to a new island because no previous BFS has reached it.
- BFS explores every land cell connected to it.
- Therefore, the entire island gets marked visited.

Since every island has at least one starting cell, every island is counted exactly once.

Hence, the algorithm correctly returns the number of islands.

---

## Complexity Analysis

Let

- `n = number of rows`
- `m = number of columns`

Every cell is visited at most once.

```
Time  : O(n × m)
```

Visited array

```
Space : O(n × m)
```

Queue in worst case

```
O(n × m)
```

Overall

```
Time  : O(n × m)

Space : O(n × m)
```

## Java Solution (BFS)

```java
class Pair {
    int f;
    int s;

    public Pair(int f, int s) {
        this.f = f;
        this.s = s;
    }
}

class Solution {

    public void bfs(int r, int c, int[][] vis, char[][] grid) {

        vis[r][c] = 1;

        Queue<Pair> q = new LinkedList<>();
        q.add(new Pair(r, c));

        int n = grid.length;
        int m = grid[0].length;

        int[][] dirs = {
            {0, -1},
            {-1, 0},
            {1, 0},
            {0, 1}
        };

        while (!q.isEmpty()) {

            Pair curr = q.poll();

            int rr = curr.f;
            int cc = curr.s;

            for (int[] dir : dirs) {

                int newr = rr + dir[0];
                int newc = cc + dir[1];

                if (newr >= 0 && newr < n &&
                    newc >= 0 && newc < m &&
                    grid[newr][newc] == '1' &&
                    vis[newr][newc] == 0) {

                    vis[newr][newc] = 1;
                    q.add(new Pair(newr, newc));
                }
            }
        }
    }

    public int numIslands(char[][] grid) {

        int n = grid.length;
        int m = grid[0].length;

        int[][] vis = new int[n][m];

        int cnt = 0;

        for (int i = 0; i < n; i++) {

            for (int j = 0; j < m; j++) {

                if (grid[i][j] == '1' && vis[i][j] == 0) {

                    cnt++;
                    bfs(i, j, vis, grid);
                }
            }
        }

        return cnt;
    }
}
```

# DFS Solution

Instead of using a queue, we can recursively visit all neighboring land cells.

```java
class Solution {

    int[][] dirs = {
        {0,-1},
        {-1,0},
        {1,0},
        {0,1}
    };

    public void dfs(int r, int c, char[][] grid) {

        if (r < 0 || c < 0 ||
            r >= grid.length ||
            c >= grid[0].length ||
            grid[r][c] == '0') {
            return;
        }

        grid[r][c] = '0';

        for (int[] dir : dirs) {
            dfs(r + dir[0], c + dir[1], grid);
        }
    }

    public int numIslands(char[][] grid) {

        int islands = 0;

        for (int i = 0; i < grid.length; i++) {

            for (int j = 0; j < grid[0].length; j++) {

                if (grid[i][j] == '1') {

                    islands++;
                    dfs(i, j, grid);
                }
            }
        }

        return islands;
    }
}
```

---

# Space Optimized Approach

Instead of maintaining a separate visited array, we can directly mark visited land as water.

```java
grid[r][c] = '0';
```

This saves

```
O(n × m)
```

extra space.

The DFS solution above already uses this optimization.

---

## Key Takeaways

- Every island is a **connected component** in a grid.
- BFS and DFS both work equally well.
- Visit every land cell exactly once.
- Instead of using a separate visited matrix, modifying the input grid is a common space optimization.
- This problem is one of the most important applications of **Graph Traversal on Grids**.
