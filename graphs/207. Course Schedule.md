207. Course Schedule
Problem

You are given numCourses courses and prerequisites.

prerequisites[i] = [a, b]

means:

b → a

You must complete course b before taking course a.

The question is:

Can we finish all courses?

The key observation is:

If the prerequisite graph contains a cycle, we cannot finish all courses.

Therefore, this problem is essentially:

Detect a cycle in a directed graph using Kahn's Algorithm (Topological Sort).

Approach: Kahn's Algorithm

We use:

Adjacency list
Indegree
Queue
Count of processed courses
Step 1: Build the graph

For:

[1, 0]

the meaning is:

0 → 1

So we add:

ls.get(0).add(1);
Important correction to your code

Your code currently does:

ls.get(prerequisites[i][0]).add(prerequisites[i][1]);

which creates:

1 → 0

That is the reverse direction of the prerequisite relationship.

Your solution can still appear to work for cycle detection because reversing every edge preserves whether a directed graph has a cycle. However, it is better and more intuitive to construct the graph in the actual prerequisite direction:

ls.get(prerequisites[i][1]).add(prerequisites[i][0]);
Step 2: Calculate Indegree

For every edge:

u → v

we do:

ind[v]++;

indegree[v] means:

How many courses must be completed before course v?

Step 3: Add courses with indegree 0

If:

indegree[i] == 0

then there are no prerequisites for course i.

So we can take it immediately.

if(ind[i] == 0) {
    q.add(i);
}
Step 4: Process the queue

Take a course:

int node = q.remove();
cnt++;

After completing this course, it is no longer a prerequisite for its neighbors.

Therefore:

ind[it]--;

If a neighbor's indegree becomes 0, it is now available:

if(ind[it] == 0) {
    q.add(it);
}
Step 5: Check how many courses were processed

At the end:

return cnt == v;

If:

cnt == v

all courses were completed → possible

If:

cnt < v

some courses are stuck → cycle exists → impossible.

Java Solution
class Solution {

    public boolean canFinish(int v, int[][] prerequisites) {

        List<List<Integer>> adj = new ArrayList<>();

        for(int i = 0; i < v; i++) {
            adj.add(new ArrayList<>());
        }

        // Build graph
        for(int[] p : prerequisites) {

            int course = p[0];
            int prerequisite = p[1];

            // prerequisite -> course
            adj.get(prerequisite).add(course);
        }

        int[] indegree = new int[v];

        // Calculate indegree
        for(int i = 0; i < v; i++) {
            for(int next : adj.get(i)) {
                indegree[next]++;
            }
        }

        Queue<Integer> q = new LinkedList<>();

        // Courses with no prerequisites
        for(int i = 0; i < v; i++) {
            if(indegree[i] == 0) {
                q.add(i);
            }
        }

        int cnt = 0;

        // Kahn's Algorithm
        while(!q.isEmpty()) {

            int node = q.remove();
            cnt++;

            for(int next : adj.get(node)) {

                indegree[next]--;

                if(indegree[next] == 0) {
                    q.add(next);
                }
            }
        }

        return cnt == v;
    }
}

The Main Intuition

Think of prerequisites as dependencies.

For:

0 → 1 → 2

we can do:

Take 0
   ↓
0 is completed
   ↓
1 becomes available
   ↓
Take 1
   ↓
2 becomes available
   ↓
Take 2

But for:

0 → 1 → 2 → 0

everyone is waiting for someone else:

0 waits for 2
2 waits for 1
1 waits for 0

Nobody has indegree 0.

Therefore Kahn's algorithm gets stuck.

Why cnt == v Detects a Cycle

This is the most important part to remember.

Kahn's algorithm tries to create a topological ordering.

A directed graph has a topological ordering iff it has no cycle.

Therefore:

cnt == V
    ↓
All nodes processed
    ↓
Topological ordering exists
    ↓
No cycle
    ↓
Can finish courses

Whereas:

cnt < V
    ↓
Some nodes couldn't be processed
    ↓
Cycle exists
    ↓
Cannot finish courses
Your Code vs Correct Graph Direction

You wrote:

ls.get(prerequisites[i][0]).add(prerequisites[i][1]);

For:

[1,0]

this creates:

1 → 0

But the actual prerequisite relationship is:

0 → 1

because 0 must be completed before 1.

So use:

ls.get(prerequisites[i][1]).add(prerequisites[i][0]);
However, there is an interesting point

Your solution is still correct for cycle detection, because reversing all edges of a directed graph does not change whether a cycle exists.

For example:

Original:
0 → 1 → 2 → 0

Reversed:

0 → 2 → 1 → 0

Both contain a cycle.

So your answer works, but building the graph as:

prerequisite → course

is the cleaner and standard approach.

Kahn's cycle-detection template
calculate indegree

put all indegree-0 nodes into queue

while(queue not empty) {

    node = remove();

    count++;

    for(neighbor : node's neighbors) {

        indegree[neighbor]--;

        if(indegree[neighbor] == 0)
            queue.add(neighbor);
    }
}

return count == V;
