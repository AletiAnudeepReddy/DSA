# 994. Rotting Oranges

**Difficulty:** Medium  
**Topic:** Graph, BFS, Matrix, Multi-Source BFS

---

## Intuition

A rotten orange infects all **4-directionally adjacent** fresh oranges **every minute**.

Instead of running BFS from every rotten orange separately, we can think of **all rotten oranges as starting points at time = 0**.

This is a classic **Multi-Source BFS** problem.

- Put every rotten orange into the queue initially.
- Count the number of fresh oranges.
- Perform BFS level by level.
- Every newly infected orange enters the queue with `time + 1`.
- Track the maximum time required.
- If every fresh orange becomes rotten, return the time.
- Otherwise return **-1**.

---

## Approach (Multi-Source BFS)

### Step 1
Traverse the grid.

- Count fresh oranges.
- Push every rotten orange into the queue with time `0`.

---

### Step 2

Run BFS.

For every rotten orange:

- Visit its four neighbours.
- If a neighbour is fresh:
  - Mark it rotten.
  - Push it into the queue with `time + 1`.
  - Increase the count of rotten fresh oranges.

---

### Step 3

After BFS,

If

```
rottedFresh == totalFresh
```

return the maximum time.

Otherwise,

some fresh oranges were unreachable.

Return **-1**.

---

## Example

Input

```
2 1 1
1 1 0
0 1 1
```

Initially

```
Queue:
(0,0,time=0)
```

Minute 1

```
2 2 1
2 1 0
0 1 1
```

Minute 2

```
2 2 2
2 2 0
0 1 1
```

Minute 3

```
2 2 2
2 2 0
0 2 1
```

Minute 4

```
2 2 2
2 2 0
0 2 2
```

Answer = **4**

---

## Algorithm

1. Count all fresh oranges.
2. Push every rotten orange into the queue.
3. Perform Multi-Source BFS.
4. Infect neighbouring fresh oranges.
5. Track elapsed time.
6. If all fresh oranges were infected return time.
7. Otherwise return -1.

---

## Correctness

Initially, every rotten orange starts spreading simultaneously.

Since BFS explores nodes level by level,

- all oranges infected at minute `t`
- are processed before oranges infected at minute `t+1`.

Therefore the first time a fresh orange is reached is the **minimum possible minute** it can become rotten.

If some fresh orange is never reached, it is isolated by empty cells and can never rot, so the answer is **-1**.

Hence the algorithm always returns the minimum required time.

---

## Complexity Analysis

Let

- **N = rows**
- **M = columns**

Each cell is visited at most once.

**Time Complexity**

```
O(N × M)
```

**Space Complexity**

Queue + visited array

```
O(N × M)
```

## Java Solution

```java
class Pair {
    int row;
    int col;
    int tm;

    Pair(int _row, int _col, int _tm) {
        this.row = _row;
        this.col = _col;
        this.tm = _tm;
    }
}

class Solution {
    public int orangesRotting(int[][] grid) {
        int n = grid.length;
        int m = grid[0].length;

        Queue<Pair> q = new LinkedList<>();
        int[][] vis = new int[n][m];
        int cntFresh = 0;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {

                if (grid[i][j] == 2) {
                    q.add(new Pair(i, j, 0));
                    vis[i][j] = 2;
                } else {
                    vis[i][j] = 0;
                }

                if (grid[i][j] == 1)
                    cntFresh++;
            }
        }

        int tm = 0;
        int cnt = 0;

        int[] drow = {-1, 0, 1, 0};
        int[] dcol = {0, 1, 0, -1};

        while (!q.isEmpty()) {

            Pair curr = q.poll();

            int r = curr.row;
            int c = curr.col;
            int t = curr.tm;

            tm = Math.max(tm, t);

            for (int i = 0; i < 4; i++) {

                int nr = r + drow[i];
                int nc = c + dcol[i];

                if (nr >= 0 && nr < n &&
                    nc >= 0 && nc < m &&
                    vis[nr][nc] == 0 &&
                    grid[nr][nc] == 1) {

                    vis[nr][nc] = 2;
                    cnt++;

                    q.add(new Pair(nr, nc, t + 1));
                }
            }
        }

        return (cnt != cntFresh) ? -1 : tm;
    }
}
```

---

## Key Takeaways

- This is a **Multi-Source BFS** problem.
- All rotten oranges act as **simultaneous BFS sources**.
- BFS naturally computes the **minimum time** required to infect every reachable orange.
- If the number of infected fresh oranges is less than the total fresh oranges, some oranges are unreachable, so return **-1**.
