130. Surrounded Regions
Problem

You are given an m x n board containing 'X' and 'O'.

An 'O' region should be converted to 'X' only if it is completely surrounded by 'X'.

The important observation is:

Any 'O' connected to the boundary can never be surrounded.

So instead of finding surrounded regions directly, we find all 'O' cells connected to the boundary and mark them as safe. Every remaining 'O' can then be converted to 'X'.

Approach: Boundary DFS
Idea
Create a vis matrix.
Start DFS from every 'O' on the boundary.
Mark every 'O' reachable from those boundary cells as visited.
Traverse the whole board:
If board[i][j] == 'O' and vis[i][j] == 0, it is surrounded → change it to 'X'.
Otherwise, leave it as 'O'.
Why does this work?

Consider:

X X X X
X O O X
X X O X
X O X X

The bottom O is connected to the boundary, so it is safe:

X X X X
X O O X
X X O X
X O X X
    ↑
 boundary

The upper three Os are not connected to any boundary O, so they are surrounded and can be captured.

Result:

X X X X
X X X X
X X X X
X O X X
Code
class Solution {

    private void dfs(int row, int col, int[][] vis,
                     char[][] mat, int[] delrow, int[] delcol) {

        vis[row][col] = 1;

        int n = mat.length;
        int m = mat[0].length;

        for (int i = 0; i < 4; i++) {

            int nrow = row + delrow[i];
            int ncol = col + delcol[i];

            if (nrow >= 0 && nrow < n &&
                ncol >= 0 && ncol < m &&
                vis[nrow][ncol] == 0 &&
                mat[nrow][ncol] == 'O') {

                dfs(nrow, ncol, vis, mat, delrow, delcol);
            }
        }
    }

    public void solve(char[][] board) {

        int n = board.length;
        int m = board[0].length;

        int[] delrow = {-1, 0, 1, 0};
        int[] delcol = {0, 1, 0, -1};

        int[][] vis = new int[n][m];

        // First column and last column
        for (int i = 0; i < n; i++) {

            if (vis[i][0] == 0 && board[i][0] == 'O') {
                dfs(i, 0, vis, board, delrow, delcol);
            }

            if (vis[i][m - 1] == 0 && board[i][m - 1] == 'O') {
                dfs(i, m - 1, vis, board, delrow, delcol);
            }
        }

        // First row and last row
        for (int j = 0; j < m; j++) {

            if (vis[0][j] == 0 && board[0][j] == 'O') {
                dfs(0, j, vis, board, delrow, delcol);
            }

            if (vis[n - 1][j] == 0 && board[n - 1][j] == 'O') {
                dfs(n - 1, j, vis, board, delrow, delcol);
            }
        }

        // Capture all unvisited O's
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {

                if (vis[i][j] == 0 && board[i][j] == 'O') {
                    board[i][j] = 'X';
                }
            }
        }
    }
}
The most important part

The entire problem can be reduced to this:

Boundary O
     ↓
DFS/BFS
     ↓
Mark all connected O's as SAFE
     ↓
Remaining O's = SURROUNDED
     ↓
Convert them to X
Why start from the boundary?

Because a region is not surrounded if even one of its cells touches the boundary.

So:

O → O → O
          ↓
       boundary

All three are safe.

Whereas:

X X X X
X O O X
X O O X
X X X X

None of these Os can reach the boundary, so the entire region is surrounded.

Complexity

Let n = number of rows and m = number of columns.

Time

Boundary DFS visits each cell at most once:

O(n × m)

The final traversal is also:

O(n × m)

Overall:

O(n × m)
Space

The vis matrix takes:

O(n × m)

DFS recursion can additionally use up to:

O(n × m)

in the worst case.

So auxiliary space is:

O(n × m)
Pattern to remember

This is an important Boundary Traversal + DFS/BFS pattern.

You will see the same idea in problems involving:

Surrounded regions
Enclosed areas
Cells connected to the boundary
Number of enclaves
Pacific Atlantic Water Flow (related boundary-thinking)
Flood-fill type problems
